## Where algebraic expressions come from

**An algebraic expression is a recipe for a number you don't know yet.** Letters (variables) stand for the unknown amounts.

**Book example 1 — Raju's boxes.** Red boxes hold 4 pens, blue boxes hold 5 pencils. Raju buys **x** red and **y** blue boxes and gets 3 extra pens free.

```
pens in x red boxes      = 4x
pencils in y blue boxes  = 5y
total                    = 4x + 5y + 3
```

| Word | In 4x + 5y + 3 |
|---|---|
| **terms** | 4x, 5y and 3 — the pieces joined by + or − |
| **variables** | x and y — the letters (the book used to call them "letter-numbers") |
| **coefficients** | 4 (of x) and 5 (of y) — the numbers multiplying the variables |
| **constant** | 3 — the term with no variable |

**Book example 2 — fencing a garden** of length l and width w: wire along both lengths at ₹100/m, wood along both widths at ₹80/m, seeds at ₹50 per square metre.

```
wire   = 2l × 100   = 200l
wood   = 2w × 80    = 160w
seeds  = 50 × l × w = 50lw
total  = 200l + 160w + 50lw
```

**What's different from example 1:** the term **50lw** multiplies **two** variables together (because area is length × width).

**Book example 3 — a 20 cm wire bent into rectangles.** Length + width = half the perimeter = 10 cm. If the length is x, the width is (10 − x), so

```
area = x(10 − x) = 10x − x²
```

**Only one variable this time — but x appears squared.**

## 2.1 Polynomials in one variable, and their degree

**From now on we use only ONE variable at a time** — like 4x, x² + 1, 2y − 5, 3z + 7, 5y³ + y² + 2y − 1.

> [!IMPORTANT]
> **A (univariate) POLYNOMIAL is an expression in one variable made of terms like (number) × (variable)^(whole-number power), added together.**
>
> **Its DEGREE is the HIGHEST power of the variable that appears.**

| Polynomial | Degree | Name |
|---|---|---|
| 5y³ + y² + 2y − 1 | 3 | **cubic** |
| x² + 5x + 1 | 2 | **quadratic** |
| 3z + 7 | 1 | **linear** |
| 8 | 0 | **constant** |

> [!NOTE]
> **Why is a plain number like 8 "degree 0"?** Because 8 = 8 × x⁰, and any (non-zero) number to the power 0 is 1. So the highest power of x present is 0.
>
> **Why x⁰ = 1:** going down the powers, x³ → x² → x¹ means dividing by x each time. One more step: x¹ ÷ x = 1. So x⁰ = 1.

**Reading coefficients:** in 5y³ + y² + 2y − 1, the coefficient of y³ is **5**, of y² is **1** (y² means 1 × y²), of y is **2**, and the **constant term is −1** (the sign belongs to the term).

### Exercise Set 2.1, worked

1. Degrees: 2x² − 5x + 3 → **2**; y³ + 2y − 1 → **3**; −9 → **0**; 4z − 3 → **1**.
2. Examples: degree 1: **3x + 2**; degree 2: **x² − 4**; degree 3: **2x³ + x − 5** (any correct ones are fine).
3. x⁴ − 3x³ + 6x² − 2x + 7: coefficient of x² is **6**, of x³ is **−3**.
4. 4z³ + 5z² − 11: there's no z term at all, so the coefficient of z is **0**.
5. 9x³ + 5x² − 8x − 10: constant term **−10**.

> [!WARNING]
> **The sign in front of a term is part of the coefficient.** In x⁴ − 3x³ the coefficient of x³ is **−3**, not 3. And a missing term has coefficient **0**.

## 2.2 Linear polynomials

> [!IMPORTANT]
> **A LINEAR polynomial has degree 1: it looks like ax + b, with a ≠ 0.**
>
> (a ≠ 0 because if a were 0 the x-term disappears and we'd just have the constant b.)

**Example 4:** a square of side x has perimeter **4x**. Sides 1, 1.5, 2, 2.5, 3 cm give perimeters 4, 6, 8, 10, 12 cm — **every extra 0.5 cm of side adds exactly 2 cm** of perimeter.

**Example 5 — the chess club:** ₹200 to join plus ₹50 per match. After m matches you have paid **200 + 50m**.

| matches m | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| amount (₹) | 200 | 250 | 300 | 350 | 400 |

**If a player paid ₹750:** 200 + 50m = 750 → 50m = 550 → **m = 11 matches**.

> [!IMPORTANT]
> **The signature of a linear polynomial: when the input goes up by equal steps, the output goes up (or down) by EQUAL steps.**
>
> **Why:** compare ax + b at x and at x + 1. The difference is [a(x + 1) + b] − [ax + b] = **a** — the same number every time, whatever x is. So a linear polynomial always changes by **a** per unit step.
>
> A quadratic doesn't behave like this: 10x − x² at x = 1, 2, 3, 4 gives 9, 16, 21, 24 — jumps of 7, 5, 3. Not constant.

### Linear equations

**Set a linear polynomial equal to a number and you get a LINEAR EQUATION** — which you solve by "undoing" the operations.

**Example 6:** two numbers add to 64; one is 10 more than the other. Let the smaller be **x**, the larger **x + 10**:

```
x + (x + 10) = 64
     2x + 10 = 64
          2x = 54      (subtract 10 from both sides)
           x = 27      (divide both sides by 2)
```

**The numbers are 27 and 37.** Check: 27 + 37 = 64 ✓, 37 − 27 = 10 ✓.

> [!NOTE]
> **Why "do the same to both sides" is allowed:** an equation says two amounts are equal — a balanced scale. Taking 10 off both pans, or halving both, keeps them balanced.

### A polynomial as an input–output machine

**Put in x, get out the value.** For 2x + 3: input 4 → 2 × 4 + 3 = **11**; input −6 → 2 × (−6) + 3 = **−9**. A rule like this, giving one output for each input, is called a **function**. 2x + 3 is a **linear function**; the wire-rectangle area 10x − x² is a **quadratic function** (at x = 6: 60 − 36 = **24 cm²**).

### Exercise Set 2.2, worked

1. 5x − 3 at x = 0, −1, 2 → **−3, −8, 7**.
2. 7s² − 4s + 6 at s = 0 → **6**; s = −3 → 7(9) + 12 + 6 = **81**; s = 4 → 7(16) − 16 + 6 = **102**.
3. **Salil and his mother.** Let Salil be s; mother 3s. In 5 years: (s + 5) + (3s + 5) = 70 → 4s + 10 = 70 → s = 15. **Salil 15, mother 45.**
4. **Difference 63, ratio 2 : 5.** Let the numbers be 2k and 5k. 5k − 2k = 3k = 63 → k = 21 → **42 and 105**.
5. **Ruby's coins.** Let x five-rupee coins; then 3x two-rupee coins. Value: 5x + 2(3x) = 11x = 88 → x = 8. **8 five-rupee coins and 24 two-rupee coins.**
6. **300 ft fence**, longer = 4 × shorter: x + 4x = 300 → x = 60 → **60 ft and 240 ft**.
7. **Rectangle**, length = 2w + 3, perimeter 24: 2(w + 2w + 3) = 24 → 3w + 3 = 12 → w = 3 → **width 3 cm, length 9 cm**.

> [!TIP]
> **Word problems — the recipe:** (1) write "Let x = …" for the unknown you'll find easiest; (2) express every other quantity using x; (3) turn the sentence that gives a total or a condition into an equation; (4) solve; (5) **check in the original words**, not in your equation.

## 2.3 Linear patterns

**Book's tile pattern:** stage 1 has 1 square, and each stage adds 2 more.

| stage n | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| tiles | 1 | 3 | 5 | 7 | 9 | 11 | 13 |

**Finding the rule:** the tiles go up by **2** each stage, so the rule starts **2n**. But 2n at n = 1 gives 2, one too many. So **tiles = 2n − 1**.

> [!IMPORTANT]
> **A LINEAR PATTERN is a sequence whose consecutive terms differ by a CONSTANT. Its nth term is always a linear expression: (common difference) × n + (adjustment).**
>
> **Why:** starting from the first term and adding the same d each time, the nth term is first term + (n − 1)d = dn + (first term − d) — linear in n.

**Using 2n − 1:** stage 15 → **29 tiles**; stage 26 → **51 tiles**. Which stage has 21 tiles? 2n − 1 = 21 → **n = 11**. 47 tiles? 2n − 1 = 47 → **n = 24**.

**Example 7 — Bela's pocket money:** ₹100, spends ₹5 a day. Left after n days: **100 − 5n**. ₹40 left when 100 − 5n = 40 → **n = 12**. After 15 days: **₹25**. All gone when 100 − 5n = 0 → **20 days**.

**Example 8 — auto fare:** ₹25 for the first 2 km, then ₹15 per km. For n km (n ≥ 2): **25 + 15(n − 2) = 15n − 5**. 10 km → 25 + 15 × 8 = **₹145**. Fare ₹130: 15n − 5 = 130 → **n = 9 km**.

> [!WARNING]
> **Count carefully where the "extra" starts.** The auto charges ₹15 only for km **after** the first 2, so it's 15(n − 2), not 15n.

### Exercise Set 2.3, worked

1. ₹500 + ₹150 a month → **500 + 150n** after n months (650, 800, 950, …).
2. Rally of 120 losing 9 an hour → **120 − 9n** (111, 102, 93, …).
3. Length 13: breadth 12, 10, 8 → areas **156, 130, 104 cm²**; area = **13b** (drops by 26 for every 2 cm off the breadth).
4. 7 × 11 base: heights 5, 9, 13 → volumes **385, 693, 1001 cm³**; volume = **77h**.
5. 500 pages, 20 a day → **500 − 20n** left; after 15 days **200 pages**.

## 2.4 Linear growth and linear decay

> [!IMPORTANT]
> - **LINEAR GROWTH:** a quantity **increases** by the **same amount** over each equal interval (a > 0 in ax + b).
> - **LINEAR DECAY:** a quantity **decreases** by the **same amount** over each equal interval (a < 0).

**Example 9 — journey cost C(d) = 100 + 60d.** Every extra km adds ₹60 → growth. 15 km: 100 + 900 = **₹1000**. Cost ₹700: 60d = 600 → **10 km**.

**Example 10 — tank water h(t) = 3 − 0.5t** metres after t months. Each month removes 0.5 m → decay. After 5 months: 3 − 2.5 = **0.5 m**. Empty when 0.5t = 3 → after **6 months**.

### Exercise Set 2.4, worked

1. **Plant** 1.75 ft, +0.5 ft a month: **h = 1.75 + 0.5t**; after 7 months **5.25 ft**. Growth, because it rises by the same 0.5 ft every month.
2. **Phone** ₹10,000, −₹800 a year: **v = 10000 − 800t**; after 3 years **₹7,600**. Decay — same drop each year.
3. **Village** 750, +50 a year: **P = 750 + 50t**; after 6 years **1050**.
4. **Recharge** ₹600, −₹15 a day: **b(x) = 600 − 15x**; runs out when 15x = 600 → **40 days**.

> [!NOTE]
> **Real life is only linear for a while.** A plant won't grow 0.5 ft every month forever, and a phone's value can't go below zero. A linear model is a good description **over a range**.

## 2.5 Linear relationships y = ax + b

> [!IMPORTANT]
> **A LINEAR RELATIONSHIP between two variables x and y has the form y = ax + b.**
>
> - **b** is the value of y when x = 0 — the **starting amount** or **fixed charge**.
> - **a** is how much y changes when x goes up by 1 — the **rate**.

**Example 11 — data bill.** 10 GB → ₹350; 20 GB → ₹550. Find a and b in y = ax + b.

```
350 = 10a + b
550 = 20a + b
```

**Book's method (substitution):** from the first, b = 350 − 10a. Put it in the second: 550 = 20a + 350 − 10a → 10a = 200 → **a = 20**, then **b = 350 − 200 = 150**. So **y = 20x + 150**.

**Meaning:** ₹20 per GB and a fixed ₹150 monthly fee.

> [!TIP]
> **Quick way to get a:** the extra 10 GB cost an extra ₹200, so each GB costs 200 ÷ 10 = ₹20. **a = (change in y) ÷ (change in x).** Then b = y − ax using either pair.
>
> **Why:** in y = ax + b, raising x by some amount raises y by exactly a times that amount — b cancels when you subtract.

### Exercise Set 2.5, worked

1. **Learning platform:** 10 modules ₹400, 14 modules ₹500 → a = 100 ÷ 4 = **25**, b = 400 − 250 = **150**. y = 25x + 150.
2. **Gym:** 10 h ₹800, 15 h ₹1100 → a = 300 ÷ 5 = **60**, b = 800 − 600 = **200**. y = 60x + 200.
3. **Celsius from Fahrenheit, C = aF + b:** (F, C) = (32, 0) and (212, 100). a = 100 ÷ 180 = **5/9**; b = 0 − (5/9)(32) = **−160/9**. So **C = (5/9)F − 160/9 = (5/9)(F − 32)**. Check: F = 212 → (5/9)(180) = 100 ✓.

## 2.6 Graphs: every linear relationship is a straight line

**To draw y = 2x + 1, find two points:** x = 0 → y = 1, so **A (0, 1)**; x = 3 → y = 7, so **B (3, 7)**. Join and extend.

| x | −1 | 0 | 1 | 2 | 3 | 7 |
|---|---|---|---|---|---|---|
| y = 2x + 1 | −1 | 1 | 3 | 5 | 7 | 15 |

> [!IMPORTANT]
> **A point lies on the line exactly when its coordinates satisfy the equation.** (7, 15): 2 × 7 + 1 = 15 ✓ → on the line. (2, 6): 2 × 2 + 1 = 5 ≠ 6 → not on it.
>
> **Why two points are enough:** the graph of a linear relationship is a straight line (each step right of 1 unit always goes up by the same a, so the direction never changes), and through two points there is exactly one straight line.

**Guessing the equation from points.** (−1, −3), (0, 0), (1, 3), (3, 9), (4, 12): every y is **3 times** x → **y = 3x**. (−3, 6), (−2, 4), (0, 0), (1, −2), (2, −4), (3, −6): every y is **−2 times** x → **y = −2x**.

### Slope: the number a

**Draw y = ½x, y = x and y = 2x on the same axes.**

- All three pass through **(0, 0)** — put x = 0 and y = a × 0 = 0.
- **y = x** goes up 1 for every 1 across — the 45° line, **equally inclined to both axes**.
- **y = 2x** (a > 1) is **steeper** than y = x; **y = ½x** (a < 1) is **less steep**.

> [!IMPORTANT]
> **In y = ax + b, a is the SLOPE: how far the line rises for each 1 unit you move right.**
>
> - **a > 0** → line rises left to right → **linear growth**.
> - **a < 0** → line falls left to right → **linear decay**. (y = −x, y = −3x, y = −⅓x all go **downhill**; −3x is the steepest downhill.)
> - Bigger **size** of a (ignoring sign) → steeper.
>
> **The slope equals the constant difference of the pattern.** Tiles y = 2x − 1 go up 2 per stage, and the slope is 2.

**y = 3x + 1 versus y = −3x + 1:** both cross the y-axis at (0, 1) and are equally steep, but the first **rises** and the second **falls** — mirror images in the y-axis.

### The y-intercept: the number b

**y = x + 3, y = 2x + 5 and y = 3x − 2** cross the y-axis at (0, 3), (0, 5) and (0, −2).

> [!IMPORTANT]
> **y = ax + b cuts the y-axis at (0, b). b is the Y-INTERCEPT.**
>
> **Why:** every point on the y-axis has x = 0, and putting x = 0 gives y = a × 0 + b = b.

**Parallel lines.** y = 2x − 1, y = 2x + 1 and y = 2x + 5 have the **same slope 2** but different intercepts −1, 1, 5.

> [!IMPORTANT]
> **Same slope, different b → PARALLEL lines.**
>
> **Why:** at every x, the line y = 2x + 5 sits exactly 4 units above y = 2x + 1 (the difference is (2x + 5) − (2x + 1) = 4, with no x left). A constant gap means they never meet.
>
> **Change a with b fixed** → the line **turns** about (0, b). **Change b with a fixed** → the line **slides** up or down, staying parallel.

**Where a line cuts the x-axis:** there y = 0. For y = 3x + 2: 0 = 3x + 2 → x = −2/3 → **(−2/3, 0)**.

## Questions from the book, worked

1. **Degree 3 with x² coefficient −7:** e.g. **x³ − 7x² + 2x + 1**.
2. (i) 5x² − 3x + 7 at x = 1 → 5 − 3 + 7 = **9**. (ii) 4t³ − t² + 6 at t = a → **4a³ − a² + 6** (just replace t by a).
3. **Multiply by 5/2, add 2/3, get −7/12.** (5/2)x + 2/3 = −7/12 → (5/2)x = −7/12 − 8/12 = −15/12 = −5/4 → x = −5/4 × 2/5 = **−1/2**. Check: (5/2)(−1/2) + 2/3 = −5/4 + 2/3 = −15/12 + 8/12 = −7/12 ✓.
4. **One number 5 times the other; add 21 to both, one becomes twice the other.** Numbers x and 5x: 5x + 21 = 2(x + 21) → 3x = 21 → x = 7. **7 and 35.** Check: 56 = 2 × 28 ✓.
5. **₹800 + ₹250 a month:** 800 + 250n. After 6 months **₹2,300**; after 2 years (24 months) **₹6,800**.
6. **Digits differ by 3; number + reversed = 143.** A two-digit number with digits p, q is 10p + q; reversed is 10q + p; the sum is **11(p + q)**. 11(p + q) = 143 → p + q = 13. With p − q = 3: p = 8, q = 5. **85 and 58.** (85 + 58 = 143 ✓.)
7. Rewrite each as y = ax + b first:
   - (i) y = −3x + 4 → slope **−3**, cuts the y-axis at **(0, 4)**.
   - (ii) 2y = 4x + 7 → y = 2x + 7/2 → slope **2**, **(0, 7/2)**.
   - (iii) 5y = 6x − 10 → y = (6/5)x − 2 → slope **6/5**, **(0, −2)**.
   - (iv) 3y = 6x − 11 → y = 2x − 11/3 → slope **2**, **(0, −11/3)**.
   - **(ii) and (iv) are parallel** — same slope 2, different intercepts.
8. **y = (9/5)(x − 273) + 32.** (i) 313 K: (9/5)(40) + 32 = 72 + 32 = **104 °F**. (ii) 158 °F: (9/5)(x − 273) = 126 → x − 273 = 70 → **343 K**.
9. **Work = force × distance, force 3:** **w = 3d** — a line through the origin with slope 3. At d = 2, **w = 6**.
10. **Line through (1, 5) and (3, 11):** slope = (11 − 5) ÷ (3 − 1) = 3; b = 5 − 3 = 2 → **p(x) = 3x + 2**. Cuts the y-axis at **(0, 2)** and the x-axis where 3x + 2 = 0 → **(−2/3, 0)**.
11. **p = ax + b, q = cx + d.** p(0) = 5 → **b = 5**. p + q = (a + c)x + (5 + d) = 6x + 4 → a + c = 6 and d = −1. p − q = (a − c)x + 6 is zero at x = 3 → 3(a − c) = −6 → a − c = −2. So a = 2, c = 4: **p(x) = 2x + 5, q(x) = 4x − 1**.
12. **Hexagons sharing a side:** 6, 11, 16, 21, 26, … (each new hexagon needs only 5 new sticks, because one side is shared). Rule: **5n + 1**. Stage 15: **76**. 200 sticks? 5n + 1 = 200 → n = 39.8 — not a whole number, so **no**.
13. p through (2, 3) and (6, 11): slope 8 ÷ 4 = 2, so **p(x) = 2x − 1**. q is parallel (slope 2) through (4, −1): −1 = 8 + d → **q(x) = 2x − 9**. x-axis crossings: p at **(1/2, 0)**, q at **(9/2, 0)**.
14. **f(x) = ax + a = a(x + 1), a > 0:** every such line passes through **(−1, 0)**, rises (positive slope), and has its y-intercept equal to its slope.

## In a nutshell

- A **polynomial** in one variable: terms like (number) × x^(whole number). **Degree** = highest power. Degree 0 constant, 1 linear, 2 quadratic, 3 cubic.
- A **linear polynomial** is **ax + b (a ≠ 0)**; setting it equal to a number gives a **linear equation**.
- Equal steps in x → **equal steps in the value** (always a). That's a **linear pattern**: nth term = dn + (first term − d).
- **Growth**: same increase each interval (a > 0). **Decay**: same decrease (a < 0).
- **y = ax + b**: a = rate = **slope** = (change in y) ÷ (change in x); b = starting value = **y-intercept**, where the line meets the y-axis at (0, b).
- Every linear relationship graphs as a **straight line**; two points fix it. A point is on it iff it satisfies the equation.
- **Same slope → parallel.** b = 0 → passes through the origin.

> [!WARNING]
> **Top traps:** the sign belongs to the coefficient (−3x³ has coefficient −3) · a missing term has coefficient 0 · a constant has degree 0, not 1 · rewrite 2y = 4x + 7 as y = 2x + 3.5 **before** reading the slope · in "₹25 for the first 2 km, then ₹15 per km", charge 15(n − 2), not 15n · slope is change in **y** over change in **x**, not the other way · check word-problem answers in the original sentence.
