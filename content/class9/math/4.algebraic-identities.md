## A pattern to explain

Take any three consecutive square numbers, add the smallest and largest, and subtract twice the middle:

```
1, 4, 9      (1 + 9) − 2(4)  = 10 − 8  = 2
9, 16, 25    (9 + 25) − 2(16) = 34 − 32 = 2
25, 36, 49   (25 + 49) − 2(36) = 74 − 72 = 2
```

**The answer is always 2.** By the end of this chapter you'll see exactly why.

## Identity vs equation

> [!IMPORTANT]
> **An IDENTITY is an equation that is true for ALL values of its variables.**
>
> **An EQUATION need not be** — it may hold for only particular values.

`x² − 1 = 24` is true only for `x = 5` or `x = −5` → an **equation**.
`(x + y)² = x² + 2xy + y²` is true for **every** x and y → an **identity**.

## `(a + b)² = a² + 2ab + b²`

**The picture.** A square of side `(a + b)` splits into a square `a²`, a square `b²`, and **two** rectangles of `ab`.

```
        a       b
    ┌───────┬──────┐
  a │  a²   │  ab  │
    ├───────┼──────┤
  b │  ab   │  b²  │
    └───────┴──────┘
```

**But the picture only covers positive LENGTHS.** Does the identity hold for negatives and fractions too?

**Check with `a = −2, b = −3`:** `(a+b)² = (−5)² = 25`; and `a² + 2ab + b² = 4 + 12 + 9 = 25` ✓

**Check with `a = −2/3, b = 3/4`:** `(a+b) = 1/12`, so `(a+b)² = 1/144`; and `4/9 − 1 + 9/16 = 1/144` ✓

**The proof that settles it — distributivity:**

```
(a + b)² = (a + b)(a + b) = a(a + b) + b(a + b)
         = a² + ab + ba + b² = a² + 2ab + b²
```

> [!TIP]
> **This is the real lesson: a picture SUGGESTS an identity; algebra PROVES it for every number.** The geometric argument only ever covers positive lengths.

### Is `(a + b)²` bigger than `a² + b²`?

**They differ by exactly `2ab`.**

| Condition | Result |
|---|---|
| a and b have the **same sign** → `2ab > 0` | **`(a+b)² > a² + b²`** |
| a and b have **opposite signs** → `2ab < 0` | **`(a+b)² < a² + b²`** |
| **a or b is 0** → `2ab = 0` | **equal** |

**Example:** `a = 10, b = 2` → `144 > 104` ✓ **Example:** `a = 5, b = −2` → `9 < 29` ✓

### Uses

**Expanding:** `(5x + 2y)² = (5x)² + 2(5x)(2y) + (2y)² =` **25x² + 20xy + 4y²**

**Fast squaring:** `43² = (40 + 3)² = 1600 + 240 + 9 =` **1849**

## `(a − b)² = a² − 2ab + b²`

**Just replace b by −b** in the first identity — `(−b)² = +b²` and `2a(−b) = −2ab`.

**The picture:** from a square of side a, cut off a rectangle `ab` and another `b(a − b)`:
`(a − b)² = a² − ab − b(a − b) = a² − ab − ba + b² = a² − 2ab + b²`

**Fast squaring:** `29² = (30 − 1)² = 900 − 60 + 1 =` **841**
`79² = (80 − 1)² = 6400 − 160 + 1 =` **6241**

### Explaining the opening pattern

Three consecutive numbers are `n − 1`, `n`, `n + 1`:

```
(n − 1)² + (n + 1)² = (n² − 2n + 1) + (n² + 2n + 1) = 2n² + 2
subtract 2n²                                       = 2
```

**The 2n terms cancel and the n² cancels — leaving 2, always.** ∎

## `(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca`

**Derived by grouping:** let `d = b + c`. Then

```
(a + d)² = a² + 2ad + d²
         = a² + 2a(b + c) + (b + c)²
         = a² + 2ab + 2ac + b² + 2bc + c²
```

**The picture:** a square of side `a + b + c` splits into **three squares** (`a², b², c²`) and **six rectangles** — two each of `ab`, `bc` and `ca`.

**Fast squaring:** `119² = (100 + 10 + 9)²`
`= 10000 + 100 + 81 + 2(1000) + 2(900) + 2(90) = 10000 + 100 + 81 + 2000 + 1800 + 180 =` **14161**

> [!TIP]
> **Choosing the right identity matters.** For `117²` use `(100 + 17)²`; for `198²` use `(200 − 2)²`; for `214²` use `(200 + 14)²`. **Pick the split that gives you the roundest numbers.**

## Factorising with the square identities

**Recognise the shape `a² + 2ab + b²` and read off a and b.**

**`x² + 4x + 4`:** `x² = (x)²`, `4 = 2²`, `4x = 2(x)(2)` → **`(x + 2)²`**

**`36x² + 12x + 1`:** `(6x)² + 2(6x)(1) + 1²` → **`(6x + 1)²`**

**`50p² + 60pq + 18q²`:** the coefficients don't look like squares — but **take out the common factor 2 first**:
`= 2(25p² + 30pq + 9q²) = 2[(5p)² + 2(5p)(3q) + (3q)²] =` **`2(5p + 3q)²`**

> [!TIP]
> **Always look for a common factor BEFORE trying to match an identity.** It often turns an unrecognisable expression into a perfect square.

## Śhrīdharāchārya's squaring rule

**Rearranging `a² − b² = (a + b)(a − b)` gives**

**`a² = (a + b)(a − b) + b²`**

**Choose b to make one factor round.** `55² = (55+5)(55−5) + 5² = 60 × 50 + 25 = 3000 + 25 =` **3025**

> [!TIP]
> **The "ends in 5" pattern.** `35² = 1225`, `65² = 4225`, `85² = 7225`, `105² = 11025`.
>
> **The rule:** for a number ending in 5, take the part before the 5, multiply it by one more than itself, and stick **25** on the end.
> `85²` → `8 × 9 = 72` → **7225** ✓ `105²` → `10 × 11 = 110` → **11025** ✓
>
> **Why:** `(10n + 5)² = 100n² + 100n + 25 = 100·n(n+1) + 25`.

## Factorising `x² + bx + c` — splitting the middle term

**Algebra tiles first.** A rectangle of sides `x + 3` and `x + 4` is built from **one x²-tile, seven x-tiles (3 to the right, 4 below) and twelve unit tiles in a 3 × 4 array**.

**The dimensions of the rectangle are the factors.** So `x² + 7x + 12 = (x + 3)(x + 4)`.

> [!IMPORTANT]
> **Without tiles: compare with `x² + (a + b)x + ab`.**
>
> **You need two numbers whose SUM is the x-coefficient and whose PRODUCT is the constant.**

**`x² + 7x + 12`:** need `a + b = 7`, `ab = 12` → **3 and 4** → `(x + 3)(x + 4)`

**`x² + 11x + 30`:** need `a + b = 11`, `ab = 30`. Try 2 and 15 → product ✓ but sum 17 ✗. Try 3 and 10 → sum 13 ✗. **5 and 6** → both ✓ → `(x + 5)(x + 6)`

**`x² − 5x + 6`:** need `a + b = −5`, `ab = +6`. **A positive product with a negative sum means BOTH are negative** → `−2` and `−3` → `(x − 2)(x − 3)`

**`x² − 4x − 96`:** need `a + b = −4`, `ab = −96`. **A negative product means OPPOSITE signs** → `−12` and `8` → `(x − 12)(x + 8)`

> [!TIP]
> **The sign shortcut:**
> - **`ab` positive** → a and b have the **same** sign (both match the sign of `a + b`)
> - **`ab` negative** → a and b have **opposite** signs

**General rule:** `(x + a)(x + b) = x² + (a + b)x + ab`
And `(px + a)(qx + b) = pq·x² + (pb + qa)x + ab`

## Cubes

**`(a + b)³ = a³ + 3a²b + 3ab² + b³`**

**Derivation:** `(a + b)³ = (a + b)(a² + 2ab + b²) = a³ + 3a²b + 3ab² + b³`

**The picture:** a **cube** of edge `a + b` splits into **two cubes** (`a³` and `b³`) and **six cuboids** — three of `a × a × b` (total `3a²b`) and three of `a × b × b` (total `3ab²`).

**Replace b by −b:**

**`(a − b)³ = a³ − 3a²b + 3ab² − b³`** — the four terms **alternate in sign**.

**Worked:** a cube of volume `p³ + 6p²q + 12pq² + 8q³`.
`= (p)³ + 3(p)²(2q) + 3(p)(2q)² + (2q)³ = (p + 2q)³` → **side = `p + 2q`**

**Worked:** `8n³ − 60n²m + 150nm² − 125m³`
`= (2n)³ − 3(2n)²(5m) + 3(2n)(5m)² − (5m)³ =` **`(2n − 5m)³`**

## Sums and differences of cubes

```
(x − y)(x² + xy + y²) = x³ − y³
(x + y)(x² − xy + y²) = x³ + y³
```

**Why the first works:** expand and watch the middle terms cancel —
`x³ + x²y + xy² − x²y − xy² − y³ = x³ − y³` ✓

> [!TIP]
> **`x − y` is a factor of `xⁿ − yⁿ` for EVERY n.**
>
> `x² − y² = (x − y)(x + y)` · `x³ − y³ = (x − y)(x² + xy + y²)`
> `x⁴ − y⁴ = (x² − y²)(x² + y²) = (x − y)(x + y)(x² + y²)` — and there it is again.

## The three-variable cube identity

**`(x + y + z)(x² + y² + z² − xy − yz − zx) = x³ + y³ + z³ − 3xyz`**

**Worked:** three numbers sum to 10, their product is 25, and their squares sum to 38. Find the sum of their cubes.

```
Need xy + yz + zx first, from (x+y+z)² = x² + y² + z² + 2(xy + yz + zx):
   100 = 38 + 2(xy + yz + zx)  →  xy + yz + zx = 31

Then the identity:
   (10)(38 − 31) = x³ + y³ + z³ − 3(25)
   70 = x³ + y³ + z³ − 75
   x³ + y³ + z³ = 145
```

## Simplifying rational expressions

**Factorise the top and the bottom, then cancel common factors.**

**Worked:** simplify `(x² − 7x + 12)/(5x² + 5x − 100)`, given the denominator ≠ 0.

```
Numerator:   a + b = −7, ab = 12  →  −3 and −4  →  (x − 3)(x − 4)
Denominator: take out 5 → 5(x² + x − 20)
             a + b = 1, ab = −20  →  5 and −4   →  5(x − 4)(x + 5)

  (x − 3)(x − 4)          x − 3
─────────────────  =  ───────────
  5(x − 4)(x + 5)       5(x + 5)
```

> [!WARNING]
> **You may only cancel a factor that is not zero** — which is why the question states the denominator ≠ 0.
>
> **And you can only cancel FACTORS, never individual terms.** `(x + 3)/(x + 5)` cannot be reduced by cancelling the x's.

## Applications

**Worked (Saira's rectangle):** one x-by-x square, 8 strips of `x × 1`, and 15 unit squares.
**Total area = `x² + 8x + 15`.** Factorising: `a + b = 8`, `ab = 15` → 3 and 5.
**The rectangle is `(x + 5)` by `(x + 3)`.**

**Worked (the pool):** breadth is 4 m less than length, area 96 m².
```
x(x − 4) = 96  →  x² − 4x − 96 = 0
Split −4x using −12 and 8:
x² − 12x + 8x − 96 = x(x − 12) + 8(x − 12) = (x − 12)(x + 8) = 0
So x = 12 or x = −8
```
**A length cannot be negative, so x = 12.** **Length 12 m, breadth 8 m.** ✓ `12 × 8 = 96`

> [!IMPORTANT]
> **`(x − 12)(x + 8) = 0` means one of the factors must be 0** — a product is zero only if a factor is zero. **Then check both answers against the real situation** and discard any that make no sense.

## Every identity in one place

```
(a + b)²         = a² + 2ab + b²
(a − b)²         = a² − 2ab + b²
(a + b)(a − b)   = a² − b²
a²               = (a + b)(a − b) + b²          [Śhrīdharāchārya]
(a + b + c)²     = a² + b² + c² + 2ab + 2bc + 2ca
(x + a)(x + b)   = x² + (a + b)x + ab
(a + b)³         = a³ + 3a²b + 3ab² + b³
(a − b)³         = a³ − 3a²b + 3ab² − b³
(x − y)(x² + xy + y²) = x³ − y³
(x + y)(x² − xy + y²) = x³ + y³
(x+y+z)(x²+y²+z²−xy−yz−zx) = x³ + y³ + z³ − 3xyz
```
