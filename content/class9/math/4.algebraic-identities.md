## A surprising pattern to start

**Take three square numbers in a row: 1, 4, 9.** Add the smallest and largest, then subtract twice the middle: (1 + 9) − 2 × 4 = **2**.

**Try 25, 36, 49:** (25 + 49) − 72 = **2**. Try 9, 16, 25: 34 − 32 = **2**. It is *always* 2. **Why?** Checking examples can't prove "always" — there are infinitely many cases. This chapter gives us the tool that can: **algebraic identities**. (The proof is in section 4.3.)

## 4.1 Identity versus equation

> [!IMPORTANT]
> **An IDENTITY is an equation that is true for EVERY value of its variables.**
> **An ordinary EQUATION is true only for some values.**
>
> - x² − 1 = 24 is true only for x = 5 or x = −5 → an **equation**.
> - (x + y)² = x² + 2xy + y² is true for all x and y → an **identity**.

**Why identities are useful:** they let you swap one form for another freely — expand a product, or squeeze a long expression back into factors — and they make mental arithmetic fast.

## 4.2 The square of a sum: (a + b)²

### The picture

**Take a square of side (a + b)** and cut each side into a piece a and a piece b:

```
          a          b
     ┌──────────┬──────┐
     │          │      │
   a │   a²     │  ab  │
     │          │      │
     ├──────────┼──────┤
   b │   ab     │  b²  │
     └──────────┴──────┘
```

**The whole square = one a² square + one b² square + two ab rectangles.**

> [!IMPORTANT]
> **(a + b)² = a² + 2ab + b²**

### Why it is true for ALL numbers, not just lengths

**The picture only works when a and b are lengths (positive).** Test negatives: a = −2, b = −3: (a + b)² = (−5)² = **25**, and a² + 2ab + b² = 4 + 12 + 9 = **25** ✓. Test fractions: a = −2/3, b = 3/4: a + b = 1/12, so (a + b)² = 1/144; a² + 2ab + b² = 4/9 − 1 + 9/16 = (64 − 144 + 81)/144 = **1/144** ✓.

**But testing never proves "every". The distributive law does:**

```
(a + b)² = (a + b)(a + b)
         = a(a + b) + b(a + b)        (distributive law)
         = a² + ab + ba + b²
         = a² + 2ab + b²              (ab = ba)
```

**This uses only rules that hold for all numbers**, so the identity holds for all numbers. ∎

### Is (a + b)² bigger than a² + b²?

**(a + b)² − (a² + b²) = 2ab.** So it all depends on the sign of **ab**:

| if | then |
|---|---|
| a and b have the **same sign** (ab > 0) | (a + b)² **>** a² + b² |
| a and b have **opposite signs** (ab < 0) | (a + b)² **<** a² + b² |
| a = 0 or b = 0 | they are **equal** |

e.g. a = 10, b = 2: 144 > 104 (the difference 40 is 2 × 10 × 2).

> [!WARNING]
> **The most common algebra mistake in the world: (a + b)² = a² + b². It is FALSE** (unless a or b is 0). You lose the 2ab — the two rectangles in the picture.

### Using it

**Expanding:** treat a and b as whole blocks. (5x + 2y)²: a = 5x, b = 2y →
(5x)² + 2(5x)(2y) + (2y)² = **25x² + 20xy + 4y²**.

**Mental squares:** 43² = (40 + 3)² = 1600 + 240 + 9 = **1849**.

**Exercise Set 4.1, worked:**

- (x + 1/x)-type terms: (1/x + 1/y)² = **1/x² + 2/(xy) + 1/y²** (the middle term is 2 × 1/x × 1/y)

## 4.3 Factorising with identities — reading them backwards

**An identity can be read right-to-left:** a² + 2ab + b² **=** (a + b)². So if an expression *looks like* a² + 2ab + b², it **is** a perfect square.

**How to spot it:** (1) are the first and last terms perfect squares? (2) is the middle term **twice the product** of their square roots?

- **x² + 4x + 4:** x² = (x)², 4 = 2², and 4x = 2(x)(2) ✓ → **(x + 2)²**.
- **36x² + 12x + 1:** (6x)², 1², 12x = 2(6x)(1) ✓ → **(6x + 1)²**.
- **50p² + 60pq + 18q²:** 50 isn't a square — but **take out the common factor 2 first**: 2(25p² + 30pq + 9q²) = 2[(5p)² + 2(5p)(3q) + (3q)²] = **2(5p + 3q)²**.

> [!TIP]
> **Always look for a common factor FIRST.** It often turns an ugly expression into a recognisable one.

### The square of a difference

**Replace b by −b in (a + b)²:** (a − b)² = a² + 2a(−b) + (−b)² →

> [!IMPORTANT]
> **(a − b)² = a² − 2ab + b²**
>
> **Why the last term is +b²:** (−b)² = (−b)(−b) = +b² — negative times negative.

**Picture:** in a square of side a, cut off a strip of width b along one side (area ab) and another along the adjacent side (area b(a − b)). What's left is the square (a − b)²:
(a − b)² = a² − ab − b(a − b) = a² − ab − ab + b² = **a² − 2ab + b²** ✓.

**Mental squares:** 29² = (30 − 1)² = 900 − 60 + 1 = **841**. 79² = (80 − 1)² = 6400 − 160 + 1 = **6241**. 193² = (200 − 7)² = 40000 − 2800 + 49 = **37249**. 299² = (300 − 1)² = **89401**.

### The opening puzzle, proved

**Three consecutive numbers: n − 1, n, n + 1.** Their squares: (n − 1)², n², (n + 1)².

```
(n − 1)² + (n + 1)² = (n² − 2n + 1) + (n² + 2n + 1) = 2n² + 2
subtract 2 × n²:     2n² + 2 − 2n² = 2
```

**The n's cancel completely, so the answer is 2 for EVERY n.** ∎ That's the power of an identity: one calculation covers infinitely many cases.

**Exercise Set 4.2, worked:**

- 9x² + 24xy + 16y² = (3x)² + 2(3x)(4y) + (4y)² = **(3x + 4y)²**
- 4s² + 20st + 25t² = **(2s + 5t)²**
- 49x² + 28xy + 4y² = **(7x + 2y)²**

## 4.4 More identities

### (a + b + c)²

**Trick: treat (b + c) as one block d.** (a + d)² = a² + 2ad + d² = a² + 2a(b + c) + (b + c)² = a² + 2ab + 2ac + b² + 2bc + c².

> [!IMPORTANT]
> **(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca**
>
> **Every square once, every pair twice.** In the picture, a square of side a + b + c splits into 3 squares (a², b², c²) and 6 rectangles (two each of ab, bc, ca).

**Worked:** 119² = (100 + 10 + 9)² = 10000 + 100 + 81 + 2000 + 1800 + 180 = **14161**.

**Exercise Set 4.3, worked:**

- 117² = (100 + 17)² = 10000 + 3400 + 289 = **13689**; 78² = (80 − 2)² = **6084**; 198² = (200 − 2)² = **39204**; 214² = (200 + 14)² = **45796**; 1104² = (1100 + 4)² = **1218816**; 1120² = (1100 + 20)² = **1254400**.
- 16y² − 24y + 9 = **(4y − 3)²**.
- (p + 3q + 7r)² = **p² + 9q² + 49r² + 6pq + 42qr + 14pr**.
- (3x − 2y + 4z)² = **9x² + 4y² + 16z² − 12xy − 16yz + 24xz** (treat −2y as the "b": its square is +4y², its products carry a minus).
- **Is (a + b − c)² + (a − b + c)² + (a − b − c)² = 2a² + 2b² + 2c²?** Test a = 1, b = c = 0: left = 1 + 1 + 1 = 3, right = 2. **Not an identity.** (Expanded, the left is 3a² + 3b² + 3c² − 2ab − 2bc − 2ca.)

> [!TIP]
> **One counter-example kills a claimed identity.** To *prove* an identity you need algebra; to *disprove* it, one set of numbers is enough.

### Difference of squares, and Śhrīdhara's squaring trick

> [!IMPORTANT]
> **a² − b² = (a + b)(a − b)**
>
> **Why:** (a + b)(a − b) = a² − ab + ba − b² = a² − b² — the middle terms cancel.

**Śhrīdharāchārya (750 CE)** rewrote it as **a² = (a + b)(a − b) + b²** to square numbers quickly — choose b to make a + b and a − b easy:

```
55² = (55 + 5)(55 − 5) + 5² = 60 × 50 + 25 = 3025
35² = 40 × 30 + 25 = 1225
65² = 70 × 60 + 25 = 4225
85² = 90 × 80 + 25 = 7225
105² = 110 × 100 + 25 = 11025
```

**Pattern:** a number ending in 5, say "n5", has square **n × (n + 1) followed by 25**. (Because (10n + 5)² = 100n² + 100n + 25 = 100n(n + 1) + 25.)

**Products near a middle number:** 23 × 17 = (20 + 3)(20 − 3) = 400 − 9 = **391**; 104 × 96 = 10000 − 16 = **9984**.

## 4.5 Algebra tiles and splitting the middle term

**Tiles:** a big square of area **x²**, a long strip of area **x** (x by 1), and a small unit square of area **1**.

**(x + 3)(x + 4)** as a rectangle: one x² tile, 3 strips on one side, 4 strips on the other, and a 3 × 4 block of 12 unit squares:

```
(x + 3)(x + 4) = x² + 3x + 4x + 12 = x² + 7x + 12
```

**Read backwards, the rectangle FACTORISES x² + 7x + 12 into (x + 3)(x + 4).** The key move was **splitting 7x into 3x + 4x**. Splitting it as 2x + 5x fails: the corner would then be a 2 × 5 block, which holds 10 unit tiles — but we have 12. The split must make the corner hold **exactly** the constant.

> [!IMPORTANT]
> **(x + a)(x + b) = x² + (a + b)x + ab**
>
> **To factorise x² + Bx + C: find two numbers that ADD to B and MULTIPLY to C.**
>
> **Why:** compare x² + Bx + C with x² + (a + b)x + ab. The x-terms must match (a + b = B) and the constants must match (ab = C).

**Worked:**

- **x² + 11x + 30:** pairs multiplying to 30: (1, 30), (2, 15), (3, 10), (5, 6). Which add to 11? **5 and 6** → **(x + 5)(x + 6)**.
- **x² − 5x + 6:** add to −5, multiply to +6 → **−2 and −3** → **(x − 2)(x − 3)**.
- **r² − r − 42:** add to −1, multiply to −42 → **−7 and 6** → **(r − 7)(r + 6)**.

> [!TIP]
> **Signs guide the search.** Constant **positive** → both numbers have the **same** sign (the sign of the middle term). Constant **negative** → **opposite** signs, and the bigger one takes the middle term's sign.

**With a number in front of x²:** (px + a)(qx + b) = **pq x² + (pb + qa)x + ab**. So for 10x² − 11x − 6 = (2x − 3)(5x + 2): check pq = 10, pb + qa = 2(2) + 5(−3) = 4 − 15 = −11 ✓, ab = −6 ✓.

**Exercise Set 4.4, worked:**

- s² − 11s + 24 = **(s − 3)(s − 8)** (−3 + −8 = −11, (−3)(−8) = 24)
- 3x² − 4x − 7 = **(3x − 7)(x + 1)**
- 10x² − 11x − 6 = **(2x − 3)(5x + 2)**
- 6x² + 7x + 2 = **(2x + 1)(3x + 2)**
- 41² = **1681**; 27² = **729**; 23 × 17 = **391**; 135² = **18225**; 97² = **9409**; 18 × 29 = **522**; 34 × 43 = **1462**; 205² = **42025**
- 9a² + b² + 4c² − 6ab + 12ac − 4bc = **(3a − b + 2c)²**
- 16s² + 25t² − 40st = **(4s − 5t)²**
- 49g² + 14gh + h² = **(7g + h)²**
- 64u² + 121v² + 4w² − 176uv − 32uw + 44vw = **(8u − 11v − 2w)²**

**James and Reshma** both expand (a − b)²(a + b) differently — **both are right**: identities can be combined in any order, and they'll reach the same a³ − a²b − ab² + b³.

## 4.6 Cubes

**(a + b)³ = (a + b)(a + b)² = (a + b)(a² + 2ab + b²)** — multiply out:

```
a(a² + 2ab + b²) = a³ + 2a²b + ab²
b(a² + 2ab + b²) =       a²b + 2ab² + b³
total            = a³ + 3a²b + 3ab² + b³
```

> [!IMPORTANT]
> **(a + b)³ = a³ + 3a²b + 3ab² + b³**
> **(a − b)³ = a³ − 3a²b + 3ab² − b³** (replace b by −b; signs alternate)
>
> **The cube picture:** a cube of edge a + b splits into **2 cubes** (a³ and b³) and **6 cuboids** — three of size a × a × b and three of size a × b × b. Total 1 + 3 + 3 + 1 = 8 pieces, matching the coefficients.

**Reading backwards:**

- p³ + 6p²q + 12pq² + 8q³ = p³ + 3(p²)(2q) + 3(p)(2q)² + (2q)³ = **(p + 2q)³** — so a cube of this volume has side **p + 2q**.
- 8n³ − 60n²m + 150nm² − 125m³ = **(2n − 5m)³**.

**Mental cubes:** 199³ = (200 − 1)³ = 8000000 − 120000 + 600 − 1 = **7880599**. 147³ = (150 − 3)³ = 3375000 − 202500 + 4050 − 27 = **3176523**.

### Sum and difference of cubes

> [!IMPORTANT]
> **x³ − y³ = (x − y)(x² + xy + y²)**
> **x³ + y³ = (x + y)(x² − xy + y²)**
>
> **Why:** multiply out (x − y)(x² + xy + y²) = x³ + x²y + xy² − x²y − xy² − y³. All the middle terms cancel in pairs, leaving x³ − y³.

**Notice:** (x − y) divides x² − y², x³ − y³, and x⁴ − y⁴ = (x² − y²)(x² + y²) — and in fact every xⁿ − yⁿ.

### The three-cube identity

> [!IMPORTANT]
> **x³ + y³ + z³ − 3xyz = (x + y + z)(x² + y² + z² − xy − yz − zx)**
>
> **Big consequence:** if **x + y + z = 0**, the right side is 0, so **x³ + y³ + z³ = 3xyz**.

**Book example 15:** x + y + z = 10, xyz = 25, x² + y² + z² = 38. Find x³ + y³ + z³.

1. From (x + y + z)² = x² + y² + z² + 2(xy + yz + zx): 100 = 38 + 2(xy + yz + zx) → **xy + yz + zx = 31**.
2. Three-cube identity: x³ + y³ + z³ − 3(25) = 10 × (38 − 31) = 70.
3. **x³ + y³ + z³ = 70 + 75 = 145.**

## 4.7 Simplifying rational expressions

**A fraction with polynomials on top and bottom simplifies exactly like 12/18 = 2/3: factorise both, cancel common factors.**

**Book example 16:** (x² − 7x + 12) ÷ (5x² + 5x − 100).

- Top: add to −7, multiply to 12 → −3, −4 → **(x − 3)(x − 4)**.
- Bottom: 5(x² + x − 20) → add to 1, multiply to −20 → 5, −4 → **5(x + 5)(x − 4)**.
- Cancel (x − 4): **(x − 3) / [5(x + 5)]**.

> [!WARNING]
> **You may cancel only FACTORS (things multiplied), never TERMS (things added).** (x + 3)/(x + 5) does **not** simplify to 3/5. And you can cancel (x − 4) only because the question says the denominator isn't 0 — dividing by a zero factor is never allowed.

**Exercise Set 4.5, worked:**

- (n³ − 3n²m + 3nm² − m³) / (5m² − 10mn + 5n²) = (n − m)³ / [5(n − m)²] = **(n − m)/5**
- (4y² − 20yz + 25z²) / (25z² − 4y²) = (2y − 5z)² / [(5z − 2y)(5z + 2y)] = **(5z − 2y)/(5z + 2y)** (note 2y − 5z = −(5z − 2y))
- (x² + x − 6)(x² − 7x + 12) / [(x² − 6x + 8)(x² − 9)] = (x + 3)(x − 2)(x − 3)(x − 4) / [(x − 2)(x − 4)(x − 3)(x + 3)] = **1**
- (p⁴ − 16) / (p² − 4p + 4) = (p − 2)(p + 2)(p² + 4) / (p − 2)² = **(p + 2)(p² + 4)/(p − 2)**

### Word problems

**Saira's tiles:** 1 square x², 8 strips x, 15 unit squares → area x² + 8x + 15 = **(x + 3)(x + 5)**: a rectangle **(x + 5) by (x + 3)**.

**The pool:** breadth is 4 m less than length; area 96 m². Let length = x: x(x − 4) = 96 → x² − 4x − 96 = 0. Numbers adding to −4 and multiplying to −96: **−12 and 8** → (x − 12)(x + 8) = 0.

> [!IMPORTANT]
> **If a product is 0, one of the factors must be 0.** So x = 12 or x = −8. A length can't be negative → **length 12 m, breadth 8 m**. (Check: 12 × 8 = 96 ✓.)

## In a nutshell

| Identity | Remember it as |
|---|---|
| (a + b)² = a² + 2ab + b² | square, twice the product, square |
| (a − b)² = a² − 2ab + b² | same, middle term negative |
| a² − b² = (a + b)(a − b) | middle terms cancel |
| (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca | every square once, every pair twice |
| (x + a)(x + b) = x² + (a + b)x + ab | add for the middle, multiply for the end |
| (a ± b)³ = a³ ± 3a²b + 3ab² ± b³ | 1, 3, 3, 1; signs alternate for − |
| x³ ± y³ = (x ± y)(x² ∓ xy + y²) | |
| x³ + y³ + z³ − 3xyz = (x + y + z)(x² + y² + z² − xy − yz − zx) | if x + y + z = 0, sum of cubes = 3xyz |

- **Identity** = true for all values; prove with the distributive law, disprove with one counter-example.
- **Factorising** = reading identities backwards; take out common factors first.
- **Rational expressions:** factorise top and bottom, cancel common **factors** (never terms).
- **Product = 0 ⇒ a factor = 0**; reject answers that make no sense (negative lengths).

> [!WARNING]
> **Top traps:** (a + b)² ≠ a² + b² — don't drop 2ab · (−b)² = +b² · in (3x)² square the 3 too: 9x² · in (a − b)³ the signs **alternate** + − + − · x³ + y³ ≠ (x + y)³ · cancel factors, not terms · take out a common factor before hunting for a square · when splitting the middle term, the two numbers must **add** to the middle coefficient **and multiply** to the constant (times the x² coefficient) · a negative root can be a correct solution of the equation but a wrong answer to a length question.
