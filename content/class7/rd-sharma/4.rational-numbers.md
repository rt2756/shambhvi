# 4. Rational Numbers

## What a rational number is

**Example:** −3/4, 5/2, 7 (= 7/1), 0 (= 0/5), −2 (= −2/1).

- A **rational number** is any number you can write as **p/q**, where p and q are integers and **q ≠ 0**.
- So every integer and every fraction is rational — rationals are fractions that are allowed to be negative.

**Why q ≠ 0:** p/q means p ÷ q, and dividing by 0 has no answer (see Integers).

| Number | Natural | Whole | Integer | Rational |
|---|---|---|---|---|
| 5 | ✓ | ✓ | ✓ | ✓ |
| 0 | ✗ | ✓ | ✓ | ✓ |
| −4 | ✗ | ✗ | ✓ | ✓ |
| −2/3 | ✗ | ✗ | ✗ | ✓ |

## Positive and negative

- **Positive:** top and bottom have the **same** sign: 3/5, (−3)/(−5).
- **Negative:** **different** signs: −3/5, 3/(−5).
- **0** is neither.
- (−3)/(−5) = 3/5, and 3/(−5) = −3/5. **Why:** these are divisions, and the integer sign rules apply.

## Standard form

A rational number is in **standard form** when the **denominator is positive** and top and bottom have **no common factor** except 1.

**Example:** 18/(−24) → move the sign to the top: −18/24 → divide by HCF 6 → **−3/4**.

**Why bother:** it gives every rational number one "official" spelling, so you can tell at a glance whether two are equal.

## Equivalent rational numbers

- Multiply or divide top and bottom by the **same non-zero integer**: −2/3 = −4/6 = −6/9 = 8/(−12).
- **Test:** a/b = c/d exactly when **a × d = b × c**. −2/3 and 8/(−12): (−2)(−12) = 24 and 3 × 8 = 24 ✓.

**Why it works:** multiplying top and bottom by k is multiplying by k/k = 1, which doesn't change the value.

## On the number line

**Example:** to mark −5/3, write it as −1 ⅔. Go to −1, split the gap from −1 to −2 into 3 equal parts, take 2 of them to the left.

- Positives go right of 0, negatives go left, just like integers.

## Comparing

- **Rule:** write both in standard form, make the denominators equal, then compare the tops.
  - −2/3 vs −3/4 → −8/12 vs −9/12 → −8 > −9, so **−2/3 > −3/4**.
- Any positive > 0 > any negative.

> [!WARNING]
> With negatives the order flips: 3/4 > 2/3 but **−3/4 < −2/3**. Further from 0 on the left = smaller.

## Rational numbers between two rationals

- Between any two rationals there are **infinitely many** others.
- **Method 1 (equal denominators):** between 1/3 and 1/2 → 2/6 and 3/6 → make them 20/60 and 30/60 → 21/60, 22/60, … 29/60.
- **Method 2 (average):** the number halfway between a and b is (a + b)/2. Between 1/3 and 1/2: (1/3 + 1/2) ÷ 2 = 5/6 ÷ 2 = **5/12**.

**Why there are infinitely many:** you can always cut the gap finer — tenths, hundredths, thousandths — and there is always a new number in the middle.

## Quick practice

1. Is 0 a rational number? Why?
2. Write 36/(−48) in standard form.
3. Are −3/7 and 9/(−21) equivalent?
4. Which is greater: −5/6 or −7/9?
5. Write −4/5 with denominator 35.
6. Find 3 rational numbers between −1 and 0.
7. Find the rational number exactly halfway between 1/4 and 3/4.

4. −15/18 vs −14/18 → **−7/9** is greater
