## The one law behind the whole chapter

**Distributive property:** `a(b + c) = ab + ac`

**Why it works — count a rectangle two ways.** Put `a` rows of dots, with `b` dots then `c` more dots in each row.

```
      b columns      c columns
     .....          ......
a    .....   ab     ......   ac
     .....          ......
```

Count by whole rows: `a × (b + c)`. Count by blocks: `ab + ac`. **Same dots, so the same number.**

> [!TIP]
> We write `a(b + c)` for `a × (b + c)` — the `×` is dropped next to brackets, exactly like `5a` and `xy`.

Combined with commutativity, it also runs the other way: `(a + b)c = ac + bc`.

## How a product changes when the numbers change

Take `23 × 27`.

| Change | New product | Increase |
|---|---|---|
| second number +1 | `23(27 + 1) = 23×27 + 23` | **+23** (= the other number) |
| first number +1 | `(23+1)27 = 23×27 + 27` | **+27** |
| both +1 | `(23+1)(27+1) = 23×27 + (23 + 27 + 1)` | **+51** |
| one +1, one −1 | `(23+1)(27−1) = 23×27 + 27 − 23 − 1` | **+3** |

**In general:** `a(b + 1) = ab + a` — increasing one factor by 1 adds **the other factor**.

**Why:** one extra column of a rectangle is one extra column of `a` dots.

### The master identity

**Identity 1:  `(a + m)(b + n) = ab + mb + an + mn`**

**Why it works:** apply distributivity twice.

```
(a + m)(b + n) = (a + m)b + (a + m)n
               = ab + mb + an + mn
```

**In words: multiply every term of the first bracket by every term of the second, then add.**

Picture it as a rectangle of side `(a + m)` by `(b + n)` cut into four blocks: `ab`, `an`, `mb`, `mn`.

> [!IMPORTANT]
> **Subtraction is not a separate case.** Write `(a + 1)(b − 1)` as `(a + 1)(b + (−1))` and use m = 1, n = −1:
>
> `ab + 1·b + a·(−1) + 1·(−1) = ab + b − a − 1` ✓
>
> The **integer sign rules** handle everything, so **one identity covers all four sign combinations**:
>
> - `(a − u)(b + v) = ab − ub + av − uv`
> - `(a − u)(b − v) = ab − ub − av + uv`

**When does the product stay the SAME?** `(a + 2)(b − 4) = ab` needs `−4a + 2b − 8 = 0`, i.e. **b = 2a + 4**. So `(1, 6)`, `(2, 8)`, `(3, 10)` all work: `1×6 = 3×2 = 6` ✓

### Identities

**An identity is an equation true for every value of its letters** — like `a(b + 8) = ab + 8a`.

Contrast an **equation** like `2x = 6`, which is true only for x = 3.

## More than two terms

Distributivity doesn't stop at two terms in a bracket.

**Example:** `(3a/2)(a − b + 1/5)`

```
= (3a/2 × a) − (3a/2 × b) + (3a/2 × 1/5)
= (3/2)a² − (3/2)ab + (3/10)a
```

No two terms have the **same letters**, so nothing can be combined further.

> [!TIP]
> **Like terms** have exactly the same letters with the same powers. `a²b` and `2a²b` combine into `3a²b`; `a²b` and `ab²` do **not** — different letters, different meaning.

**Example:** `(a + b)(a² + 2ab + b²) = a³ + 3a²b + 3ab² + b³`

## Fast multiplication using the law

### × 11

`3874 × 11 = 3874(10 + 1) = 38740 + 3874`

Written as a column sum:

```
  d    c    b    a    0
+      d    c    b    a
─────────────────────────
  d  (c+d) (b+c) (a+b)  a
```

**The rule: copy the last digit, then add each pair of neighbouring digits, then copy the first digit — carrying as you go.**

`3874 × 11`: last digit **4**; `7+4=11` → write 1 carry 1; `8+7+1=16` → write 6 carry 1; `3+8+1=12` → write 2 carry 1; first digit `3+1=4`. → **42614** ✓

### × 101, × 1001

`dcba × 101 = dcba × 100 + dcba`, so digits **two apart** get added:

```
  d    c    b    a    0    0
+            d    c    b    a
─────────────────────────────
  d    c  (b+d) (a+c)  b    a
```

Same idea for 1001 (three apart), 10001 (four apart).

### × 99, × 999

`9734 × 99 = 9734(100 − 1) = 973400 − 9734 =` **963666**

> [!NOTE]
> **Brahmagupta** (628 CE) gave the first explicit statement of the distributive law in the *Brahmasphuṭasiddhānta*, calling it **khaṇḍa-guṇanam** — "multiplication by parts": *break the multiplier into parts, multiply each, and add*. The fast-multiplication tricks he called **iṣṭa-guṇana**, and they were developed further by Sridharacharya (750 CE) and Bhaskaracharya (*Lilavati*, 1150 CE).

## The three identities you must know

### Identity 1A — `(a + b)² = a² + 2ab + b²`

**Why (picture):** a square of side `a + b` splits into a square `a²`, a square `b²`, and **two** rectangles each `a × b`.

```
        a       b
    ┌───────┬──────┐
  a │  a²   │  ab  │
    ├───────┼──────┤
  b │  ab   │  b²  │
    └───────┴──────┘
```

**Worked:** `65² = (60 + 5)² = 3600 + 2(300) + 25 =` **4225**
**Worked:** `104² = (100 + 4)² = 10000 + 800 + 16 =` **10816**

> [!WARNING]
> **`(a + b)² is NOT a² + b².`** The two `ab` rectangles are real area — forgetting them is the single most common algebra mistake there is. Check with numbers: `(3+4)² = 49`, but `3² + 4² = 25`.

### Identity 1B — `(a − b)² = a² − 2ab + b²`

**Why (picture):** to get the small square of side 55 inside a square of side 60, cut off **two** 60 × 5 strips. But those strips **overlap** in a 5 × 5 corner, which has been removed twice — so add it back once.

`55² = 60² − (60×5) − (5×60) + 5² = 3600 − 300 − 300 + 25 =` **3025** ✓

**Or derive it from 1A:** `(a − b)² = (a + (−b))² = a² + 2a(−b) + (−b)² = a² − 2ab + b²`.

**Worked:** `99² = (100 − 1)² = 10000 − 200 + 1 =` **9801**
**Worked:** `58² = (60 − 2)² = 3600 − 240 + 4 =` **3364**

### Identity 1C — `(a + b)(a − b) = a² − b²`

**Why:** expand — `a² − ab + ba − b²`, and the two middle terms **cancel**.

**Why (picture):** cut a `b × (a − b)` strip off an `a² − b²` L-shape and slide it round; the L becomes a rectangle `(a + b)` by `(a − b)`.

**Worked:** `98 × 102 = (100 − 2)(100 + 2) = 10000 − 4 =` **9996**
**Worked:** `45 × 55 = (50 − 5)(50 + 5) = 2500 − 25 =` **2475**

> [!TIP]
> **Sridharacharya's squaring trick** rearranges 1C into
>
> `a² = (a + b)(a − b) + b²`
>
> Pick b to make one factor a round number.
> `31² = 32 × 30 + 1² = 960 + 1 =` **961**
> `197² = 200 × 194 + 3² = 38800 + 9 =` **38809**

### The pattern that keeps going

```
(a − b)(a + b)                    = a² − b²
(a − b)(a² + ab + b²)             = a³ − b³
(a − b)(a³ + a²b + ab² + b³)      = a⁴ − b⁴
```

**Why it always works:** in each product every middle term appears twice, once `+` and once `−`, so everything **telescopes away** except `aⁿ` and `−bⁿ`.

## Two number patterns explained by the identities

**Pattern 1:** `2(2² + 1²) = 3² + 1²`, `2(6² + 5²) = 11² + 1²`

**Why:** add identities 1A and 1B —

`(a + b)² + (a − b)² = (a² + 2ab + b²) + (a² − 2ab + b²) = 2(a² + b²)`

The `2ab` terms cancel. So **twice a sum of two squares is always a sum of two squares** — namely `(a+b)²` and `(a−b)²`.

**Pattern 2:** `9×9 − 1×1 = 10 × 8`, `8×8 − 6×6 = 14 × 2`

**Why:** that's just Identity 1C read backwards — `a² − b² = (a + b)(a − b)`.

> [!TIP]
> **Do these hold for negatives and fractions?** Yes. The identities were proved using only distributivity and sign rules, which hold for **all** rational numbers — so the patterns come along automatically.

## Mind the mistake

| Wrong working | What went wrong | Correct |
|---|---|---|
| `−3p(−5p + 2q) = −3p + 5p − 2q` | the −3p wasn't **multiplied**, only copied | `15p² − 6pq` |
| `2(x − 1) + 3(x + 4) = 2x − 1 + 3x + 4` | the 2 and 3 didn't reach the second term | `2x − 2 + 3x + 12 = 5x + 10` |
| `y + 2(y + 2) = (y + 2)²` | `y + 2(…)` is not `(y+2)(…)` | `y + 2y + 4 = 3y + 4` |
| `(5m + 6n)² = 25m² + 36n²` | the **2ab** term is missing | `25m² + 60mn + 36n²` |
| `3a(2b × 3c) = 6ab × 9ac` | 3a was distributed over a **product** | `3a × 6bc = 18abc` |
| `5w² + 6w = 11w²` | `w²` and `w` are **not like terms** | `5w² + 6w` (already simplest) |
| `(a + 2)(b + 4) = ab + 8` | only the first and last terms multiplied | `ab + 4a + 2b + 8` |

> [!WARNING]
> **Distributivity works over ADDITION, not over multiplication.** `3a(2b + 3c) = 6ab + 9ac` ✓ but `3a(2b × 3c) = 18abc` — you multiply once, not twice.

## One pattern, many expressions

A dot pattern gives step-k counts `(k+1)² − 1`, `k² + 2k`, `k(k+1) + k`, `k(k+2)` depending on how you slice the picture.

Expanding each:

```
(k+1)² − 1 = k² + 2k + 1 − 1 = k² + 2k
k(k+1) + k = k² + k + k     = k² + 2k
k(k+2)     = k² + 2k
```

**All four are the same expression.** They *had* to be — they count the same dots.

> [!TIP]
> **This is a genuinely useful check.** If two people slice a picture differently and their algebra disagrees, one of them made an arithmetic slip. Expanding is the referee.

**Area example:** a square of side `(m + n)` with four `m × n` rectangles round a hole.
Tadang: `(m + n)² − 4mn`. Yusuf: the hole is a square of side `(n − m)`, so `(n − m)²`.
Check: `(m+n)² − 4mn = m² + 2mn + n² − 4mn = m² − 2mn + n² = (n − m)²` ✓

## Handy consequences

- **Calendar 2×2 block:** label it `a`, `a+1`, `a+7`, `a+8`. The diagonal products differ by
  `a(a+8) − (a+1)(a+7) = a² + 8a − (a² + 8a + 7) =` **−7**, always. The **falling** diagonal product is 7 less.
- **Squares of even numbers are multiples of 4:** `(2n)² = 4n²` ✓
- **Squares of odd numbers are 1 more than a multiple of 8:** `(2n+1)² = 4n² + 4n + 1 = 4n(n+1) + 1`, and `n(n+1)` is always even, so `4n(n+1)` is a multiple of **8** ✓
- **Three consecutive numbers:** middle² minus the product of the outer two is `n² − (n−1)(n+1) = n² − (n² − 1) =` **1**, always.
- **Which is bigger, 14 × 26 or 16 × 24?** Both have sum 40. Write them as `(20−6)(20+6) = 400 − 36 = 364` and `(20−4)(20+4) = 400 − 16 =` **384**. **The closer the two factors, the bigger the product** — because you subtract a smaller square.
- **Remainders multiply too:** if `M = 7p + 3` and `N = 7q + 5`, then `MN = 49pq + 35p + 21q + 15 = 7(…) + 15`, so the remainder is `15 − 14 =` **1**.
