# ➗ Fractions & decimals

## Fractions

- Think of fractions as a **same-size pizza** cut into equal slices.
- A fraction shows **part of a whole**: `3/4` means 3 slices when 1 pizza is cut into 4 equal slices.
- **Numerator** = top number; it tells how many pizza slices we have.
- **Denominator** = bottom number; it tells how many equal slices make 1 whole pizza.
- **Fraction bar means division:** `6/2` means `6 ÷ 2`, so it equals 3.
- **"of" means multiplication:** `1/2 of 10 pizza slices = 1/2 × 10 = 10/2 = 5 slices`.

> [!WARNING]
> A fraction only works when the pizza is cut into **equal** slices. Unequal slices cannot be counted fairly.

## Types of fractions

- **Proper fraction:** numerator < denominator, so the value is between 0 and 1 pizza (`3/4`, `4/7`).
- **Improper fraction:** numerator > denominator, so the value is more than 1 pizza (`9/4`, `7/6`). 
- **Mixed fraction:** a whole number plus a fraction (`2 1/4`). It is another way to write an improper fraction (`9/4 = 2 1/4`).
- **Like fractions:** same denominator, so the pizzas are cut into the same number of equal slices (`2/7`, `5/7`).
- **Unlike fractions:** different denominators, so the pizzas are cut into different slice sizes (`2/7`, `3/6`).
- **Equivalent fractions:** fractions that look different but have the same value. (`1/2 = 2/4 = 3/6`, all show half a pizza).

## Converting between fractions

- **Improper -> mixed:** divide, then write `Q R/D` (**Quotient Remainder / Divisor**). Example: `11/4` pizza slices = 11 ÷ 4 = 2 remainder 3, so `11/4 = 2 3/4`.
- **Mixed -> improper:** multiply, then write `(whole × denominator + numerator) / denominator`. Example: `2 3/4 = (2 × 4 + 3) / 4 = 11/4`.

## Comparing fractions

- **Like fractions:** compare numerators because the slice size is the same (`5/9 > 3/9`).
- **Unlike fractions:** first make the denominators the same, then compare numerators.
  - Example: compare `2/3` pizza and `3/4` pizza. LCM of 3 and 4 is 12, so `2/3 = 8/12` and `3/4 = 9/12`. Now compare 8 and 9, so `2/3 < 3/4`.

## Addition & subtraction of fractions

- **Like fractions:** add or subtract only the numerators; keep the denominator the same. Example: `3/4 + 2/4 = 5/4 = 1 1/4` pizzas.
- **Unlike fractions:** first make the denominators the same, then add or subtract numerators.
  - Example: `1/4 + 1/6`. LCM of 4 and 6 is 12, so `1/4 = 3/12` and `1/6 = 2/12`. Therefore `1/4 + 1/6 = 5/12` pizza.
- Subtraction works the same way: make denominators the same first, then subtract numerators.

## Fraction and decimal conversions

- **Proper fraction -> decimal:** just divide numerator by denominator (`3/4` pizza = 0.75 pizza, `1/5` pizza = 0.2 pizza).
- **Improper fraction -> decimal:** write the improper fraction as a mixed fraction, divide the fraction part, then add it to the whole part (`9/4 = 2 1/4 = 2 + 1/4 = 2 + 0.25 = 2.25` pizzas).
- **Decimal -> fraction:** count the digits after the decimal; use that many zeroes in the denominator. Example: `0.75 = 75/100`, and `0.5643 = 5643/10000`.

## Simplest form of fractions

- If the numerator and denominator can be divided by the same number, divide both by that number.
- `75/100 = 3/4` pizza, because numerator and denominator are divided by 25.
- `12/100 = 3/25` pizza, because numerator and denominator are divided by 4.
- `6/12 = 1/2` pizza.

## Multiplication of fractions

- Multiply numerator × numerator.
- Multiply denominator × denominator.
- Example: `2/3 × 4/5 = (2 × 4) / (3 × 5) = 8/15` pizza.

## Division of fractions

- Divide by multiplying by the **reciprocal** of the divisor.
- **Keep-Change-Flip:** keep the first fraction, change `÷` to `×`, then flip the second fraction.
- Example: `2/3 ÷ 4/5 = 2/3 × 5/4 = 10/12 = 5/6` pizza.
- Example: `2/7 ÷ 8/10 = 2/7 × 10/8 = 20/56 = 5/14` pizza.

> [!TIP]
> After any fraction answer, check if it can be simplified.

> [!WARNING]
> Add or subtract pizza fractions only after the denominators match (`1/2 + 1/3 ≠ 2/5`). 
>
> For division, flip only the **second** fraction.

## Decimals & money

- The point splits whole and part: 4.73 = 4 + 7/10 + 3/100 (tenths, hundredths, thousandths).
- **Compare:** line up the point and compare place by place; 0.5 = 0.50.
- **Add / subtract:** line up the decimal points.
- **Fraction ↔ decimal:** divide to turn a pizza fraction into a decimal (`3/4 = 0.75`); write decimal digits over their place value to turn a decimal back into a fraction (`0.25 = 25/100 = 1/4`).
- **Money:** 100 paise = ₹1; write amounts with 2 decimal places (₹12.50).

> [!WARNING]
> 0.5 > 0.45 (line up the point, don't count digits) · keep 2 places after the point for paise.
