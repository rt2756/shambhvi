## What mathematics is

> **Mathematics is, in large part, the search for patterns — and for the explanations as to *why* those patterns exist.**

Finding a pattern is only half the job. **The explanation matters as much as the pattern**, because an explanation can be reused far beyond where it was found: patterns in the motion of stars led to the theory of gravitation, and so to satellites and rockets; patterns in genomes led to diagnosing and curing diseases.

- Patterns in **whole numbers** are studied by **number theory**.
- Patterns in **shapes** are studied by **geometry**.

## Key number sequences

| Sequence | Numbers | Rule |
|---|---|---|
| **All 1's** | 1, 1, 1, 1, … | always 1 |
| **Counting numbers** | 1, 2, 3, 4, … | add 1 |
| **Odd numbers** | 1, 3, 5, 7, 9, … | add 2, starting at 1 |
| **Even numbers** | 2, 4, 6, 8, 10, … | add 2, starting at 2 |
| **Triangular numbers** | 1, 3, 6, 10, 15, 21, 28, … | add 2, then 3, then 4, … |
| **Squares** | 1, 4, 9, 16, 25, 36, 49, … | `n × n` |
| **Cubes** | 1, 8, 27, 64, 125, 216, … | `n × n × n` |
| **Virahānka numbers** | 1, 2, 3, 5, 8, 13, 21, … | **add the previous two** |
| **Powers of 2** | 1, 2, 4, 8, 16, 32, 64, … | double each time |
| **Powers of 3** | 1, 3, 9, 27, 81, 243, … | triple each time |

**Why the names:** the sequences are named after the **shape their dots make**.
- **Triangular** numbers: 1, 3, 6, 10 dots arrange into a **triangle**.
- **Squares:** 4, 9, 16 dots arrange into a **square grid**.
- **Cubes:** 8, 27, 64 dots stack into a **cube**.

> [!TIP]
> **36 is both triangular AND square** — 36 dots make a perfect triangle *and* a perfect square. The same number can play different roles depending on the picture you draw of it.

## Relations between sequences — and the pictures that explain them

### Adding odd numbers gives squares

```
1                    = 1
1 + 3                = 4
1 + 3 + 5            = 9
1 + 3 + 5 + 7        = 16
1 + 3 + 5 + 7 + 9    = 25
```

**Why it works:** take a square grid of dots. Peel it apart into **L-shaped layers** — the corner dot (1), then the L around it (3), then the next L (5), then 7, and so on. Each L is the next odd number, and together they rebuild the whole square.

Because you can draw that picture for a square of **any** size, the pattern holds **forever**.

- Sum of the first **10** odd numbers = `10 × 10 = ` **100**.
- Sum of the first **100** odd numbers = **10,000**.

### Adding up and down also gives squares

```
1                        = 1
1 + 2 + 1                = 4
1 + 2 + 3 + 2 + 1        = 9
1 + 2 + 3 + 4 + 3 + 2 + 1 = 16
```

**Why:** picture the square tilted as a diamond and count the **diagonals** — they hold 1, 2, 3, …, n, …, 3, 2, 1 dots. So `1 + 2 + … + 100 + … + 2 + 1 = ` **10,000**.

### More relations

| Do this | You get | Why |
|---|---|---|
| Add up **All 1's** | **counting numbers** | one more 1 each time |
| Add up **counting numbers** | **triangular numbers** | each new row adds the next counting number to the triangle |
| Add **consecutive triangular numbers** | **squares** | two triangles slot together into a square |
| Add up **powers of 2** (1, 1+2, 1+2+4, …) | 1, 3, 7, 15, … — **one less than the next power of 2** | doubling always overshoots the running total by exactly 1 |
| **Triangular × 6 + 1** | **hexagonal** numbers 1, 7, 19, 37 | six triangles around a central dot |
| Add up **hexagonal numbers** | **cubes** 1, 8, 27, 64 | the hexagonal layers stack into a cube |

## Shape sequences

| Sequence | Related number sequence |
|---|---|
| **Regular polygons** (triangle, quadrilateral, pentagon…) | **counting numbers from 3** — 3, 4, 5, 6, … |
| **Complete graphs** K2, K3, K4, … | **triangular numbers** — 1, 3, 6, 10 lines |
| **Stacked squares** | **squares** — 1, 4, 9, 16 |
| **Stacked triangles** | **squares** — 1, 4, 9, 16 |
| **Koch snowflake** | 3, 12, 48, … = **3 × powers of 4** |

- **Regular** means **all sides equal and all angles equal**.
- A regular polygon has **as many corners as sides** — every side ends at a corner where the next begins.
- **Stacked triangles give squares** because the rows contain **1, 3, 5, 7, …** little triangles — the odd numbers again, which we already know add up to squares.
- **Koch snowflake:** each step replaces every line segment `—` with a "speed bump", turning 1 segment into 4 — so the count multiplies by 4 each time.
