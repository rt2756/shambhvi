# 🟪 Squares (1 to 20)

The **square** of a number is that number **times itself**: `n² = n × n`. It's called a
"square" because `n × n` is exactly how many small boxes fit in an **n-by-n square** — for
example `4² = 16` fills a 4×4 grid.

| n | n² = n × n |
|---|---|
| 1 | 1 |
| 2 | 4 |
| 3 | 9 |
| 4 | 16 |
| 5 | 25 |
| 6 | 36 |
| 7 | 49 |
| 8 | 64 |
| 9 | 81 |
| 10 | 100 |
| 11 | 121 |
| 12 | 144 |
| 13 | 169 |
| 14 | 196 |
| 15 | 225 |
| 16 | 256 |
| 17 | 289 |
| 18 | 324 |
| 19 | 361 |
| 20 | 400 |

> [!TIP]
> **A pattern to check yourself:** the gaps between squares are the **odd numbers** —
> `1 → 4` is +3, `4 → 9` is +5, `9 → 16` is +7, and so on. That's because
> `(n + 1)² − n² = 2n + 1`, which is always odd. If two of your squares don't differ by
> the next odd number, one of them is wrong.

> [!NOTE]
> **Anchor on the easy ones first:** `5² = 25`, `10² = 100`, `15² = 225`, `20² = 400`.
> Learn these four, then fill in the numbers around them.
