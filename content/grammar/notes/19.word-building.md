# 19. Word building

*Shows up in: every NCERT English book from class 5 to 10 ("Let us learn" word exercises).*

English builds most long words out of **small parts**. Learn the parts and you can work out
words you've never seen: *un + break + able = **unbreakable** — "cannot be broken"*.

## Prefixes — added at the **front**, change the **meaning**

| Prefix | Means | Examples |
|---|---|---|
| **un-** | not | unhappy, unkind, unable |
| **dis-** | not / opposite | dislike, disagree, disappear |
| **in- / im- / il- / ir-** | not | incorrect, impossible, illegal, irregular |
| **mis-** | wrongly | misspell, misunderstand, misbehave |
| **re-** | again | rewrite, rebuild, return |
| **pre-** | before | preview, prehistoric, prepaid |
| **over-** | too much | overeat, overload |
| **under-** | too little / below | underpaid, underground |
| **sub-** | under | subway, submarine |
| **inter-** | between | international, interview |
| **anti-** | against | antiseptic, antisocial |
| **non-** | not | nonsense, non-stop |
| **bi- / tri-** | two / three | bicycle, triangle |

**Why im- / il- / ir-:** they are all *in-* that changed to match the next sound so it's easier to say —
***im**possible* (before p, b, m), ***il**legal* (before l), ***ir**regular* (before r).

> [!TIP]
> A prefix never changes spelling: *mis + spell = mi**ss**pell* (two s's), *dis + satisfied = di**ss**atisfied*, *un + natural = u**nn**atural*.

## Suffixes — added at the **end**, usually change the **word class**

| Suffix | Makes a … | Examples |
|---|---|---|
| **-ness, -ment, -ity, -tion/-sion, -ance/-ence, -hood, -ship, -dom** | noun | kindness, movement, ability, action, decision, appearance, childhood, friendship, freedom |
| **-er / -or / -ist** | noun (a person who) | teacher, actor, artist |
| **-ful, -less, -ous, -able/-ible, -al, -ive, -y, -ish** | adjective | hopeful, careless, famous, readable, natural, active, rainy, childish |
| **-ly** | adverb | quickly, happily |
| **-ise / -ize, -en, -ify** | verb | realise, widen, simplify |

**Why:** prefixes tweak *meaning* (happy → unhappy, still an adjective); suffixes change the *job* of the word
(happy → happiness, now a noun). That is why exam questions ask you to "use the correct form of the word".

- One root, many forms: *create (verb) → creation, creator, creativity (nouns) → creative (adj.) → creatively (adv.)*

**Spelling with suffixes:** drop silent e before a vowel suffix (*hope → hoping*, but *hope → hopeful*);
y → i (*happy → happiness*); double a short final consonant (*begin → beginner*).

## Compound words

Two words joined into one new meaning: *sun + flower = sunflower, foot + ball, tooth + brush, rain + bow.*
- Written as **one word** (*classroom*), **with a hyphen** (*mother-in-law, well-known*), or **open** (*ice cream, post office*).

## Synonyms, antonyms, homophones

- **Synonyms** — same/similar meaning: *big – large, begin – start, brave – courageous, ask – enquire.*
- **Antonyms** — opposite meaning: *hot – cold, ancient – modern, generous – mean, victory – defeat.*
  Often made with a prefix: *honest – **dis**honest, possible – **im**possible.*
- **Homophones** — **sound** the same, **spelt** differently, different meaning:

| | | |
|---|---|---|
| their / there / they're | to / too / two | hear / here |
| weather / whether | piece / peace | right / write |
| knew / new | flower / flour | sale / sail |
| whole / hole | buy / by / bye | principal / principle |
| stationary (still) / stationery (pens & paper) | | |

**Why spelling matters here:** in speech the context tells you which one; in writing only the spelling does.
Memory trick: station**e**ry has **e** for **e**nvelope; station**a**ry has **a** for st**a**nding still.
