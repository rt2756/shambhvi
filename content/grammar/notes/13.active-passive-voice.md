# 13. Active & passive voice

*Shows up in: class 8, 9; tested in class 9–10.*

- **Active:** *The cat **chased** the mouse.* — the doer (cat) is the subject.
- **Passive:** *The mouse **was chased** by the cat.* — the receiver (mouse) is the subject.

Same event, different **spotlight**. Active puts the **doer** first; passive puts the **thing done to** first.

**When passive is better:** when the doer is unknown, obvious or unimportant —
*My bike **was stolen**. Rice **is grown** in Bengal. The bridge **was built** in 1950.*

## The recipe

1. Object of the active → becomes the **subject**.
2. Verb → **be** (in the **same tense** as the active verb) + **V3**.
3. Old subject → **by + object form** (or drop it).

*She **writes** a letter.* → *A letter **is written** by her.*

**Why "be + V3":** *be* carries the tense, and V3 (the past participle) describes the state the thing
is left in — *written, broken, chosen*. So the tense lives in the *be*-part, not in V3.

> [!WARNING]
> Only **transitive** verbs (with an object) can be made passive. *She sleeps* / *He arrived* have no passive — there's no object to move.

## The tense table (verb: *write*, object: *a letter*)

| Tense | Active | Passive |
|---|---|---|
| Simple present | writes | **is / are** written |
| Present continuous | is writing | is / are **being** written |
| Present perfect | has written | has / have **been** written |
| Simple past | wrote | **was / were** written |
| Past continuous | was writing | was / were **being** written |
| Past perfect | had written | had **been** written |
| Simple future | will write | will **be** written |
| Future perfect | will have written | will have **been** written |
| Modals | can / must / should write | can / must / should **be** written |

> [!NOTE]
> Perfect-continuous and future-continuous tenses are not normally used in the passive — they sound clumsy.

**Pronoun changes:** *I → me, we → us, he → him, she → her, they → them* (and back the other way).
*They praised **him**.* → ***He** was praised by **them**.*

## Special types

**Questions** — keep it a question:
- *Did she write the letter?* → *Was the letter written by her?*
- *Who wrote this?* → ***By whom** was this written?*
- *What did he say?* → *What **was said** by him?*

**Commands (imperative)** — use **let … be + V3**, or *you are requested/ordered to*:
- *Open the door.* → ***Let** the door **be opened**.*
- *Please help me.* → *You **are requested** to help me.*

**Two objects** — either can become the subject:
- *He gave me a book.* → *I **was given** a book by him.* / *A book **was given** to me by him.*

**"by" is not always used:**
- *I know him.* → *He **is known to** me.* · *The jug contains milk.* → *Milk **is contained in** the jug.*
- *Someone has stolen my pen.* → *My pen **has been stolen**.* (drop vague doers: someone, people, they.)
- *The news shocked us.* → *We were shocked **at** the news.* (also *surprised at, interested in, pleased with*).

**More you'll meet in class 9–10:**
- Negative command: *Don't touch it.* → *Let it **not be touched**.*
- *People say that he is honest.* → ***It is said that** he is honest.* / *He **is said to be** honest.*
- Verb + preposition stays together: *We must take care of the old.* → *The old must be **taken care of**.*
- Modal + have: *Somebody should have told her.* → *She **should have been told**.*
