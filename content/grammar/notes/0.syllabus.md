# 0. Grammar map — classes 5 to 10

Grammar in CBSE is **not taught as one book** — it sits inside the NCERT English readers
(*Santoor* class 5, *Poorvi* classes 6–8, *Kaveri* class 9, *First Flight* class 10) as
"Let us learn" exercises, and the class 9–10 exam adds a fixed grammar section. So the
lessons here are arranged **by topic**, building from words → sentences → changing
sentences → using it all. Each lesson starts with the classes where it shows up.

> [!TIP]
> Class 5–6: lessons 1–6, 10–12, 18–19. Class 7–8: add 7–9, 13–16, 20. Class 9–10: everything,
> and lesson 21 is the exam-style check that you can *use* it.

## How to use a lesson

1. Read the lesson (the **Why it works** lines matter more than the rules).
2. Take the 🟢 Simple test. Score 8+ → move to 🟡, then 🟠, then 🔴.
3. Got one wrong? Read its *why* after Submit, then re-read that part of the lesson.
