# 17. Question tags

*Shows up in: class 9 (and in speaking/listening practice from class 7).*

- *It's a lovely day, **isn't it**?* · *You don't like tea, **do you**?*

A **question tag** is a tiny question added at the end of a statement to **check** something or ask the listener to **agree**.

## The two rules

1. **Positive statement → negative tag. Negative statement → positive tag.**
   *She **is** clever, **isn't** she?* · *She **isn't** clever, **is** she?*
2. **Tag = helping verb + pronoun** — reuse the statement's helping verb and turn the subject into a pronoun.
   *Ravi **can** swim, **can't he**?* · *The girls **were** late, **weren't they**?*

**Why opposite?** The tag offers the other side so the listener can confirm. A positive tag on a positive
statement (*She is clever, is she?*) sounds like surprise or sarcasm, not a check.

**Why reuse the helper:** the tag is a short form of the full question — *isn't she (clever)?* — so it keeps the same verb and drops the rest.

## No helping verb? Bring in do / does / did

- *He **plays** cricket, **doesn't** he?* (simple present, he → does)
- *They **live** here, **don't** they?*
- *You **went** home, **didn't** you?* (simple past → did)

## Special cases (learn these)

| Statement | Tag | Why |
|---|---|---|
| ***I am*** late, | **aren't I?** | *amn't I* isn't used, so English borrows *aren't* |
| ***Let's*** go, | **shall we?** | *let's* is a suggestion for *us*, and *shall we* is how we suggest |
| *Open the door* (command), | **will you? / won't you?** | an order turned polite |
| *Don't* be late, | **will you?** | negative command → positive *will you* |
| ***Everyone*** came, | **didn't they?** | *everyone / someone / nobody* → **they** |
| ***Nothing*** happened, | **did it?** | *nothing / everything* → **it** |
| ***This / That*** is yours, | **isn't it?** | *this/that* → **it** |
| ***There*** is a problem, | **isn't there?** | *there* stays *there* |
| He ***has*** a car (owns), | **doesn't he?** | *has* as a main verb takes *do* |
| He ***has*** finished, | **hasn't he?** | *has* as a helper is reused |
| ***Let us*** go (asking *you* to allow us), | **will you?** | it's a request to the listener |
| ***Have*** a sweet (an offer), | **won't you?** | friendly invitations |
| You ***used to*** live here, | **didn't you?** | *used to* makes questions with *did* |
| He***'d better*** go, | **hadn't he?** | *'d* = **had** here |
| She***'d like*** tea, | **wouldn't she?** | *'d* = **would** here |
| ***One*** should try, | **shouldn't one?** | *one* stays *one* |

## Hidden negatives

**never, hardly, seldom, scarcely, rarely, no, nobody, nothing, few, little** make a statement **negative**, so the tag is **positive**.
- *She **never** lies, **does** she?* · ***Nobody** called, **did** they?* · *He **hardly** works, **does** he?*

**Why:** the statement already says "no", even without *not* — so the tag must swing the other way, to positive.

> [!TIP]
> Don't trust the word *not* alone — **read the meaning**. *Few people came* = hardly anyone (negative) → *did they?*
> *A few people came* = some did (positive) → *didn't they?*
