# 🎸 Week 8 — G and C: the key of G

**Goal:** add **G** and **C**, and play the most-used progressions in the **key of G** — with five chords you
now know: **G, C, D, Em, Am**.

**Read first:** look back at lessons **10** and **11**.

## 🎚️ Tune (3 min)

All six strings, finishing each one by tuning **up** to the note.

## 🔥 Warm-up (5 min)

1. Finger stretches.
2. One-minute changes **A ↔ D** — write the number down.

## 🛠️ Technique (10 min)

### A. The new chords — 4 min

```
   G                       C
   E A D G B e             E A D G B e
       o o o               x     o   o
   ===========             ===========
1  | | | | | |          1  | | | | 1 |
   -----------             -----------
2  | 1 | | | |          2  | | 2 | | |
   -----------             -----------
3  2 | | | | 3          3  | 3 | | | |
```

Roll call each one. **G**: strum all six. **C**: strum from the A string.

**Why does C leave out the low E?** C's root is on the A string (fret 3). The open low E is an E — a chord
note, but putting it at the bottom makes the chord sound unsteady. Starting from the root keeps it solid.

> [!TIP]
> In **C**, the open G and high e strings must ring. If they're dead, a finger is lying on them — arch
> fingers 2 and 1 so they come down on their tips, with the wrist a little lower under the neck.

### B. The anchor changes — 3 min

**C ↔ Am:** fingers **1 and 2 stay down**. Only finger 3 moves (A string fret 3 ↔ G string fret 2).

```
   Am                      C
   E A D G B e             E A D G B e
   x o       o             x     o   o
   ===========             ===========
1  | | | | 1 |          1  | | | | 1 |
   -----------             -----------
2  | | 2 3 | |          2  | | 2 | | |
   -----------             -----------
3  | | | | | |          3  | 3 | | | |
```

One-minute changes C ↔ Am. You should beat your Em ↔ Am score from Week 3 — fewer fingers move.

**Why is this so much faster?** Every finger that stays down is one fewer thing to place in time (lesson 10).
Moving one finger instead of three is the biggest shortcut on the guitar.

### C. One-minute changes: G ↔ C, G ↔ D — 3 min

These are the hard ones — G and C are stretches. One and a half minutes each. Write the numbers down.

## 🎵 Notes & tunes (7 min)

### D. Progressions in G — 4 min

Everyday strum (D, DU, UDU), one bar per chord:

```
| G       | C       | D       | G       |      I – IV – V – I    (classic)
| G       | D       | Em      | C       |      I – V – vi – IV   (the pop progression)
| Em      | C       | G       | D       |      vi – IV – I – V   (same chords, starting sad)
| G       | Em      | C       | D       |      I – vi – IV – V   (the '50s sound)
```

**Why do the second and third lines sound so different with the same four chords?** Where a progression
**starts** decides what feels like home. Starting on G (major) feels bright; starting on Em (the relative
minor, lesson 11) makes the same chords feel thoughtful and sad.

### E. Strum along: *Happy Birthday* in G — 3 min

*Happy Birthday* is in **3/4** (lesson 6). Use the waltz strum from lesson 12: **↓ . ↓ ↑ ↓ ↑** (1, 2 &, 3 &).

```
(Hap-py) birth-day to  you, (hap-py) birth-day to  you, (hap-py)
         | G          | D            | D          | G           |

         birth-day dear ___, (hap-py) birth-day to   you!
         | G          | C            | G     D    | G           |
```

The words in brackets are the **pick-up** — sung before the bar starts, so don't strum yet. In bar 7, G and D
share the bar: G on beats 1–2, D on beat 3.

## 🎉 Fun (5 min)

Pick **any** four chords from G, C, D, Em, Am and play them in any order — they're all in the G family, so
nothing can sound "wrong". Find an order you like and give it a name.
