# 4. Reading TAB & chord boxes

Guitarists mostly write music in two simple ways: **TAB** (for single notes and riffs) and
**chord boxes** (for chords). Both tell you **where to put your fingers**, not the note names.

## TAB — six lines, one per string

```
e|-----------------|   ← string 1, thinnest (highest)
B|-----------------|
G|-----------------|
D|-----------------|
A|-----------------|
E|-----------------|   ← string 6, thickest (lowest)
```

- Each **line is a string**. The **top line is the thin high e**, the bottom line is the thick low E.
- A **number** on a line = **which fret** to press on that string.
- **0** = play the string **open** (no finger).
- Read **left to right**, like a sentence.

**Why is the high string on top?** It looks upside-down compared with looking down at the
guitar — but TAB puts the **highest-sounding** string on top, the same way all written music
puts higher notes higher up the page.

> [!IMPORTANT]
> ```
> e|-----------0---|
> B|---1---3-------|
> G|---------------|
> D|---------------|
> A|---------------|
> E|---------------|
> ```
> Play: B string fret 1 → B string fret 3 → high e string open.
> Those notes are **C → D → E** (count from the open B: B, **C** at fret 1, C♯, **D** at fret 3).

## Notes played together

When numbers are **stacked on top of each other**, play them **at the same time**:

```
e|---0---|
B|---0---|
G|---0---|
D|---2---|
A|---2---|
E|---0---|
```

That stack is the **E minor (Em)** chord: strum all six strings, with fingers on the 2nd fret
of the A and D strings.

## TAB symbols you will meet

| Symbol | Name | What to do |
|---|---|---|
| `x` | muted | touch the string so it makes a dull "chk" with no note |
| `h` (e.g. `5h7`) | hammer-on | pick fret 5, then slam a finger onto fret 7 — don't pick again |
| `p` (e.g. `7p5`) | pull-off | pick fret 7, then flick that finger off so fret 5 sounds |
| `/` or `\` (e.g. `5/7`) | slide | pick fret 5 and slide up to 7 without lifting |
| `b` (e.g. `7b`) | bend | push the string sideways so the note goes up |
| `PM` | palm mute | rest the side of your picking hand on the strings by the bridge |

> [!WARNING]
> TAB shows **where**, but **not how long**. It cannot tell you the rhythm. That is why you
> should **listen to the song** first, and why lesson 5 teaches rhythm.

## Chord boxes — a picture of the neck standing up

A chord box is the neck turned **upright**, as if the guitar were hanging on a wall facing you:

```
   E A D G B e        ← the six strings, thick on the LEFT
   o     o o o        ← o = play open,  x = don't play
   ===========        ← the nut (top of the neck)
1  | | | | | |
   -----------
2  | 2 3 | | |        ← fret 2: finger 2 on A, finger 3 on D
   -----------
3  | | | | | |
```

That is **E minor** again — the same chord as the TAB stack above.

- **Up-and-down lines** = strings. **Thick low E on the left.**
- **Across lines** = frets. The thick top line is the **nut**.
- A **number** in the box = **which finger** to use (1 = index … 4 = pinky).
- **o** above = play that string open. **x** above = don't play it.

**Why thick on the left?** Hold your guitar up in front of you with the neck pointing at the
ceiling. The thick string is now on your left — the chord box is drawn just the way you see it.

> [!IMPORTANT]
> **A minor (Am):**
> ```
>    E A D G B e
>    x o       o
>    ===========
> 1  | | | | 1 |
>    -----------
> 2  | | 2 3 | |
>    -----------
> 3  | | | | | |
> ```
> Don't play low E. Finger 1 on B string fret 1, finger 2 on D string fret 2, finger 3 on
> G string fret 2. Strum from the A string down.

## TAB numbers vs chord-box numbers

| | A number means… |
|---|---|
| **TAB** | which **fret** |
| **Chord box** | which **finger** (the fret is shown by which row it is in) |

> [!WARNING]
> This is the most common mix-up. In TAB, "2" means **fret 2**. In a chord box, "2" means
> **finger 2 (middle)**.
