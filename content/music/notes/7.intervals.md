# 7. Intervals

## The distance between two notes

Play the open A string, then fret 3 of the same string (C). Now play A, then fret 7 (E). The
second jump sounds **bigger** — because it is.

An **interval** is the **distance between two notes**. On the guitar it is easy to measure:
**count the half steps (frets)** from the lower note to the higher one.

## Interval names

| Half steps | Name | Short | Example from C | Sound |
|---|---|---|---|---|
| 0 | unison | P1 | C → C | the same note |
| 1 | minor 2nd | m2 | C → C♯ | tense, "Jaws" |
| 2 | major 2nd | M2 | C → D | a step — *py → Birth* in *Hap-py Birth-day* |
| 3 | minor 3rd | m3 | C → E♭ | sad, soft |
| 4 | major 3rd | M3 | C → E | bright, happy |
| 5 | perfect 4th | P4 | C → F | open, like a bugle call |
| 6 | tritone | TT | C → F♯ | very tense, "unfinished" |
| 7 | perfect 5th | P5 | C → G | strong, powerful — *Twin-kle twin-kle* |
| 8 | minor 6th | m6 | C → A♭ | |
| 9 | major 6th | M6 | C → A | |
| 10 | minor 7th | m7 | C → B♭ | |
| 11 | major 7th | M7 | C → B | dreamy, "almost there" |
| 12 | octave | P8 | C → C | the same note, higher |

## Why "3rd", "5th"?

The **number** comes from counting **letters**, starting with the first note as 1.

- C → E: **C**(1) D(2) **E**(3) — a **3rd**.
- C → G: **C**(1) D(2) E(3) F(4) **G**(5) — a **5th**.

The **number** says how many letters; the **half steps** say exactly how big. That is why there
are two kinds of 3rd:

- C → E = 3 letters, **4** half steps → **major** 3rd.
- C → E♭ = 3 letters, **3** half steps → **minor** 3rd ("minor" = smaller).

**Why it works:** E and E♭ are both "E", so both are 3 letters from C. But E♭ is one half step lower,
so the distance is one half step smaller — a minor (smaller) 3rd instead of a major (larger) one.

> [!WARNING]
> Count the **first note as 1**, not 0. C → D is a **2nd**, not a "1st". (Half steps start at 0;
> letter numbers start at 1 — don't mix them up.)

## Why some intervals sound sweet

Remember (lesson 1) that every note is a number of shakes per second. When two notes play
together, how well they blend depends on how neatly their shakes line up.

| Interval | Shakes compare like | Sound |
|---|---|---|
| Octave | 2 : 1 | blends completely |
| Perfect 5th | 3 : 2 | very smooth, strong |
| Perfect 4th | 4 : 3 | smooth |
| Major 3rd | about 5 : 4 | sweet |
| Minor 2nd | about 16 : 15 | clashing, buzzy |

**Why it works:** with 3 : 2, the shakes line up every **3 swings** of the higher note — often, so it
sounds calm. With 16 : 15, they only line up every 16 swings; in between they keep bumping into
each other, and you hear that as a clash. **Small numbers = smooth; big numbers = tense.**

## Intervals on the fretboard — shapes

Because the guitar is tuned in a pattern (lesson 3), each interval has a **shape** you can move
anywhere.

| Interval | Shape (on the E, A, D strings) |
|---|---|
| **Perfect 4th** | same fret, next string up |
| **Perfect 5th** | next string up, **2 frets** higher |
| **Octave** | **two** strings up, **2 frets** higher |

**Example:** low E string fret 3 = G.
- Perfect 5th: A string fret **5** = D (G A♭ A B♭ B C D♭ **D** — 7 half steps ✓).
- Octave: D string fret **5** = G ✓.

**Why it works:** the next string is already 5 half steps higher (a perfect 4th). Add 2 frets →
5 + 2 = **7** half steps = perfect 5th. Two strings over is 5 + 5 = 10; add 2 frets → **12** = octave.

> [!WARNING]
> **The G–B exception.** The G and B strings are only **4** half steps apart. So when a shape
> crosses from the G string to the B string, move **one fret higher** than usual:
> a 5th becomes 3 frets up, an octave from the D string to the B string becomes 3 frets up.

## Sargam check

In sargam, **Sa → Pa** is a **perfect 5th** and **Sa → Ma** is a **perfect 4th**. That's why the
tanpura drone plays Sa and Pa together — it is the smoothest pair after the octave.
