# 10. Open chords

**Open chords** use some **open strings** and sit in the first three frets. They are the chords most songs
are played with. You know Em, Am and E already — here are the eight that cover thousands of songs.

## The major / minor pairs

Each pair differs by **one note — the 3rd** (lesson 9). Learn them side by side.

```
   E                       Em
   E A D G B e             E A D G B e
   o       o o             o     o o o
   ===========             ===========
1  | | | 1 | |          1  | | | | | |
   -----------             -----------
2  | 2 3 | | |          2  | 2 3 | | |
   -----------             -----------
3  | | | | | |          3  | | | | | |
```

| | E | A | D | G | B | e |
|---|---|---|---|---|---|---|
| **E** (0 2 2 1 0 0) | E | B | E | **G♯** | B | E |
| **Em** (0 2 2 0 0 0) | E | B | E | **G** | B | E |

**E major = E G♯ B. E minor = E G B.** Finger 1 on the G string turns G into G♯ — minor 3rd → major 3rd.

```
   A                       Am
   E A D G B e             E A D G B e
   x o       o             x o       o
   ===========             ===========
1  | | | | | |          1  | | | | 1 |
   -----------             -----------
2  | | 1 2 3 |          2  | | 2 3 | |
   -----------             -----------
3  | | | | | |          3  | | | | | |
```

| | E | A | D | G | B | e |
|---|---|---|---|---|---|---|
| **A** (x 0 2 2 2 0) | — | A | E | A | **C♯** | E |
| **Am** (x 0 2 2 1 0) | — | A | E | A | **C** | E |

**A = A C♯ E. Am = A C E.** The B string at fret 2 (C♯) or fret 1 (C) is the 3rd.

> [!TIP]
> In A, three fingers squeeze into fret 2 side by side. If they don't fit, angle them slightly — or use
> fingers 2, 1, 3 (middle on D, index on G, ring on B). Any fingering that rings clean is fine.

```
   D                       Dm
   E A D G B e             E A D G B e
   x x o                   x x o
   ===========             ===========
1  | | | | | |          1  | | | | | 1
   -----------             -----------
2  | | | 1 | 2          2  | | | 2 | |
   -----------             -----------
3  | | | | 3 |          3  | | | | 3 |
```

| | E | A | D | G | B | e |
|---|---|---|---|---|---|---|
| **D** (x x 0 2 3 2) | — | — | D | A | D | **F♯** |
| **Dm** (x x 0 2 3 1) | — | — | D | A | D | **F** |

**D = D F♯ A. Dm = D F A.** The high e string carries the 3rd. Strum **only the top four strings**.

> [!WARNING]
> D and Dm sound muddy if the low E or A strings ring — those notes (E, A) aren't the root. Start the
> strum on the D string, or let your thumb rest lightly on the low E to mute it.

## G and C — the big two

```
   G                       C
   E A D G B e             E A D G B e
       o o o               x     o   o
   ===========             ===========
1  | | | | | |          1  | | | | 1 |
   -----------             -----------
2  | 1 | | | |          2  | | 2 | | |
   -----------             -----------
3  2 | | | | 3          3  | 3 | | | |
```

| | E | A | D | G | B | e |
|---|---|---|---|---|---|---|
| **G** (3 2 0 0 0 3) | G | B | D | G | B | G |
| **C** (x 3 2 0 1 0) | — | C | E | G | C | E |

**G = G B D. C = C E G.** Check: every note in each chord is one of its three chord notes.

**Why does each chord skip certain strings?** A chord sounds most solid when its **lowest note is the
root**. C's root is on the A string (fret 3), so the low E (an E, not a C) is left out. D's root is the open
D string, so both lower strings are left out.

> [!TIP]
> G and C are stretches. For G you can also use fingers 3-2-4 (ring on low E, middle on A, pinky on
> high e) — it makes changing to C easier later. Pick one and stick with it.

## Changing chords faster — keep what you can

Before changing, look for fingers that **don't need to move**:

| Change | Shortcut |
|---|---|
| **C ↔ Am** | fingers 1 and 2 **stay put**; only finger 3 moves (A string fret 3 ↔ G string fret 2) |
| **Em ↔ E** | add or lift finger 1 — nothing else moves |
| **Am ↔ E** | same shape, slide it **one string over** |
| **D ↔ Dm** | finger 3 stays on the B string; the others re-shuffle |

**Why look for anchors?** Every finger that stays down is one fewer thing to place in time. Fewer moving
parts = faster, cleaner changes.

## Which strings to strum

| Chord | Strum from |
|---|---|
| E, Em, G | low E (all six) |
| A, Am, C | the A string (5 strings) |
| D, Dm | the D string (4 strings) |

**Why does it matter?** An extra string that isn't a chord note — or puts the wrong note at the bottom —
makes the chord sound blurred. Aim your first down-strum at the root string.
