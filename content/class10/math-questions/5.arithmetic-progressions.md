Define an arithmetic progression and the common difference.

> [!ANSWER]
> **An AP is a list of numbers in which each term is obtained by ADDING A FIXED NUMBER to the preceding term, except the first term.**
>
> **That fixed number is the COMMON DIFFERENCE, d, and it can be positive, negative or ZERO.**
>
> **General form:**
> ```
> a,  a + d,  a + 2d,  a + 3d,  …
> ```
> **You need BOTH a and d to know an AP.** With a = 6 alone the AP could be `6, 9, 12, …` (d = 3) or `6, 3, 0, …` (d = −3) or `6, 6, 6, …` (d = 0).

---

How do you test whether a list of numbers is an AP, and in which order must you subtract?

> [!ANSWER]
> ```
> d = a(k+1) − a(k)          — the LATER term MINUS the earlier one
> ```
> **Check SEVERAL consecutive differences; they must ALL be equal.**
>
> **The order matters even when the numbers are decreasing.** For `6, 3, 0, −3, …` the common difference is `3 − 6 = −3`, **not** `6 − 3 = 3`.
>
> **Once you already know a list is an AP, one difference is enough** — but to *test* an unknown list, one is never enough.

---

Which of these are APs: 4, 10, 16, 22, …; 1, −1, −3, −5, …; −2, 2, −2, 2, …; 1, 1, 1, 2, 2, 2, 3, 3, 3, …?

> [!ANSWER]
> ```
> 4, 10, 16, 22, …    differences 6, 6, 6      → AP, d = 6.  Next: 28, 34
> 1, −1, −3, −5, …    differences −2, −2, −2   → AP, d = −2. Next: −7, −9
> −2, 2, −2, 2, …     differences 4, −4        → NOT an AP
> 1,1,1,2,2,2,3,3,3   differences 0, 0, 1      → NOT an AP
> ```
> **The last one shows why you must check more than one difference** — the first two are both 0 and would have fooled you.

---

Is 1, 1, 2, 3, 5, 8, … an AP? Explain.

> [!ANSWER]
> **No.**
> ```
> differences: 0, 1, 1, 2, 3 — not constant
> ```
> **It follows a rule — each term is the sum of the two before it — but that is not the AP rule.**
>
> **"Follows a pattern" and "is an AP" are different claims.** An AP needs specifically **"add a fixed number"**, and this sequence (the rabbit-pairs sequence) does something else entirely.

---

Taxi fare is ₹15 for the first km and ₹8 for each additional km. Does the list of fares form an AP?

> [!ANSWER]
> ```
> 15, 23, 31, 39, …        differences all 8
> ```
> **YES — an AP with a = 15 and d = 8.**
>
> **Why: each extra kilometre ADDS a fixed ₹8** — which is exactly the AP rule.

---

A vacuum pump removes 1/4 of the air remaining in a cylinder at each stroke. Does the amount of air form an AP?

> [!ANSWER]
> **NO.**
>
> **Removing a quarter leaves three-quarters, so each amount is the previous one MULTIPLIED by 3/4** — not the previous one plus a fixed number.
> ```
> 1, 0.75, 0.5625, 0.4219, …
> differences: −0.25, −0.1875, −0.1406 — not constant
> ```
> **The differences shrink because a quarter of a smaller amount is smaller.** This is a *geometric* pattern, not an arithmetic one.

---

Digging a well costs ₹150 for the first metre, rising by ₹50 for each subsequent metre. Is this an AP?

> [!ANSWER]
> ```
> 150, 200, 250, 300, …
> ```
> **YES — a = 150, d = 50.** Each extra metre **adds** a fixed ₹50.

---

₹10000 is deposited at 8% compound interest per annum. Does the yearly amount form an AP?

> [!ANSWER]
> **NO.**
>
> **Compound interest MULTIPLIES the amount by 1.08 each year** rather than adding a fixed sum.
> ```
> 10000, 10800, 11664, 12597.12, …
> differences: 800, 864, 933.12 — growing, not constant
> ```
> **The interest itself grows because it is charged on a larger amount each year.**
>
> **Contrast with SIMPLE interest, which does give an AP** — the interest is the same every year.

> [!ANSWER]

> 3, 3+√2, 3+2√2, …    d = √2                     → AP. Next: 3+4√2, 3+5√2, 3+6√2
>
> 0.2, 0.22, 0.222, …  differences 0.02, 0.002    → NOT an AP
>
> 0, −4, −8, −12, …    d = −4                     → AP. Next: −16, −20, −24
>

> ```
> **The surd one is a genuine AP** — irrational common differences are allowed. **The decimal one is not**, even though it looks orderly.

Are these APs? 1, 3, 9, 27, …; a, 2a, 3a, 4a, …; a, a², a³, a⁴, …; √2, √8, √18, √32, …

> [!ANSWER]
> ```
> 1, 3, 9, 27, …          differences 2, 6, 18        → NOT an AP (tripling)
>
> a, 2a, 3a, 4a, …        d = a                       → AP. Next: 5a, 6a, 7a
>
> a, a², a³, a⁴, …        differences a²−a, a³−a²     → NOT an AP in general
>
> √2, √8, √18, √32, …     = √2, 2√2, 3√2, 4√2
>                         d = √2                      → AP. Next: √50, √72, √98
> ```
> **The last one is the instructive case: simplify before judging.** As written the terms look unrelated; as `√2, 2√2, 3√2, 4√2` the pattern is obvious.

Are √3, √6, √9, √12, … and 1², 3², 5², 7², … and 1², 5², 7², 73 arithmetic progressions?

> [!ANSWER]
> ```
> √3, √6, √9, √12, …   = 1.732, 2.449, 3, 3.464
>                        differences 0.717, 0.551, 0.464  → NOT an AP
>
> 1², 3², 5², 7²       = 1, 9, 25, 49
>                        differences 8, 16, 24            → NOT an AP
>
> 1², 5², 7², 73       = 1, 25, 49, 73
>                        differences 24, 24, 24           → YES, an AP with d = 24
> ```
> **The last one is a trap in the other direction** — it looks like a list of squares and is not, but it IS an AP. **Always work out the actual numbers.** Next terms: 97, 121, 145.

---

State the formula for the nth term, and explain why it has (n − 1) rather than n.

> [!ANSWER]
> ```
> aₙ = a + (n − 1)d
> ```
> **Why (n − 1): to reach the nth term from the FIRST, you take one step FEWER than n.** No steps are needed to reach the 1st term, one step to reach the 2nd, two to reach the 3rd.
>
> **Check on n = 1:** `a₁ = a + 0·d = a` ✔ — exactly what it should be. **If the formula had n, it would give `a + d` for the first term, which is wrong.**
>
> **aₙ is also called the GENERAL TERM**, and if the AP has m terms then **aₘ is the LAST term, often written l**.

Find the 10th term of 2, 7, 12, …

> [!ANSWER]
> ```
> a = 2, d = 5, n = 10
>
> a₁₀ = 2 + (10 − 1)(5) = 2 + 45 = 47
> ```

Find the missing terms: (i) 2, __, 26; (ii) __, 13, __, 3; (iii) 5, __, __, 9½.

> [!ANSWER]
> ```
> (i)   a = 2, a₃ = 26:   2 + 2d = 26  →  d = 12
>       missing term: 14
>
> (ii)  a₂ = 13, a₄ = 3:  2d = 3 − 13 = −10  →  d = −5
>       a = 13 + 5 = 18,  a₃ = 8
>       so:  18, 13, 8, 3
>

> ```
> **The method every time: two known terms give an equation in d**, because the gap between the mth and nth terms is `(n − m)d`.

Find the number of terms in 7, 13, 19, …, 205 and in 18, 15½, 13, …, −47.

> [!ANSWER]
> ```
> 7, 13, 19, …, 205:   a = 7, d = 6
>       205 = 7 + (n − 1)(6)
>       198 = 6(n − 1)   →   n − 1 = 33   →   n = 34
>
> 18, 15½, 13, …, −47:  a = 18, d = −5/2

Is −150 a term of the AP 11, 8, 5, 2, …?

> [!ANSWER]
> ```
> a = 11, d = −3
>
> −150 = 11 + (n − 1)(−3)
> −161 = −3(n − 1)
> n − 1 = 161/3       ← not a whole number
> ```
> **NO — −150 is not a term.**
>
> **Why the fraction settles it: n counts POSITION in the list, so it must be a positive INTEGER.** There is no "161/3 + 1 th" term. The AP steps straight over −150.

---

The 11th term of an AP is 38 and the 16th is 73. Find the 31st term.

> [!ANSWER]
> ```
> a + 10d = 38        …(1)
> a + 15d = 73        …(2)
>
> (2) − (1):  5d = 35   →   d = 7
> then        a = 38 − 70 = −32
>
> a₃₁ = −32 + 30(7) = −32 + 210 = 178
> ```
> **Subtracting the two equations kills a immediately** — which is why you should always subtract first and find d.

---

An AP has 50 terms, its 3rd term is 12 and its last term is 106. Find the 29th term.

> [!ANSWER]
> ```
> a + 2d = 12         …(1)
> a + 49d = 106       …(2)        the 50th term is the last
>
> (2) − (1):  47d = 94   →   d = 2
> then        a = 12 − 4 = 8
>
> a₂₉ = 8 + 28(2) = 64
> ```

---

The 3rd and 9th terms of an AP are 4 and −8. Which term is zero?

> [!ANSWER]
> ```
> a + 2d = 4          …(1)
> a + 8d = −8         …(2)
>
> (2) − (1):  6d = −12   →   d = −2
> then        a = 4 + 4 = 8
>
> for aₙ = 0:  8 + (n − 1)(−2) = 0
>              2(n − 1) = 8   →   n = 5
> ```
> **The 5th term is zero.**

---

The 17th term of an AP exceeds its 10th term by 7. Find the common difference.

> [!ANSWER]
> ```
> a₁₇ − a₁₀ = 7
>
> [a + 16d] − [a + 9d] = 7
> 7d = 7   →   d = 1
> ```
> **Note that a cancels completely** — the gap between two terms never depends on the first term, only on how many steps apart they are.
>
> **In general `aₙ − aₘ = (n − m)d`**, which is worth remembering as a shortcut.

---

Which term of 3, 15, 27, 39, … is 132 more than its 54th term?

> [!ANSWER]
> ```
> a = 3, d = 12
>
> a₅₄ = 3 + 53(12) = 3 + 636 = 639
> required term = 639 + 132 = 771
>
> 771 = 3 + (n − 1)(12)
> 768 = 12(n − 1)   →   n − 1 = 64   →   n = 65
> ```
> **The 65th term.**
>
> **Shortcut using `aₙ − aₘ = (n − m)d`:** `132 = (n − 54)(12)` gives `n − 54 = 11`, so `n = 65` — the same answer without ever computing a₅₄.

---

Two APs have the same common difference, and their 100th terms differ by 100. By how much do their 1000th terms differ?

> [!ANSWER]
> **By 100 — exactly the same.**
> ```
> first AP:  aₙ = a + (n − 1)d
> second:    bₙ = b + (n − 1)d          same d
>
> aₙ − bₙ = [a + (n − 1)d] − [b + (n − 1)d] = a − b
> ```
> **The difference is a − b for EVERY n** — the `(n − 1)d` parts are identical and cancel.
>
> **So if the 100th terms differ by 100, then a − b = 100, and the 1000th terms differ by 100 too.** Two APs with the same common difference stay a fixed distance apart for ever.

How many three-digit numbers are divisible by 7?

> the first three-digit multiple of 7:  105  (since 7 × 15 = 105)
> the last:                             994  (since 7 × 142 = 994)

> **128 such numbers.**
>

For what n are the nth terms of 63, 65, 67, … and 3, 10, 17, … equal?

> [!ANSWER]
> ```
> first AP:   a = 63, d = 2   →   aₙ = 63 + 2(n − 1)
> second AP:  a = 3,  d = 7   →   bₙ = 3 + 7(n − 1)
>
> 63 + 2(n − 1) = 3 + 7(n − 1)
> 60 = 5(n − 1)
> n − 1 = 12   →   n = 13
> ```
> **The 13th terms are equal** — both are `63 + 24 = 87` and `3 + 84 = 87` ✔
>
> **The second AP starts far behind but climbs faster, so it eventually catches up.**

Determine the AP whose 3rd term is 16 and whose 7th term exceeds the 5th by 12.

> [!ANSWER]
> ```
> a₇ − a₅ = 12   →   2d = 12   →   d = 6
>
> a₃ = 16:   a + 2(6) = 16   →   a = 4
>
> the AP is  4, 10, 16, 22, 28, …
> ```
> **Using `aₙ − aₘ = (n − m)d` on the second condition gives d in one line.**

Find the 20th term from the last term of 3, 8, 13, …, 253.

> [!ANSWER]
> **Easiest method — REVERSE the AP.** Reading backwards, the first term is 253 and the common difference is −5:
> ```
> a₂₀ = 253 + 19(−5) = 253 − 95 = 158
> ```
> **Checking the other way:**
> ```
> how many terms?  253 = 3 + (n − 1)(5)  →  n = 51
> the 20th from the end is the (51 − 20 + 1) = 32nd from the start
> a₃₂ = 3 + 31(5) = 158        ✔
> ```
> **The reversal avoids the `n − k + 1` off-by-one completely** — which is exactly why it is the safer method.

The sum of the 4th and 8th terms of an AP is 24, and of the 6th and 10th is 44. Find the first three terms.

> [!ANSWER]
> ```
> (a + 3d) + (a + 7d) = 24   →   2a + 10d = 24   →   a + 5d = 12      …(1)
> (a + 5d) + (a + 9d) = 44   →   2a + 14d = 44   →   a + 7d = 22      …(2)
>
> (2) − (1):  2d = 10   →   d = 5
> then        a = 12 − 25 = −13
>
> first three terms:  −13, −8, −3
> ```

Subba Rao started in 1995 on ₹5000 a year with a ₹200 annual increment. In which year did his income reach ₹7000?

> [!ANSWER]
> ```
> a = 5000, d = 200, aₙ = 7000
>
> 7000 = 5000 + (n − 1)(200)

---

Explain Gauss's trick for adding 1 to 100, and derive the sum formula for an AP from it.

> [!ANSWER]
> **Gauss wrote the sum forwards and backwards and added:**
> ```
> S = 1   + 2  + 3  + … + 99 + 100
> S = 100 + 99 + …      + 2  + 1
> ------------------------------------
> 2S = 101 + 101 + … + 101        (100 times)
> 2S = 100 × 101      →     S = 5050
> ```
> **Every vertical pair adds to the SAME total** — that is the whole idea.
>
> **The same trick on a general AP:**
> ```
> S = a + (a + d) + … + [a + (n − 1)d]
> S = [a + (n − 1)d] + [a + (n − 2)d] + … + a
> ------------------------------------------------
> 2S = n[2a + (n − 1)d]          n pairs, each 2a + (n − 1)d
>
> Sₙ = (n/2)[2a + (n − 1)d]
> ```

---

State the three forms of the sum formula and say when each is most useful.

> [!ANSWER]
> ```
> Sₙ = (n/2)[2a + (n − 1)d]        use when a, d and n are known
>
> Sₙ = (n/2)(a + aₙ)               use when the nth term is already known
>
> Sₙ = (n/2)(a + l)                use when the FIRST and LAST terms are known
>                                  but d is NOT
> ```
> **The last form says something memorable: the sum is the NUMBER of terms times their AVERAGE**, and in an AP the average of all the terms is simply the average of the first and last — which is exactly what Gauss's pairing shows.

---

Shakila puts ₹100 in a money box on her daughter's first birthday and increases it by ₹50 each year. How much is in the box by the 21st birthday?

> [!ANSWER]
> ```
> a = 100, d = 50, n = 21
>
> S = (21/2)[2(100) + 20(50)]
>   = (21/2)(200 + 1000)
>   = (21/2)(1200) = 21 × 600 = 12600
> ```
> **₹12,600.**
>
> **Adding 21 numbers by hand would have worked too** — but the formula makes it one line, and would work just as easily for 210 years.

> **A negative sum is perfectly possible** — the terms turn negative early and stay there.

Find the sum of the first 1000 positive integers, and the sum of the first n odd numbers.

> [!ANSWER]
> **First 1000 positive integers:**
> ```
> a = 1, l = 1000, n = 1000
> S = (1000/2)(1 + 1000) = 500 × 1001 = 500500
> ```
> **First n odd numbers — 1, 3, 5, …:**
> ```
> a = 1, d = 2
> Sₙ = (n/2)[2(1) + (n − 1)(2)] = (n/2)(2n) = n²
> ```
> **The sum of the first n odd numbers is exactly n².** `1 = 1²`, `1+3 = 4 = 2²`, `1+3+5 = 9 = 3²` ✔ — a striking result that falls straight out of the formula.

Find the sum of all multiples of 3 from 3 to 99.

> [!ANSWER]
> ```
> 3, 6, 9, …, 99 with a = 3, d = 3, l = 99
>
> how many terms?   99 = 3 + (n − 1)(3)  →  96 = 3(n − 1)  →  n = 33
>
> S = (33/2)(3 + 99) = (33/2)(102) = 33 × 51 = 1683
> ```
> **Using `Sₙ = (n/2)(a + l)` was quickest here**, since both the first and last terms were given.

How is the nth term related to the sums, and why?

> [!ANSWER]
> ```
> aₙ = Sₙ − Sₙ₋₁
> ```
> **The nth term is the sum of the first n terms MINUS the sum of the first (n − 1).**
>
> **Why: everything except the nth term appears in BOTH sums and cancels.** `Sₙ` contains terms 1 to n, and `Sₙ₋₁` contains terms 1 to n−1 — so subtracting leaves exactly the nth term.
>
> **This is genuinely useful when a question gives you a formula for Sₙ and asks for a particular term.**

Find the sum of the first 10 terms of 2, 7, 12, …

> [!ANSWER]
> ```
> a = 2, d = 5, n = 10
>
> S = (10/2)[2(2) + 9(5)] = 5(4 + 45) = 5(49) = 245
> ```

₹1000 is invested at 8% SIMPLE interest per year. Do the yearly interests form an AP? Find the interest at the end of 30 years.

> [!ANSWER]
> ```
> simple interest = (P × R × T)/100
>
> year 1:  (1000 × 8 × 1)/100 = ₹80
> year 2:  (1000 × 8 × 2)/100 = ₹160
> year 3:  (1000 × 8 × 3)/100 = ₹240
>
> the list 80, 160, 240, … has d = 80  →  YES, an AP with a = 80
>
> a₃₀ = 80 + 29(80) = 80 × 30 = ₹2400
> ```
> **Why simple interest gives an AP but compound interest does not: simple interest is charged on the ORIGINAL principal every year, so the same ₹80 is ADDED each time.** Compound interest is charged on a growing amount, so it multiplies instead.

A flower bed has 23 rose plants in the first row, 21 in the second, 19 in the third, and 5 in the last row. How many rows are there?

> [!ANSWER]
> ```
> 23, 21, 19, …, 5 is an AP with a = 23, d = −2, aₙ = 5
>
> 5 = 23 + (n − 1)(−2)
> −18 = −2(n − 1)
> n − 1 = 9   →   n = 10
> ```
> **There are 10 rows.**
