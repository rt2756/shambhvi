## 2.1 Degrees and names

**The DEGREE of a polynomial is the highest power of the variable in it.**

| Degree | Name | General form | Examples |
|---|---|---|---|
| **1** | **LINEAR** | `ax + b`, a ≠ 0 | `2x − 3`, `√3 x + 5`, `3z + 4` |
| **2** | **QUADRATIC** | `ax² + bx + c`, a ≠ 0 | `2x² + 3x − 2/5`, `y² − 2`, `5v² − (2/3)v` |
| **3** | **CUBIC** | `ax³ + bx² + cx + d`, a ≠ 0 | `2 − x³`, `3 − x² + x³`, `3x³ − 2x² + x − 1` |

**'Quadratic' comes from *quadrate*, meaning SQUARE** — degree 2.

> [!WARNING]
> **These are NOT polynomials:**
> ```
> 1/(x − 1)        √x + 2        1/(x² + 2x + 3)
> ```
> **A polynomial needs whole-number powers of the variable, and the variable never in a denominator or under a root.**
>
> **And `2x + 5 − x²` is not LINEAR**, even though it contains `2x` — the highest power is 2, so it is quadratic. **Degree is decided by the highest power present, not the first term written.**

## What a zero is

**The VALUE of p(x) at x = k, written p(k), is what you get by replacing x with k.**

```
p(x) = x² − 3x − 4

p(2)  = 2² − 3(2) − 4  = 4 − 6 − 4  = −6
p(0)  = −4
p(−1) = (−1)² − 3(−1) − 4 = 1 + 3 − 4 = 0
p(4)  = 4² − 3(4) − 4 = 16 − 12 − 4 = 0
```

> [!IMPORTANT]
> **A real number k is a ZERO of the polynomial p(x) if p(k) = 0.**
>
> **So −1 and 4 are the zeroes of x² − 3x − 4.**

**For a linear polynomial:**
```
if k is a zero of p(x) = ax + b, then ak + b = 0, so k = −b/a

zero of a linear polynomial  =  −(constant term) / (coefficient of x)
```

**Example:** `2x + 3` → `k = −3/2`.

**So the zero of a linear polynomial is already related to its coefficients. Does the same happen for quadratics and cubics? That is the question this chapter answers.**

## 2.2 The geometrical meaning of a zero

### Linear

**The graph of `y = ax + b` is a STRAIGHT LINE.**

**Example:** `y = 2x + 3` passes through (−2, −1) and (2, 7), and **crosses the x-axis at (−3/2, 0)** — exactly the zero of the polynomial.

> [!IMPORTANT]
> **A linear polynomial `ax + b` (a ≠ 0) has EXACTLY ONE zero — the x-coordinate of the single point where its graph meets the x-axis, namely `(−b/a, 0)`.**

### Quadratic

**The graph of `y = ax² + bx + c` is a PARABOLA:**
- **opens UPWARDS when a > 0**
- **opens DOWNWARDS when a < 0**

**Example — `y = x² − 3x − 4`:**

| x | −2 | −1 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|---|---|
| y | 6 | **0** | −4 | −6 | −6 | −4 | **0** | 6 |

**The graph crosses the x-axis at x = −1 and x = 4 — precisely the zeroes.**

> [!IMPORTANT]
> **THE ZEROES OF A POLYNOMIAL ARE PRECISELY THE x-COORDINATES OF THE POINTS WHERE THE GRAPH OF y = p(x) MEETS THE x-AXIS.**
>
> **Why this must be so:** a point is on the x-axis exactly when its **y-coordinate is 0**. On the graph, y = p(x). So being on the x-axis means **p(x) = 0** — which is the definition of a zero. **Two different-sounding ideas turn out to be the same thing.**

**Three cases for a quadratic:**

| Case | Graph | Zeroes |
|---|---|---|
| **(i)** | cuts the x-axis at **two distinct points** | **two distinct zeroes** |
| **(ii)** | touches the x-axis at **exactly one point** (the two points have coincided) | **two equal zeroes**, i.e. one zero |
| **(iii)** | lies **entirely above or entirely below** the x-axis | **NO zero** |

**So a quadratic polynomial has at most TWO zeroes.**

### Cubic

**Example — `y = x³ − 4x`:**

| x | −2 | −1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| y | **0** | 3 | **0** | −3 | **0** |

**Zeroes: −2, 0 and 2 — again the x-axis crossings.**

**Two more cubics:**
- **`y = x³`** — its **only** zero is 0, and its graph meets the x-axis only there
- **`y = x³ − x² = x²(x − 1)`** — zeroes **0 and 1**

> [!IMPORTANT]
> **THE GENERAL RESULT: a polynomial p(x) of degree n has AT MOST n zeroes**, because the graph of y = p(x) meets the x-axis at **at most n points**.
>
> **"At most", not "exactly"** — a quadratic may have 2, 1 or 0 zeroes, as the three cases show.

## 2.3 Zeroes and coefficients

### Discovering the pattern

**Take `p(x) = 2x² − 8x + 6` and factorise by splitting the middle term:**
```
2x² − 8x + 6 = 2x² − 6x − 2x + 6
             = 2x(x − 3) − 2(x − 3)
             = (2x − 2)(x − 3) = 2(x − 1)(x − 3)

zeroes: x = 1 and x = 3

sum     = 1 + 3 = 4  = −(−8)/2 = −(coefficient of x)/(coefficient of x²)  ✔
product = 1 × 3 = 3  =    6 /2 =  (constant term)/(coefficient of x²)     ✔
```

**Take `p(x) = 3x² + 5x − 2`:**
```
3x² + 5x − 2 = 3x² + 6x − x − 2 = 3x(x + 2) − 1(x + 2) = (3x − 1)(x + 2)

zeroes: x = 1/3 and x = −2

sum     = 1/3 + (−2) = −5/3  = −(5)/3   ✔
product = (1/3)(−2)  = −2/3  =  (−2)/3  ✔
```

### Proving it

> [!IMPORTANT]
> **If α and β are the zeroes of `p(x) = ax² + bx + c` (a ≠ 0), then `x − α` and `x − β` are factors, so**
> ```
> ax² + bx + c = k(x − α)(x − β)          for some constant k
>              = k[x² − (α + β)x + αβ]
>              = kx² − k(α + β)x + kαβ
>
> comparing coefficients:
>       a = k          b = −k(α + β)          c = kαβ
>
> therefore
>       α + β = −b/a           αβ = c/a
> ```

> [!IMPORTANT]
> **THE QUADRATIC RELATIONSHIPS**
> ```
> sum of zeroes      α + β = −b/a = −(coefficient of x) / (coefficient of x²)
> product of zeroes  αβ    =  c/a =  (constant term)   / (coefficient of x²)
> ```
> **The MINUS SIGN belongs to the SUM only.** That single detail causes most of the errors in this chapter.

**Worked — `x² + 7x + 10`:**
```
x² + 7x + 10 = (x + 2)(x + 5)     →  zeroes −2 and −5

sum     = −2 + (−5) = −7  = −7/1  ✔
product = (−2)(−5)  = 10  =  10/1 ✔
```

**Worked — `x² − 3`** (using `a² − b² = (a − b)(a + b)`):
```
x² − 3 = (x − √3)(x + √3)     →  zeroes √3 and −√3

sum     = √3 + (−√3) = 0   = −0/1   ✔   (there is no x term, so b = 0)
product = (√3)(−√3)  = −3  = −3/1   ✔
```

### Building a polynomial from its zeroes

**Worked — find a quadratic whose zeroes have sum −3 and product 2.**
```
α + β = −b/a = −3          αβ = c/a = 2

take a = 1  →  b = 3,  c = 2

polynomial:  x² + 3x + 2
```

> [!IMPORTANT]
> **The answer is not unique.** Any `k(x² + 3x + 2)` with k real has exactly the same zeroes — multiplying a polynomial by a constant does not move where it crosses the axis.
>
> **The convenient general form:**
> ```
> x² − (sum of zeroes)x + (product of zeroes)
> ```
> — take a = 1 and read the coefficients straight off. **Note the minus sign in front of the sum.**

### Cubics

**Take `p(x) = 2x³ − 5x² − 14x + 8`, whose zeroes are 4, −2 and 1/2:**
```
sum                     = 4 + (−2) + 1/2 = 5/2  = −(−5)/2   ✔
sum of products in pairs = 4(−2) + (−2)(1/2) + (1/2)(4)
                        = −8 − 1 + 2 = −7      = −14/2      ✔
product                 = 4 × (−2) × 1/2 = −4  = −8/2       ✔
```

> [!IMPORTANT]
> **THE CUBIC RELATIONSHIPS** — for `ax³ + bx² + cx + d` with zeroes α, β, γ:
> ```
> α + β + γ            = −b/a
> αβ + βγ + γα         =  c/a
> αβγ                  = −d/a
> ```

> [!TIP]
> **The pattern, once you see it, covers both cases:**
> ```
> one at a time:    −b/a          two at a time:  +c/a          three at a time:  −d/a
> ```
> **The signs ALTERNATE — minus, plus, minus — and you work down the coefficients b, c, d in order**, each divided by a.
>
> **The quadratic is the same pattern stopped early:** sum `= −b/a`, product (two at a time) `= +c/a`.

**Worked — verify that 3, −1 and −1/3 are the zeroes of `p(x) = 3x³ − 5x² − 11x − 3`:**
```
p(3)    = 3(27) − 5(9) − 11(3) − 3 = 81 − 45 − 33 − 3 = 0    ✔
p(−1)   = 3(−1) − 5(1) − 11(−1) − 3 = −3 − 5 + 11 − 3 = 0    ✔
p(−1/3) = 3(−1/27) − 5(1/9) − 11(−1/3) − 3
        = −1/9 − 5/9 + 11/3 − 3 = −6/9 + 2/3 = −2/3 + 2/3 = 0 ✔

with a = 3, b = −5, c = −11, d = −3:

α+β+γ        = 3 − 1 − 1/3 = 5/3      = −(−5)/3   ✔
αβ+βγ+γα     = 3(−1) + (−1)(−1/3) + (−1/3)(3)
             = −3 + 1/3 − 1 = −11/3   = −11/3     ✔
αβγ          = 3(−1)(−1/3) = 1        = −(−3)/3   ✔
```

## Summary

```
DEGREE 1 linear ax + b · 2 quadratic ax² + bx + c · 3 cubic ax³ + bx² + cx + d
   in every case the leading coefficient a ≠ 0
NOT polynomials: 1/(x−1), √x + 2 — no negative powers, no variable under a root

ZERO   k is a zero of p(x) if p(k) = 0
GEOMETRY  the zeroes are the x-coordinates where the graph of y = p(x)
          meets the x-axis — because on the x-axis y = 0, and y = p(x)

a polynomial of degree n has AT MOST n zeroes
   quadratic: 2 distinct · 2 equal · or none  (parabola cuts, touches, or misses)
   parabola opens UP if a > 0, DOWN if a < 0

QUADRATIC ax² + bx + c with zeroes α, β
      α + β = −b/a          αβ = c/a
   to build one: x² − (sum)x + (product), and any multiple k of it works too

CUBIC ax³ + bx² + cx + d with zeroes α, β, γ
      α + β + γ    = −b/a          one at a time
      αβ + βγ + γα =  c/a          two at a time
      αβγ          = −d/a          three at a time
   signs alternate − + − ; coefficients b, c, d taken in order, each over a
```
