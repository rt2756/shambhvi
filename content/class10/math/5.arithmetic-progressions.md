## What this chapter is about

Look at these everyday lists:

- **Reena's salary:** she starts at ₹8000 a month and gets ₹500 more each year → 8000, 8500, 9000, 9500, 10000, …
- **Rungs of a ladder** shrink by 2 cm each: 45, 43, 41, 39, …, 25.
- **Shakila's money box:** ₹100 on her daughter's 1st birthday, ₹150 on the 2nd, ₹200 on the 3rd, …

In each list, you get the next number by **adding the same amount** every time. Such a list is an **arithmetic progression (AP)**. This chapter gives two shortcuts: one to jump straight to any term (the 100th salary, without writing 99 others), and one to add up many terms quickly.

## 5.2 Arithmetic progressions

> [!IMPORTANT]
> **An ARITHMETIC PROGRESSION is a list of numbers in which each term is obtained by adding a fixed number to the term before it** (except the first term).
>
> - The fixed number is the **common difference, d**. It can be **positive, negative or zero**.
> - The first term is called **a** (or a₁). The terms are a₁, a₂, a₃, …, aₙ.
>
> ```
> a,   a + d,   a + 2d,   a + 3d,   …
> ```

**How to find d:** subtract any term from the one **after** it: **d = aₖ₊₁ − aₖ**.

**How to test for an AP:** work out a₂ − a₁, a₃ − a₂, a₄ − a₃, … If they are **all the same**, it is an AP. If even one differs, it isn't.

> [!NOTE]
> - **Finite AP:** stops (the 45-to-25 ladder). **Infinite AP:** goes on forever (3, 5, 7, 9, …).
> - d = 0 is allowed: 3, 3, 3, 3, … is an AP.
> - d negative means the AP **decreases**: 21, 18, 15, … has d = −3.

**Example 1 — 3/2, 1/2, −1/2, −3/2, …** a = 3/2, d = 1/2 − 3/2 = **−1**. (Each difference is −1.)

**Example 2 — AP or not?**

```
(i)   4, 10, 16, 22, …      differences 6, 6, 6        AP, next: 28, 34
(ii)  1, −1, −3, −5, …      differences −2, −2, −2     AP, next: −7, −9
(iii) −2, 2, −2, 2, …       differences 4, −4, 4       NOT an AP
(iv)  1, 1, 1, 2, 2, 2, …   differences 0, 0, 1        NOT an AP
```

## 5.3 The nth term

### Discover it with Reena's salary

```
year 1:  8000
year 2:  8000 + 500                 = 8000 + 1 × 500
year 3:  8000 + 500 + 500           = 8000 + 2 × 500
year 4:  8000 + 500 + 500 + 500     = 8000 + 3 × 500
year n:                               8000 + (n − 1) × 500
```

**Why (n − 1) and not n?** To get from the 1st term to the nth term you take **n − 1 steps** — just like 5 fence posts have only 4 gaps between them.

> [!IMPORTANT]
> **nth term (general term) of an AP:**
> ```
> aₙ = a + (n − 1)d
> ```
> If the AP has m terms, the **last term** is l = a + (m − 1)d.

**Example 3 — 10th term of 2, 7, 12, …** a = 2, d = 5: a₁₀ = 2 + 9 × 5 = **47**.

**Example 4 — which term of 21, 18, 15, … is −81? Is any term 0?**

```
a = 21, d = −3
−81 = 21 + (n − 1)(−3)   →   −102 = −3(n − 1)   →   n − 1 = 34   →   n = 35
0 = 21 + (n − 1)(−3)     →   n − 1 = 7          →   n = 8
```
−81 is the **35th** term, and the **8th** term is 0.

> [!IMPORTANT]
> **Is a number a term of the AP?** Solve for n. If n comes out as a **positive whole number**, yes. If it's a fraction or negative, no — there's no "8.4th" term.

**Example 5 — the AP whose 3rd term is 5 and 7th term is 9.**

```
a + 2d = 5
a + 6d = 9
subtract:  4d = 4  →  d = 1,  a = 3        AP: 3, 4, 5, 6, …
```
**Why subtracting works:** going from term 3 to term 7 is 4 steps of d, and the value rose by 4, so each step is 1.

**Example 6 — is 301 in 5, 11, 17, 23, …?** d = 6. 301 = 5 + 6(n − 1) → n − 1 = 296/6 = 49⅓. Not whole → **no**.

**Example 7 — how many two-digit numbers are divisible by 3?** They are 12, 15, …, 99 (an AP with d = 3).
99 = 12 + 3(n − 1) → n − 1 = 29 → **n = 30**.

**Example 8 — 11th term from the end of 10, 7, 4, …, −62.** Turn the AP round: −62, −59, −56, …, 10 has a = −62, d = +3.
11th term = −62 + 10 × 3 = **−32**.

> [!TIP]
> **nth term from the end = l − (n − 1)d** — start at the last term l and step backwards.

**Example 9 — ₹1000 at 8% simple interest.** Interest is ₹80 each year, so the total interest after 1, 2, 3, … years is 80, 160, 240, … — an AP with a = d = 80.
After 30 years: a₃₀ = 80 + 29 × 80 = **₹2400**.

**Example 10 — rose rows: 23, 21, 19, …, 5. How many rows?** 5 = 23 + (n − 1)(−2) → n − 1 = 9 → **10 rows**.

## 5.4 Sum of the first n terms

### Gauss's trick

When Gauss was about 10, his teacher asked the class to add 1 + 2 + 3 + … + 100. He answered in moments: **5050**. His idea — write the sum twice, once forwards and once backwards:

```
S =   1  +   2  +   3  + … +  99  + 100
S = 100  +  99  +  98  + … +   2  +   1
add:
2S = 101 + 101 + 101 + … + 101 + 101      (100 pairs)
2S = 100 × 101   →   S = 5050
```

**Why every pair is equal:** going right, the top row goes up by 1 and the bottom row goes down by 1, so their sum stays the same.

### The same trick for any AP

```
Sₙ = a           + (a + d)       + … + [a + (n − 1)d]
Sₙ = [a + (n−1)d] + [a + (n−2)d] + … + a
add:  2Sₙ = n × [2a + (n − 1)d]
```

> [!IMPORTANT]
> **Sum of the first n terms of an AP:**
> ```
> Sₙ = (n/2) [2a + (n − 1)d]
> Sₙ = (n/2) (a + l)          where l = aₙ is the last term
> ```
> **Why the second form:** 2a + (n − 1)d = a + [a + (n − 1)d] = a + l. In words: **number of terms × the average of the first and last term.**
>
> And going backwards: **aₙ = Sₙ − Sₙ₋₁** (the sum of n terms minus the sum of n − 1 terms leaves just the nth term).

**Shakila's money box:** 100, 150, 200, … for 21 birthdays. S₂₁ = (21/2)[200 + 20 × 50] = (21/2)(1200) = **₹12600**.

**Example 11 — first 22 terms of 8, 3, −2, …** a = 8, d = −5: S₂₂ = 11[16 + 21(−5)] = 11(−89) = **−979**.

**Example 12 — S₁₄ = 1050, a = 10. Find a₂₀.**

```
1050 = 7[20 + 13d]  →  150 = 20 + 13d  →  d = 10
a₂₀ = 10 + 19 × 10 = 200
```

**Example 13 — how many terms of 24, 21, 18, … add to 78?**

```
78 = (n/2)[48 + (n − 1)(−3)] = (n/2)(51 − 3n)
156 = 51n − 3n²   →   n² − 17n + 52 = 0   →   (n − 4)(n − 13) = 0
```
**Both n = 4 and n = 13 work!** 24 + 21 + 18 + 15 = 78, and the terms from the 5th to the 13th (12, 9, 6, 3, 0, −3, −6, −9, −12) add to 0, so the total stays 78.

**Example 14 — sum of the first n positive integers:** a = 1, l = n → **Sₙ = n(n + 1)/2**. (For n = 1000: 500500.)

**Example 15 — first 24 terms when aₙ = 3 + 2n.** a₁ = 5, a₂₄ = 51 → S₂₄ = 12 × 56 = **672**.

**Example 16 — TV sets: 600 in year 3, 700 in year 7, rising uniformly.**

```
a + 2d = 600,  a + 6d = 700  →  d = 25,  a = 550
(i) 1st year: 550   (ii) 10th year: 550 + 9 × 25 = 775
(iii) total in first 7 years: (7/2)[1100 + 6 × 25] = (7/2)(1250) = 4375
```

## In a nutshell

- **AP:** each term = previous term + **d** (d can be +, − or 0). Test: all differences equal.
- **nth term:** **aₙ = a + (n − 1)d** — n − 1 steps from the first term. From the end: l − (n − 1)d.
- **Is x a term?** Solve for n; it must be a positive whole number.
- **Sum:** **Sₙ = (n/2)[2a + (n − 1)d] = (n/2)(a + l)** — Gauss's pairing.
- **aₙ = Sₙ − Sₙ₋₁**. Sum of 1 to n = n(n + 1)/2.

> [!WARNING]
> **Top traps:** it's (n − 1)d, not nd · d = later term − earlier term (so 21, 18, … has d = −3) · count terms with (l − a)/d + 1, not (l − a)/d · "between 10 and 250" excludes the end points · check both roots for n — reject a negative or fractional n, but sometimes both positive roots work · compound interest and "remove ¼ each time" are not APs.
