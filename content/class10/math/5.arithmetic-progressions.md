## 5.1 Patterns everywhere

**Nature is full of patterns** — the petals of a sunflower, the holes of a honeycomb, the grains on a maize cob, the spirals on a pineapple and a pine cone.

**And so is daily life:**

| Situation | The list of numbers |
|---|---|
| Reena's salary: ₹8000 to start, ₹500 increment each year | 8000, 8500, 9000, … |
| Ladder rungs shortening by 2 cm from a 45 cm bottom rung | 45, 43, 41, 39, 37, 35, 33, 31 |
| A savings scheme where the amount becomes 5/4 of itself every 3 years | 10000, 12500, 15625, 19531.25 |
| Unit squares in squares of side 1, 2, 3, … | 1², 2², 3², … |
| Shakila's money box: ₹100, increased by ₹50 each year | 100, 150, 200, 250, … |
| Rabbit pairs, month by month | 1, 1, 2, 3, 5, 8 |

> [!IMPORTANT]
> **These patterns are NOT all of the same kind.**
> - In some, **each term is the previous one PLUS a fixed number** (salary, ladder, money box).
> - In one, each is the previous **MULTIPLIED** by a fixed number (the savings scheme).
> - In one, they are **squares** of consecutive numbers.
> - In one (the rabbits), each is the **sum of the two before it**.
>
> **This chapter is about the FIRST kind only.**

## 5.2 What an arithmetic progression is

> [!IMPORTANT]
> **An ARITHMETIC PROGRESSION (AP) is a list of numbers in which each term is obtained by ADDING A FIXED NUMBER to the preceding term, except the first term.**
>
> **That fixed number is the COMMON DIFFERENCE, d. It can be positive, negative or ZERO.**
>
> Each number in the list is a **TERM**.

**Examples, with their common differences:**
```
1, 2, 3, 4, …              d = 1        each term is 1 more than the one before
100, 70, 40, 10, …         d = −30      each is 30 less
−3, −2, −1, 0, …           d = 1
3, 3, 3, 3, …              d = 0        adding zero each time is still an AP
−1.0, −1.5, −2.0, −2.5, …  d = −0.5
```

**Notation:** first term `a₁` (or just **a**), second `a₂`, nth term `aₙ`, common difference **d**.
```
a₂ − a₁ = a₃ − a₂ = … = aₙ − aₙ₋₁ = d
```

> [!IMPORTANT]
> **THE GENERAL FORM of an AP:**
> ```
> a,  a + d,  a + 2d,  a + 3d,  …
> ```
> **To know an AP completely you need BOTH a and d.** Neither alone is enough:
> ```
> a = 6, d =  3   →   6, 9, 12, 15, …
> a = 6, d = −3   →   6, 3, 0, −3, …
> a = 2, d =  0   →   2, 2, 2, 2, …
> ```

**FINITE vs INFINITE:** an AP with a **last term** is **FINITE** (heights 147 … 157, prizes 200 … 750); one that goes on for ever is **INFINITE** and has no last term.

### Testing whether a list is an AP

> [!IMPORTANT]
> ```
> d = a(k+1) − a(k)          — SUBTRACT each term from the one that FOLLOWS it
> ```
> **You need check only ONE such difference once you know the list is an AP** — but to TEST a list, check several, and they must all be **equal**.

> [!WARNING]
> **Subtract in the right order: the (k+1)th term MINUS the kth term, even when the later term is smaller.**
>
> For `6, 3, 0, −3, …` the common difference is `3 − 6 = −3`, **not** `6 − 3 = 3`.

**Worked — which of these are APs?**
```
(i)   4, 10, 16, 22, …
      6, 6, 6 — all equal → AP with d = 6.  Next two: 28 and 34.

(ii)  1, −1, −3, −5, …
      −2, −2, −2 → AP with d = −2.  Next two: −7 and −9.

(iii) −2, 2, −2, 2, −2, …
      a₂ − a₁ = 4  but  a₃ − a₂ = −4  →  NOT an AP.

(iv)  1, 1, 1, 2, 2, 2, 3, 3, 3, …
      0, 0, 1 → the differences are not all equal → NOT an AP.
```

> [!TIP]
> **`1, 1, 2, 3, 5, …` is not an AP either** — the differences are 0, 1, 1, 2, which are not constant. **Every term being produced by a rule is not enough; the rule must be "add a fixed number".**

## 5.3 The nth term

**Follow Reena's salary and the pattern reveals itself:**
```
year 1:  8000
year 2:  8000 + 500                      = 8000 + (2 − 1)×500
year 3:  8000 + 500 + 500 = 8000 + 2×500 = 8000 + (3 − 1)×500 = 9000
year 4:  8000 + 3×500                    = 8000 + (4 − 1)×500 = 9500
year 5:  8000 + 4×500                    = 8000 + (5 − 1)×500 = 10000

year 15: 8000 + (15 − 1)×500 = 15000
year 25: 8000 + (25 − 1)×500 = 20000
```

> [!IMPORTANT]
> **THE nth TERM of an AP with first term a and common difference d:**
> ```
> aₙ = a + (n − 1)d
> ```
> **aₙ is also called the GENERAL TERM.** If the AP has m terms, **aₘ is the LAST term, often written l.**

> [!IMPORTANT]
> **Why `(n − 1)` and not n:** to reach the **nth** term from the **first**, you take **one step fewer than n** — no steps to reach the 1st, one step to reach the 2nd, and so on.
>
> **Check it on n = 1:** `a₁ = a + 0·d = a` ✔ — which is exactly what it should be.

**Worked — the 10th term of `2, 7, 12, …`:**
```
a = 2, d = 5, n = 10
a₁₀ = 2 + (10 − 1)(5) = 2 + 45 = 47
```

**Worked — which term of `21, 18, 15, …` is −81? Is any term 0?**
```
a = 21, d = −3, aₙ = −81

−81 = 21 + (n − 1)(−3)
−81 = 24 − 3n
3n = 105    →    n = 35        the 35th term is −81

for aₙ = 0:   21 + (n − 1)(−3) = 0
              3(n − 1) = 21    →    n = 8        the 8th term is 0
```

**Worked — determine the AP whose 3rd term is 5 and 7th term is 9.**
```
a + 2d = 5        …(1)
a + 6d = 9        …(2)

(2) − (1):  4d = 4  →  d = 1,  then a = 3

the AP is  3, 4, 5, 6, 7, …
```

> [!TIP]
> **Two facts about an AP always give two linear equations in a and d** — which is Chapter 3 all over again. Subtracting them kills a immediately, giving d in one step.

**Worked — is 301 a term of `5, 11, 17, 23, …`?**
```
d = 6 throughout, so it IS an AP, with a = 5

301 = 5 + (n − 1)(6)
301 = 6n − 1
n = 302/6 = 151/3
```
**n must be a POSITIVE INTEGER — you cannot have a "151/3 rd" term. So 301 is NOT a term of this list.**

**Worked — how many two-digit numbers are divisible by 3?**
```
the list is 12, 15, 18, …, 99 — an AP with a = 12, d = 3, aₙ = 99

99 = 12 + (n − 1)(3)
87 = 3(n − 1)
n − 1 = 29    →    n = 30
```
**There are 30 such numbers.**

**Worked — the 11th term FROM THE LAST of `10, 7, 4, …, −62`.**
```
first find how many terms there are:
−62 = 10 + (n − 1)(−3)
−72 = −3(n − 1)   →   n − 1 = 24   →   n = 25

the 11th from the last is the 15th from the start — NOT the 14th

a₁₅ = 10 + 14(−3) = 10 − 42 = −32
```
**Alternative — reverse the AP.** Then `a = −62` and `d = +3`, and the 11th term is
```
a₁₁ = −62 + 10(3) = −32           ✔ same answer, less counting
```

> [!WARNING]
> **Why the 11th from the last is the 15th and NOT the 14th:** with 25 terms, the **last** is the 25th and is **1st from the end**, the 24th is 2nd from the end, and so on. **The kth from the end is the (n − k + 1)th from the start:** `25 − 11 + 1 = 15`.
>
> **The reversal method avoids this off-by-one entirely** — which is why it is worth knowing.

## 5.4 The sum of the first n terms

**Shakila puts ₹100 in a money box on her daughter's first birthday and increases it by ₹50 each year. How much is in the box by her 21st birthday?** Adding 21 numbers by hand is tedious. There is a better way.

> [!NOTE]
> **Gauss's trick.** Asked as a ten-year-old to add the integers from 1 to 100, he answered **5050** at once. He wrote the sum forwards and backwards and added:
> ```
> S = 1   + 2  + 3  + … + 99 + 100
> S = 100 + 99 + …      + 2  + 1
> ----------------------------------
> 2S = 101 + 101 + … + 101 + 101        (100 times)
>
> 2S = 100 × 101    →    S = 5050
> ```
> **Every pair adds to the same total** — that is the whole idea.

**The same trick on a general AP:**
```
S = a + (a + d) + (a + 2d) + … + [a + (n − 1)d]                  …(1)
S = [a + (n − 1)d] + [a + (n − 2)d] + … + (a + d) + a            …(2)

adding term by term, EVERY pair gives 2a + (n − 1)d, and there are n pairs:

2S = n[2a + (n − 1)d]
```

> [!IMPORTANT]
> **THE SUM OF THE FIRST n TERMS**
> ```
> Sₙ = (n/2)[2a + (n − 1)d]
> ```
> **Equivalent forms:**
> ```
> Sₙ = (n/2)(a + aₙ)          since a + (n−1)d is aₙ
>
> Sₙ = (n/2)(a + l)           where l is the LAST term
> ```
> **The `(a + l)` form is the one to use when the first and last terms are known but d is not.**

> [!TIP]
> **`Sₙ = (n/2)(a + l)` says: the sum is the NUMBER of terms times their AVERAGE**, and in an AP the average of all the terms is just the average of the **first and last**. That is exactly what Gauss's pairing shows.

**Worked — Shakila's money box:**
```
a = 100, d = 50, n = 21

S = (21/2)[2(100) + 20(50)] = (21/2)(200 + 1000) = (21/2)(1200) = 12600
```
**₹12,600 by her 21st birthday.**

> [!IMPORTANT]
> **The sum formula links four quantities — S, a, d and n. Know any three and you can find the fourth.**
>
> **And a useful bridge between the two formulas:**
> ```
> aₙ = Sₙ − Sₙ₋₁
> ```
> **The nth term is the sum of the first n terms minus the sum of the first (n − 1)** — because everything except the nth term cancels.

**Worked — the sum of the first 22 terms of `8, 3, −2, …`:**
```
a = 8, d = −5, n = 22

S = (22/2)[16 + 21(−5)] = 11(16 − 105) = 11(−89) = −979
```

## Summary

```
AP    each term = previous term + a FIXED number d
      d = common difference; can be positive, NEGATIVE or ZERO
      general form:  a, a + d, a + 2d, a + 3d, …
      you need BOTH a and d to know an AP

TEST  d = a(k+1) − a(k) — later term MINUS earlier term
      all such differences must be EQUAL

nth TERM      aₙ = a + (n − 1)d
      (n − 1) because it takes one step fewer than n to reach the nth term
      check on n = 1: a₁ = a ✔
      last term is often written l

SUM OF FIRST n TERMS
      Sₙ = (n/2)[2a + (n − 1)d]
      Sₙ = (n/2)(a + aₙ) = (n/2)(a + l)      use when a and l are known but not d
      derived by Gauss's trick: write the sum forwards and backwards and add,
      every pair giving 2a + (n − 1)d

      aₙ = Sₙ − Sₙ₋₁

WATCH FOR
   n must be a POSITIVE INTEGER — a fractional n means the value is NOT a term
   the kth term from the END is the (n − k + 1)th from the start;
      easier still, reverse the AP and use a = l, d = −d
```
