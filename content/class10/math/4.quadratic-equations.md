## What this chapter is about

**A charity trust wants a prayer hall** with a carpet area of 300 m². The length must be **one metre more than twice the breadth**. What should the sizes be?

```
let breadth = x m, so length = (2x + 1) m
area:  x(2x + 1) = 300
       2x² + x − 300 = 0
```

This equation has an **x²** in it, so the methods of Chapter 3 won't work. It is a **quadratic equation**, and this chapter is about solving them and about predicting, before solving, what kind of answers they have.

> [!NOTE]
> People have solved these for nearly 4000 years. Babylonians solved "find two numbers whose sum and product are known"; **Brahmagupta** (AD 598–665) gave an explicit formula for ax² + bx = c, and **Sridharacharya** (AD 1025) derived the quadratic formula by completing the square, as quoted by **Bhaskara II**.

## 4.2 What is a quadratic equation?

> [!IMPORTANT]
> **A QUADRATIC EQUATION in x** is one that can be written as
> ```
> ax² + bx + c = 0,      a, b, c real numbers,  a ≠ 0
> ```
> The **standard form** has the powers in descending order. Any equation that **simplifies** to this form is quadratic.
>
> **Why a ≠ 0:** if a = 0 the x² term disappears and the equation becomes linear.

### Turning words into a quadratic — Example 1

**(i) John and Jivanti have 45 marbles together. Each loses 5, and the product of what they now have is 124.**

```
John has x, so Jivanti has 45 − x
after losing 5:  x − 5  and  40 − x
(x − 5)(40 − x) = 124
40x − x² − 200 + 5x = 124
−x² + 45x − 324 = 0       → multiply by −1 →    x² − 45x + 324 = 0
```

**(ii) A cottage industry makes x toys a day; each toy costs (55 − x) rupees to make; the total cost one day was ₹750.**

```
x(55 − x) = 750   →   x² − 55x + 750 = 0
```

### Is it quadratic? Simplify first — Example 2

Expand both sides, move everything to one side, and look at the highest power that **survives**:

```
(i)  (x − 2)² + 1 = 2x − 3      x² − 4x + 5 = 2x − 3        x² − 6x + 8 = 0      YES
(ii) x(x + 1) + 8 = (x + 2)(x − 2)   x² + x + 8 = x² − 4    x + 12 = 0           NO (x² cancels)
(iii) x(2x + 3) = x² + 1        2x² + 3x = x² + 1           x² + 3x − 1 = 0      YES
(iv) (x + 2)³ = x³ − 4          x³ + 6x² + 12x + 8 = x³ − 4  6x² + 12x + 12 = 0  YES (x³ cancels!)
```

> [!WARNING]
> **Don't judge by looks.** (ii) looks quadratic but isn't; (iv) looks cubic but is quadratic. Only the **simplified** form decides.

## 4.3 Solving by factorisation

### The key fact

> [!IMPORTANT]
> **If A × B = 0, then A = 0 or B = 0.**
>
> **Why:** if neither A nor B were 0, their product couldn't be 0 (two non-zero numbers never multiply to zero). This is the whole reason we want "= 0" on one side — it lets us split one hard equation into two easy ones.

> [!IMPORTANT]
> **A ROOT of ax² + bx + c = 0** is a number α with aα² + bα + c = 0. The roots of the **equation** are exactly the **zeroes of the polynomial** ax² + bx + c (Chapter 2) — so there are **at most two**.

### Splitting the middle term

**Example 3 — 2x² − 5x + 3 = 0.**

We want to break −5x into two pieces whose **product equals a × c = 2 × 3 = 6x²** and whose sum is −5x. Try: −2x and −3x (product 6x², sum −5x ✔).

```
2x² − 2x − 3x + 3 = 0
2x(x − 1) − 3(x − 1) = 0
(2x − 3)(x − 1) = 0
2x − 3 = 0  or  x − 1 = 0    →    x = 3/2  or  x = 1
```

Check x = 1: 2 − 5 + 3 = 0 ✔.

> [!TIP]
> **Why "product = a × c"?** If 2x² − 5x + 3 = (px + q)(rx + s), the middle pieces are psx and qrx, and their product is (pr)(qs)x² = (a)(c)x². So the pieces you want always multiply to ac and add to b.

**Example 4 — 6x² − x − 2 = 0.** ac = −12; two numbers with product −12 and sum −1: **3 and −4**.

```
6x² + 3x − 4x − 2 = 3x(2x + 1) − 2(2x + 1) = (3x − 2)(2x + 1) = 0
x = 2/3  or  x = −1/2
```

**Example 5 — 3x² − 2√6x + 2 = 0.** ac = 6; two numbers with product 6 and sum −2√6: **−√6 and −√6**.

```
3x² − √6x − √6x + 2 = √3x(√3x − √2) − √2(√3x − √2) = (√3x − √2)² = 0
x = √2/√3  (twice)     — a repeated root
```

**Example 6 — the prayer hall: 2x² + x − 300 = 0.** ac = −600; numbers with product −600, sum 1: **25 and −24**.

```
2x² − 24x + 25x − 300 = 2x(x − 12) + 25(x − 12) = (x − 12)(2x + 25) = 0
x = 12  or  x = −25/2
```
A breadth can't be negative, so **breadth = 12 m, length = 2(12) + 1 = 25 m**. (Check: 12 × 25 = 300 ✔.)

> [!WARNING]
> **Reject answers that don't fit the story** — negative lengths, ages, counts, or fractions of a toy. The algebra gives every root; you decide which one the real situation allows.

## 4.4 Nature of roots

Factorising only works when you can spot the numbers. The **quadratic formula** always works.

### Where the formula comes from (completing the square)

The idea: turn the left side into a **perfect square**, because a square is easy to "undo" with a square root.

```
ax² + bx + c = 0
divide by a:              x² + (b/a)x + c/a = 0
move c/a:                 x² + (b/a)x = −c/a
add (b/2a)² to both sides:  x² + (b/a)x + (b/2a)² = (b/2a)² − c/a
the left is now a square: (x + b/2a)² = (b² − 4ac)/4a²
square-root both sides:   x + b/2a = ± √(b² − 4ac) / 2a
```

> [!IMPORTANT]
> **THE QUADRATIC FORMULA.** The roots of ax² + bx + c = 0 are
> ```
> x = [ −b ± √(b² − 4ac) ] / 2a
> ```
> **Why add (b/2a)²?** Because (x + k)² = x² + 2kx + k². To match x² + (b/a)x we need 2k = b/a, so k = b/2a — and then the missing piece is k² = (b/2a)².

### The discriminant decides everything

The number under the root, **D = b² − 4ac**, is called the **discriminant** — it "discriminates" between the kinds of roots.

> [!IMPORTANT]
> | D = b² − 4ac | Roots | Graph of y = ax² + bx + c |
> |---|---|---|
> | **D > 0** | **two distinct real roots**, (−b ± √D)/2a | cuts the x-axis twice |
> | **D = 0** | **two equal real roots**, x = −b/2a | touches the x-axis once |
> | **D < 0** | **no real roots** | never meets the x-axis |
>
> **Why:** if D > 0, √D is a real number and "+√D" and "−√D" give two different answers. If D = 0, ±0 gives the same answer twice. If D < 0, no real number squares to a negative, so √D doesn't exist among real numbers.

**Example 7 — 2x² − 4x + 3 = 0.** D = (−4)² − 4(2)(3) = 16 − 24 = **−8 < 0** → **no real roots**.

**Example 9 — 3x² − 2x + 1/3 = 0.** D = 4 − 4(3)(1/3) = 4 − 4 = **0** → **two equal roots**, x = −b/2a = 2/6 = **1/3, 1/3**.

**Example 8 — a pole on a circular park.** The park's diameter AB = 13 m. A pole P on the boundary must be 7 m further from gate A than from gate B. Possible?

An angle in a semicircle is 90°, so triangle APB is right-angled at P:

```
let PB = x, then PA = x + 7
x² + (x + 7)² = 13²
2x² + 14x + 49 = 169   →   x² + 7x − 60 = 0
D = 49 + 240 = 289 > 0    → yes, real roots exist
x = (−7 ± 17)/2 = 5 or −12
```
Distance can't be negative, so **PB = 5 m and PA = 12 m**.

### Exercise 4.3, worked

**1. Nature of roots; find them if real.**

```
(i)   2x² − 3x + 5 = 0     D = 9 − 40 = −31 < 0    → no real roots

(ii)  3x² − 4√3x + 4 = 0   D = 48 − 48 = 0         → equal roots
      x = 4√3 / 6 = 2√3/3 = 2/√3   (twice)

(iii) 2x² − 6x + 3 = 0     D = 36 − 24 = 12 > 0    → two distinct roots
      x = (6 ± √12)/4 = (6 ± 2√3)/4 = (3 ± √3)/2
```

**2. Find k for equal roots** (equal roots ⇔ D = 0).

```
(i)  2x² + kx + 3 = 0:   k² − 24 = 0   →   k = ±√24 = ±2√6

(ii) kx(x − 2) + 6 = 0  →  kx² − 2kx + 6 = 0
     D = 4k² − 24k = 4k(k − 6) = 0   →   k = 0 or 6
     k = 0 makes it not quadratic (and gives 6 = 0!), so k = 6
```

**3. A mango grove with length twice breadth and area 800 m²?**

```
x(2x) = 800  →  2x² − 800 = 0  →  x² = 400    D = 0 + 4 × 2 × 800 > 0 → yes
x = 20  →  breadth 20 m, length 40 m
```

**4. Two friends' ages add to 20; four years ago their product was 48. Possible?**

```
x and 20 − x.  Four years ago: (x − 4)(16 − x) = 48
−x² + 20x − 64 = 48   →   x² − 20x + 112 = 0
D = 400 − 448 = −48 < 0   →   NOT possible
```

**5. A park with perimeter 80 m and area 400 m²?**

```
l + b = 40,  l = 40 − b:   b(40 − b) = 400   →   b² − 40b + 400 = 0
D = 1600 − 1600 = 0   →   yes, b = 20, l = 20   (it's a square)
```

> [!TIP]
> **"Is it possible?" questions are discriminant questions.** Form the equation, compute D: negative means impossible; zero or positive means possible.

## More worked examples

**A. Solve x² + 4x − 5 = 0 by the formula.** a = 1, b = 4, c = −5; D = 16 + 20 = 36.
x = (−4 ± 6)/2 = **1 or −5**. (Factorising: (x + 5)(x − 1) ✔.)

**B. A train covers 480 km; 8 km/h slower would take 3 h more (Ex 4.1 Q2 iv).**
u² − 8u − 1280 = 0: D = 64 + 5120 = 5184 = 72². u = (8 ± 72)/2 = **40** or −32 → **40 km/h**. (Check: 480/32 − 480/40 = 15 − 12 = 3 ✔.)

**C. For what k does x² − kx + 9 = 0 have equal roots?** k² − 36 = 0 → **k = ±6**.

**D. Rohan's age (Ex 4.1 Q2 iii): x² + 32x − 273 = 0.** Product −273, sum 32: 39 and −7 → (x + 39)(x − 7) → **Rohan is 7** (mother 33; in 3 years 10 × 36 = 360 ✔).

## In a nutshell

- **Quadratic equation:** ax² + bx + c = 0 with a ≠ 0 — judge only after simplifying.
- **Roots** = zeroes of the polynomial; at most two.
- **Factorisation:** split bx into two terms with product ac and sum b, factorise, then use **A × B = 0 ⇒ A = 0 or B = 0**.
- **Formula:** x = [−b ± √(b² − 4ac)]/2a, from completing the square.
- **Discriminant D = b² − 4ac:** D > 0 two distinct real roots · D = 0 two equal roots (−b/2a) · D < 0 no real roots.
- In word problems, **reject roots that don't make sense**.

> [!WARNING]
> **Top traps:** bring everything to one side as "= 0" before factorising · don't divide both sides by x — you lose the root x = 0 · D = b² − 4ac, so a negative b still gives a positive b² · in the formula, 2a is under the WHOLE numerator · "equal roots" means D = 0, "real roots" means D ≥ 0 · k must keep a ≠ 0 (reject k = 0) · reject negative lengths, ages and speeds.
