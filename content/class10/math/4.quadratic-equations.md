## 4.1 Where they come from

**A prayer hall has carpet area 300 m², with its length one metre more than twice its breadth.**

```
let the breadth be x metres, so the length is (2x + 1) metres

area = (2x + 1)·x = 2x² + x

2x² + x = 300
2x² + x − 300 = 0        ← a QUADRATIC EQUATION
```

> [!NOTE]
> **A long history.** **Babylonians** are believed to be the first to solve quadratic equations — they could find two positive numbers with a given sum and product, which is exactly `x² − px + q = 0`.
>
> **Euclid** developed a geometrical approach. **Solving them in general form is often credited to ancient Indian mathematicians:** **Brahmagupta (598–665 CE)** gave an explicit formula for `ax² + bx = c`, and **Sridharacharya (1025 CE)** derived what we now call the **quadratic formula**, by **completing the square** (as quoted by Bhaskara II).
>
> **Al-Khwarizmi** (about 800 CE) studied various types, and **Abraham bar Hiyya Ha-Nasi** gave complete solutions in *Liber embadorum* (Europe, 1145 CE).

## 4.2 What a quadratic equation is

> [!IMPORTANT]
> **A QUADRATIC EQUATION in x is an equation of the form**
> ```
> ax² + bx + c = 0,     where a, b, c are real and a ≠ 0
> ```
> **Any equation `p(x) = 0` where p(x) is a polynomial of DEGREE 2 is a quadratic equation.** Writing the terms in **descending order of degree** gives the **STANDARD FORM**.

> [!WARNING]
> **You must SIMPLIFY before deciding whether an equation is quadratic.** An equation can look quadratic and not be, or look cubic and turn out to be quadratic.

**Worked — which of these are quadratic?**

```
(i)  (x − 2)² + 1 = 2x − 3
     LHS = x² − 4x + 4 + 1 = x² − 4x + 5
     x² − 4x + 5 = 2x − 3   →   x² − 6x + 8 = 0        ✔ QUADRATIC

(ii) x(x + 1) + 8 = (x + 2)(x − 2)
     x² + x + 8 = x² − 4
     the x² terms CANCEL:   x + 12 = 0                 ✘ NOT quadratic — it is linear

(iii) x(2x + 3) = x² + 1
     2x² + 3x = x² + 1   →   x² + 3x − 1 = 0           ✔ QUADRATIC

(iv) (x + 2)³ = x³ − 4
     x³ + 6x² + 12x + 8 = x³ − 4
     the x³ terms CANCEL:   6x² + 12x + 12 = 0
                            x² + 2x + 2 = 0            ✔ QUADRATIC after all
```

> [!IMPORTANT]
> **The lesson from (ii) and (iv): watch for terms that CANCEL.**
>
> **(ii) looked quadratic but wasn't** — the x² on each side cancelled, leaving degree 1.
> **(iv) looked cubic but was** — the x³ on each side cancelled, leaving degree 2.
>
> **Never judge the degree from the equation as written; expand and collect first.**

### Modelling situations

**Worked — John and Jivanti have 45 marbles between them. Each loses 5, and the product of what remains is 124.**
```
let John have x, so Jivanti has 45 − x

after losing 5 each:   x − 5   and   45 − x − 5 = 40 − x

(x − 5)(40 − x) = 124
40x − x² − 200 + 5x = 124
−x² + 45x − 200 = 124
−x² + 45x − 324 = 0
x² − 45x + 324 = 0
```

**Worked — a cottage industry: the cost of each toy in rupees is 55 minus the number of toys made, and one day's total cost was ₹750.**
```
let x toys be produced; cost per toy = 55 − x

total cost:  x(55 − x) = 750
             55x − x² = 750
             x² − 55x + 750 = 0
```

## 4.3 Solving by factorisation

> [!IMPORTANT]
> **A real number α is a ROOT of `ax² + bx + c = 0` if `aα² + bα + c = 0`.** We also say **α satisfies the equation**, or is a **solution**.
>
> **The ZEROES of the polynomial `ax² + bx + c` and the ROOTS of the equation `ax² + bx + c = 0` are the SAME THING** — different words for the same numbers.
>
> **A quadratic polynomial has at most two zeroes, so a quadratic equation has AT MOST TWO ROOTS.**

> [!IMPORTANT]
> **THE METHOD: factorise into two LINEAR factors, then set each factor to zero.**
>
> **Why it works:** if a product of two things is **zero**, then **at least one of them must be zero**. There is no other way to multiply to nothing.

**Worked — `2x² − 5x + 3 = 0`:**
```
split the middle term: 2 × 3 = 6, and (−2) + (−3) = −5

2x² − 2x − 3x + 3 = 2x(x − 1) − 3(x − 1) = (2x − 3)(x − 1)

(2x − 3)(x − 1) = 0

2x − 3 = 0  →  x = 3/2        or        x − 1 = 0  →  x = 1

roots: 3/2 and 1
```

**Worked — `6x² − x − 2 = 0`:**
```
6 × (−2) = −12, and 3 + (−4) = −1

6x² + 3x − 4x − 2 = 3x(2x + 1) − 2(2x + 1) = (3x − 2)(2x + 1)

roots: x = 2/3 and x = −1/2
```

**Worked — `3x² − 2√6 x + 2 = 0`:**
```
3x² − √6x − √6x + 2 = √3x(√3x − √2) − √2(√3x − √2)
                    = (√3x − √2)(√3x − √2)

√3x − √2 = 0  →  x = √2/√3

the SAME factor appears twice, so the root is REPEATED:

roots: √2/√3 and √2/√3
```

**Worked — the prayer hall.** Solve `2x² + x − 300 = 0`:
```
2 × (−300) = −600, and −24 + 25 = 1

2x² − 24x + 25x − 300 = 2x(x − 12) + 25(x − 12) = (x − 12)(2x + 25)

roots: x = 12 and x = −12.5
```
**x is a breadth, so it cannot be negative. Breadth = 12 m, and length = 2(12) + 1 = 25 m.**

> [!WARNING]
> **In a word problem, ALWAYS check both roots against the situation.** Lengths, ages, numbers of objects and speeds cannot be negative — **the algebra has no way of knowing that, so you must reject the impossible root yourself.**

## 4.4 The quadratic formula and the nature of roots

> [!IMPORTANT]
> **THE QUADRATIC FORMULA — the roots of `ax² + bx + c = 0` are**
> ```
> x = ( −b ± √(b² − 4ac) ) / (2a)          provided b² − 4ac ≥ 0
> ```

> [!IMPORTANT]
> **THE DISCRIMINANT is `b² − 4ac`.** It sits under the square-root sign, and **decides everything**:
>
> | Discriminant | Roots |
> |---|---|
> | **b² − 4ac `>` 0** | **two DISTINCT real roots** |
> | **b² − 4ac = 0** | **two EQUAL real roots** (coincident) |
> | **b² − 4ac `<` 0** | **NO real roots** |

> [!TIP]
> **Why the three cases follow immediately from the formula:**
> - If `b² − 4ac > 0`, the square root is a **positive** number, and `−b + √…` differs from `−b − √…` → **two different roots**.
> - If `b² − 4ac = 0`, the square root is **0**, so both branches give `x = −b/2a` → **one value, counted twice**.
> - If `b² − 4ac < 0`, **no real number squares to a negative**, so the formula produces nothing real → **no real roots**.
>
> **This is exactly the three-cases picture from Chapter 2** — the parabola cutting the x-axis twice, touching it once, or missing it entirely.

**Worked — the nature of the roots of `2x² − 4x + 3 = 0`:**
```
a = 2, b = −4, c = 3

b² − 4ac = 16 − 24 = −8 < 0

NO REAL ROOTS
```

**Worked — `3x² − 2x + 1/3 = 0`:**
```
a = 3, b = −2, c = 1/3

b² − 4ac = 4 − 4(3)(1/3) = 4 − 4 = 0

TWO EQUAL REAL ROOTS, both  x = −b/2a = 2/6 = 1/3
```

### Using the discriminant to answer "is it possible?"

**Worked — a pole on a circular park.** The park has diameter 13 m, with gates A and B **diametrically opposite**. Can a pole be placed on the boundary so that the **difference** of its distances from the gates is 7 m?

```
let BP = x, so AP = x + 7

AB is a DIAMETER, so ∠APB = 90°     (angle in a semicircle)

by Pythagoras:   AP² + PB² = AB²
                 (x + 7)² + x² = 13²
                 x² + 14x + 49 + x² = 169
                 2x² + 14x − 120 = 0
                 x² + 7x − 60 = 0

discriminant = 7² − 4(1)(−60) = 49 + 240 = 289 > 0
```
**Two real roots exist, so the pole CAN be placed.** Solving:
```
x = (−7 ± √289)/2 = (−7 ± 17)/2   →   x = 5  or  x = −12

x is a distance, so reject −12.  x = 5
```
**The pole is 5 m from gate B and 12 m from gate A.**

> [!IMPORTANT]
> **The strategy worth learning here: to answer "is this possible?", form the equation and look at the DISCRIMINANT — you do not need to solve it.**
>
> **Discriminant negative → the situation is impossible.** **Discriminant ≥ 0 → it is possible**, and then you can go on to find the values.

## Summary

```
QUADRATIC EQUATION   ax² + bx + c = 0,  a ≠ 0,  a, b, c real
   standard form: terms in descending order of degree
   SIMPLIFY FIRST — terms may cancel, changing the degree either way

ROOT   α is a root if aα² + bα + c = 0
       the ZEROES of the polynomial = the ROOTS of the equation
       at most TWO roots

FACTORISATION   split the middle term, write as two linear factors,
                set each factor to zero
                (a product is zero only if a factor is zero)
                a repeated factor gives a REPEATED root

QUADRATIC FORMULA
      x = ( −b ± √(b² − 4ac) ) / (2a)        needs b² − 4ac ≥ 0

DISCRIMINANT  D = b² − 4ac
      D > 0   two DISTINCT real roots       parabola CUTS the x-axis
      D = 0   two EQUAL real roots, −b/2a    parabola TOUCHES the x-axis
      D < 0   NO real roots                  parabola MISSES the x-axis

to answer "is it possible?" — form the equation and check the sign of D;
solving is only needed afterwards

IN WORD PROBLEMS always reject roots that the situation forbids —
lengths, ages, counts and speeds cannot be negative
```
