## What this chapter is about

**Akhila goes to a fair.** She rides the Giant Wheel and plays Hoopla. She plays Hoopla **half as many times** as she rides. A ride costs ₹3, a game of Hoopla ₹4, and she spends ₹20 altogether. How many of each?

You could guess: 2 rides and 1 game cost 6 + 4 = 10 — too little. 4 rides and 2 games cost 12 + 8 = 20 — yes! But guessing won't work for harder numbers. Instead, name the unknowns:

```
x = number of rides,  y = number of Hoopla games

y = x/2            (1)   half as many games as rides
3x + 4y = 20       (2)   total spend
```

Two unknowns need **two** facts, so we get **two equations together** — a *pair of linear equations*. This chapter is about solving such pairs, by drawing and by algebra.

> [!IMPORTANT]
> **A linear equation in two variables** looks like **ax + by + c = 0**, where a, b, c are real numbers and a and b are not both 0. Its graph is always a **straight line**.
>
> **A pair** is two of them about the same x and y:
> ```
> a₁x + b₁y + c₁ = 0
> a₂x + b₂y + c₂ = 0
> ```
> **A solution** is a pair of values (x, y) that makes **both** equations true at once.

> [!NOTE]
> **Why one equation isn't enough:** 3x + 4y = 20 alone has endless solutions — (4, 2), (0, 5), (8, −1), … every point on its line. The second fact picks out the one we want.

## 3.2 Graphical method

### The idea

Each equation is a line. A point lies on a line exactly when it satisfies that equation. So a point satisfying **both** must lie on **both** lines — it's where they **cross**.

**Two lines on a sheet of paper can only do three things:**

| Lines | Picture | Solutions | Name |
|---|---|---|---|
| **intersect** | cross at one point | **exactly one** (unique) | consistent |
| **parallel** | never meet | **none** | inconsistent |
| **coincident** | lie on top of each other | **infinitely many** — every point on the line | consistent (dependent) |

> [!IMPORTANT]
> **Consistent** = has at least one solution. **Inconsistent** = has no solution.
> Coincident lines are called **dependent** — one equation is really the other in disguise.

### How to draw a line quickly

For each equation, find **two points** (three to be safe) — usually by putting x = 0 and y = 0.

**Example 1 — is x + 3y = 6 and 2x − 3y = 12 consistent? Solve graphically.**

| x + 3y = 6 | x = 0 → y = 2 | y = 0 → x = 6 |
|---|---|---|
| **2x − 3y = 12** | x = 0 → y = −4 | y = 0 → x = 6 |

Both lines pass through **(6, 0)**. So they intersect there: **x = 6, y = 0**, and the pair is **consistent**.

Check: 6 + 0 = 6 ✔ and 12 − 0 = 12 ✔.

**Example 3 — Champa's sale.** "The number of skirts is two less than twice the pants; also four less than four times the pants."

```
x = pants, y = skirts
y = 2x − 2
y = 4x − 4
```

Plot them: both pass through **(1, 0)**. So Champa bought **1 pant and 0 skirts** — a strange but correct answer! (Check: 2 − 2 = 0, 4 − 4 = 0 ✔.)

### Reading the answer without drawing — the ratio test

Rewrite ax + by + c = 0 as y = −(a/b)x − c/b. The number **−a/b is the slope** (how steep the line is) and −c/b is where it crosses the y-axis.

- **Different slopes** → the lines aren't parallel → they **cross once**.
- **Same slope, different crossing points** → **parallel**.
- **Same slope and same crossing point** → **the same line**.

Comparing slopes is the same as comparing a₁/a₂ with b₁/b₂. That gives a quick test:

> [!IMPORTANT]
> | Compare | Lines | Solutions |
> |---|---|---|
> | **a₁/a₂ ≠ b₁/b₂** | intersecting | exactly one |
> | **a₁/a₂ = b₁/b₂ = c₁/c₂** | coincident | infinitely many |
> | **a₁/a₂ = b₁/b₂ ≠ c₁/c₂** | parallel | none |
>
> **Why it works:** if all three ratios are equal (say to k), the first equation is just k × the second — the same line. If only a and b ratios match, the lines have the same tilt but are shifted — parallel. If the a and b ratios differ, the tilts differ, so the lines must cross.

**Example 2 — 5x − 8y + 1 = 0 and 3x − (24/5)y + 3/5 = 0.**

```
a₁/a₂ = 5/3      b₁/b₂ = −8 ÷ (−24/5) = 40/24 = 5/3      c₁/c₂ = 1 ÷ (3/5) = 5/3
```
All equal → **coincident → infinitely many solutions**. (Multiply the second equation by 5/3 and you get the first.)

**Example 7 — two rails: x + 2y − 4 = 0 and 2x + 4y − 12 = 0. Do they cross?**

```
1/2 = 2/4 ≠ −4/−12 = 1/3     → parallel → the rails never cross (good news for trains!)
```

### Exercise 3.1, worked

**1(i). 10 students in a quiz; girls are 4 more than boys.**

```
x = girls, y = boys
x + y = 10
x − y = 4
```
Table: x + y = 10 → (10, 0), (0, 10), (5, 5). x − y = 4 → (4, 0), (5, 1), (7, 3). The lines meet at **(7, 3)**: **7 girls, 3 boys**.

**1(ii). 5 pencils + 7 pens = ₹50; 7 pencils + 5 pens = ₹46.**

```
x = cost of a pencil, y = cost of a pen
5x + 7y = 50
7x + 5y = 46
```
The lines meet at **(3, 5)**: pencil **₹3**, pen **₹5**. (Check: 15 + 35 = 50 ✔, 21 + 25 = 46 ✔.)

**2. Intersect, parallel or coincident?**

```
(i)   5x − 4y + 8 = 0, 7x + 6y − 9 = 0     5/7 vs −4/6     different → INTERSECT
(ii)  9x + 3y + 12 = 0, 18x + 6y + 24 = 0  9/18 = 3/6 = 12/24 = 1/2 → COINCIDENT
(iii) 6x − 3y + 10 = 0, 2x − y + 9 = 0     6/2 = −3/−1 = 3, but 10/9 ≠ 3 → PARALLEL
```

**3. Consistent or inconsistent?**

```
(i)   3x + 2y = 5;  2x − 3y = 7            3/2 vs 2/−3 differ → consistent (one solution)
(ii)  2x − 3y = 8;  4x − 6y = 9            2/4 = −3/−6 = 1/2, but 8/9 ≠ 1/2 → INCONSISTENT
(iii) (3/2)x + (5/3)y = 7;  9x − 10y = 14  (3/2)/9 = 1/6, (5/3)/(−10) = −1/6 → differ → consistent
(iv)  5x − 3y = 11;  −10x + 6y = −22       5/−10 = −3/6 = 11/−22 = −1/2 → coincident → consistent
(v)   (4/3)x + 2y = 8;  2x + 3y = 12       (4/3)/2 = 2/3, 2/3, 8/12 = 2/3 → coincident → consistent
```

**4. Consistent? If so, solve graphically.**

- (i) x + y = 5, 2x + 2y = 10 → all ratios ½ → **coincident**, consistent, infinitely many solutions: any (x, 5 − x).
- (ii) x − y = 8, 3x − 3y = 16 → 1/3 = 1/3 ≠ 8/16 → **parallel**, inconsistent.
- (iii) 2x + y − 6 = 0, 4x − 2y − 4 = 0 → 2/4 ≠ 1/−2 → consistent. Lines meet at **(2, 2)**.
- (iv) 2x − 2y − 2 = 0, 4x − 4y − 5 = 0 → 2/4 = −2/−4 ≠ −2/−5 → **parallel**, inconsistent.

**5. Half the perimeter of a garden is 36 m; length is 4 m more than width.**

```
l = length, w = width
l + w = 36       (half the perimeter is just length + width)
l − w = 4
```
The lines meet at (20, 16): **length 20 m, width 16 m**.

**6. Given 2x + 3y − 8 = 0, write a partner that gives (i) intersecting (ii) parallel (iii) coincident lines.**

- (i) change the tilt, e.g. **3x + 2y − 7 = 0** (2/3 ≠ 3/2).
- (ii) same a, b; different c, e.g. **2x + 3y − 12 = 0**.
- (iii) multiply the whole thing, e.g. **4x + 6y − 16 = 0** (× 2).

**7. Draw x − y + 1 = 0 and 3x + 2y − 12 = 0; find the triangle they make with the x-axis.**

```
x − y + 1 = 0 meets the x-axis (y = 0) at x = −1  → (−1, 0)
3x + 2y − 12 = 0 meets it at x = 4                 → (4, 0)
the two lines meet: y = x + 1 → 3x + 2x + 2 = 12 → x = 2, y = 3 → (2, 3)
```
Vertices **(−1, 0), (4, 0), (2, 3)**. (Its area would be ½ × base 5 × height 3 = 7.5 square units.)

> [!TIP]
> Graphs are great for **seeing** what's happening, but an answer like x = 19/29 can't be read off graph paper. That's why we need algebra.

## 3.3 Algebraic methods

### 3.3.1 Substitution — "use one equation to replace a letter in the other"

> [!IMPORTANT]
> **Steps:**
> 1. From one equation, write one variable in terms of the other (choose the easiest, e.g. one with coefficient 1).
> 2. **Substitute** that into the **other** equation → now there's only one variable. Solve it.
> 3. Put the value back to get the second variable.
> 4. Check in both original equations.
>
> **Why it works:** in a solution, x and y are the *same* numbers in both equations. So if equation (2) says x = 3 − 2y, that's true in equation (1) as well, and we're allowed to swap it in.

**Example 4 — 7x − 15y = 2 and x + 2y = 3.**

```
From (2):  x = 3 − 2y
Into (1):  7(3 − 2y) − 15y = 2
           21 − 14y − 15y = 2
           −29y = −19   →   y = 19/29
Back:      x = 3 − 2(19/29) = (87 − 38)/29 = 49/29
```

**Example 5 — Aftab and his daughter.** "Seven years ago I was seven times as old as you. Three years from now I'll be three times as old."

```
s = Aftab's age, t = daughter's age (now)
s − 7 = 7(t − 7)    →  s − 7t + 42 = 0
s + 3 = 3(t + 3)    →  s − 3t = 6   →  s = 3t + 6

Substitute:  3t + 6 − 7t + 42 = 0  →  4t = 48  →  t = 12
             s = 3(12) + 6 = 42
```
Aftab is **42**, his daughter **12**. Check: 7 years ago 35 and 5 (35 = 7 × 5 ✔); in 3 years 45 and 15 (✔).

**What substitution tells you in the special cases:**

- **Example 6 — 2x + 3y = 9 and 4x + 6y = 18.** From the first, x = (9 − 3y)/2. Substitute: 2(9 − 3y) + 6y = 18 → 18 = 18. **True for every y** → infinitely many solutions (coincident lines).
- **Example 7 — x + 2y = 4 and 2x + 4y = 12.** From the first, x = 4 − 2y. Substitute: 8 − 4y + 4y = 12 → 8 = 12. **False whatever y is** → no solution (parallel).

> [!IMPORTANT]
> **When the variable vanishes:** a TRUE statement (like 18 = 18) → **infinitely many** solutions. A FALSE statement (like 8 = 12) → **no** solution.

### Exercise 3.2, worked

**1. Solve by substitution.**

```
(i)   x + y = 14, x − y = 4.    x = 4 + y → 4 + 2y = 14 → y = 5, x = 9

(ii)  s − t = 3, s/3 + t/2 = 6.  Clear fractions (×6): 2s + 3t = 36.
      s = t + 3 → 2t + 6 + 3t = 36 → t = 6, s = 9

(iii) 3x − y = 3, 9x − 3y = 9.   y = 3x − 3 → 9x − 9x + 9 = 9 → 9 = 9 (always true)
      → infinitely many solutions, y = 3x − 3 for any x

(iv)  0.2x + 0.3y = 1.3, 0.4x + 0.5y = 2.3.  ×10: 2x + 3y = 13, 4x + 5y = 23.
      x = (13 − 3y)/2 → 2(13 − 3y) + 5y = 23 → 26 − y = 23 → y = 3, x = 2

(v)   √2x + √3y = 0, √3x − √8y = 0.  From the first, x = −(√3/√2)y.
      √3(−√3/√2)y − √8y = 0 → y(−3/√2 − 2√2) = 0 → y = 0, so x = 0

(vi)  3x/2 − 5y/3 = −2, x/3 + y/2 = 13/6.  ×6 each: 9x − 10y = −12, 2x + 3y = 13.
      x = (13 − 3y)/2 → 9(13 − 3y)/2 − 10y = −12 → 117 − 27y − 20y = −24
      → 47y = 141 → y = 3, x = 2
```

> [!TIP]
> **Clear decimals and fractions first** by multiplying the whole equation by 10 or the LCM of the denominators. It's allowed because doing the same thing to both sides keeps an equation true.

**2. Solve 2x + 3y = 11 and 2x − 4y = −24, then find m for which y = mx + 3.**

```
From the first: 2x = 11 − 3y.  Into the second: 11 − 3y − 4y = −24 → y = 5, then 2x = −4 → x = −2
y = mx + 3:  5 = −2m + 3  →  m = −1
```

**3. Word problems** — the hard part is turning words into equations. Always say what x and y stand for.

```
(i)  Two numbers differ by 26; one is three times the other.
     x − y = 26, x = 3y → 2y = 26 → y = 13, x = 39

(ii) Supplementary angles (add to 180°); larger exceeds smaller by 18°.
     x + y = 180, x − y = 18 → x = 99°, y = 81°

(iii) 7 bats + 6 balls = ₹3800; 3 bats + 5 balls = ₹1750.
     From the second: x = (1750 − 5y)/3.  7(1750 − 5y)/3 + 6y = 3800
     → 12250 − 35y + 18y = 11400 → 17y = 850 → y = 50, x = 500
     Bat ₹500, ball ₹50

(iv) Taxi: fixed charge x + y per km. 10 km costs ₹105; 15 km costs ₹155.
     x + 10y = 105, x + 15y = 155 → subtract-by-substitution: x = 105 − 10y,
     105 + 5y = 155 → y = 10, x = 5.   25 km: 5 + 25 × 10 = ₹255

(v)  Fraction x/y: (x + 2)/(y + 2) = 9/11 and (x + 3)/(y + 3) = 5/6.
     Cross-multiply: 11x + 22 = 9y + 18 → 11x − 9y + 4 = 0
                     6x + 18 = 5y + 15  → 6x − 5y + 3 = 0
     → x = 7, y = 9.  The fraction is 7/9.

(vi) Jacob x, son y. In 5 years: x + 5 = 3(y + 5). 5 years ago: x − 5 = 7(y − 5).
     x − 3y = 10 and x − 7y = −30 → x = 3y + 10 → 3y + 10 − 7y = −30 → y = 10, x = 40
```

### 3.3.2 Elimination — "add or subtract the equations to kill one variable"

**Example 8 — incomes in ratio 9 : 7, spending in ratio 4 : 3, each saves ₹2000 a month.**

Use the ratios to name things: incomes 9x and 7x, spending 4y and 3y. Savings = income − spending:

```
9x − 4y = 2000     (1)
7x − 3y = 2000     (2)
```
Make the y-coefficients equal: (1) × 3 and (2) × 4:

```
27x − 12y = 6000
28x − 12y = 8000
Subtract:  x = 2000
```
Incomes: 9 × 2000 = **₹18000** and 7 × 2000 = **₹14000**. (Then y = 4000: spending ₹16000 and ₹12000, savings ₹2000 each ✔.)

> [!IMPORTANT]
> **Elimination steps:**
> 1. Multiply one or both equations so that one variable has the **same (or opposite) coefficient** in both.
> 2. **Subtract** (or **add**) the equations — that variable disappears.
> 3. Solve the one-variable equation, then substitute back.
>
> **Why it works:** if A = B and C = D are both true, then A − C = B − D is true too — you're taking equal amounts from equal amounts. And multiplying an equation by a non-zero number doesn't change which (x, y) satisfy it.

**Example 9 — 2x + 3y = 8 and 4x + 6y = 7.** Multiply the first by 2: 4x + 6y = 16. Subtract the second: 0 = 9. **False** → **no solution** (parallel).

**Example 10 — a two-digit number plus its reverse is 66; the digits differ by 2.**

A two-digit number with tens digit x and units digit y **is worth 10x + y** (that's what place value means). Its reverse is 10y + x.

```
(10x + y) + (10y + x) = 66  →  11x + 11y = 66  →  x + y = 6
digits differ by 2:  x − y = 2  OR  y − x = 2

Case 1: x + y = 6, x − y = 2 → add: 2x = 8 → x = 4, y = 2 → 42
Case 2: x + y = 6, y − x = 2 → add: 2y = 8 → y = 4, x = 2 → 24
```
**Two numbers: 42 and 24.**

> [!TIP]
> **Substitution or elimination?** If a variable already has coefficient 1 (like x + 2y = 3), substitution is quick. If the coefficients are messy but matchable (like 7x + 6y and 3x + 5y), elimination is usually tidier. Both always give the same answer.

```
(i)  Fraction x/y: (x + 1)/(y − 1) = 1 and x/(y + 1) = 1/2

     Subtract: x = 3, y = 5.   Fraction 3/5

(iii) Digits: tens x, units y. x + y = 9.  9(10x + y) = 2(10y + x)
     90x + 9y = 20y + 2x → 88x = 11y → y = 8x

## In a nutshell

- A **pair of linear equations** = two straight lines. A **solution** = a point on both.
- **Intersecting** (a₁/a₂ ≠ b₁/b₂) → one solution. **Coincident** (all three ratios equal) → infinitely many. **Parallel** (a, b ratios equal, c ratio different) → none.
- **Consistent** = at least one solution; **inconsistent** = none.
- **Substitution:** make one variable the subject, substitute into the other equation.
- **Elimination:** multiply to match coefficients, then add or subtract.
- Variable vanishes leaving a **true** statement → infinitely many; a **false** one → none.

> [!WARNING]
> **Top traps:** write both equations in the same form (ax + by + c = 0) before comparing ratios — signs matter · substitute into the OTHER equation, not the one you rearranged · when subtracting equations, subtract every term, including the right side · two-digit number = 10x + y, not xy · in age problems apply "years ago/hence" to BOTH people · always check your answer in both original equations.
