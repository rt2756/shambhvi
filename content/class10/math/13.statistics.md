## 13.1 What this chapter adds

**Class 9 gave the three MEASURES OF CENTRAL TENDENCY — mean, median and mode — for UNGROUPED data.**

**This chapter extends all three to GROUPED data**, and introduces **cumulative frequency**, the **cumulative frequency distribution**, and the curves called **OGIVES**.

## 13.2 Mean of grouped data

**For ungrouped data with values `x₁, x₂, …` occurring `f₁, f₂, …` times:**
```
mean  x̄ = (f₁x₁ + f₂x₂ + … + fₙxₙ) / (f₁ + f₂ + … + fₙ)

written with the summation sign Σ:     x̄ = Σfᵢxᵢ / Σfᵢ
```

> [!IMPORTANT]
> **For GROUPED data we do not know the individual values — only which class each falls in.**
>
> **So we ASSUME every observation in a class equals the CLASS MARK — the midpoint of the class.**
> ```
> class mark  xᵢ = (upper limit + lower limit) / 2
> ```
> **This is an assumption, and it is why the answer is an approximate mean.** Grouping has thrown information away, and the class mark is the best single stand-in for what was lost.

### Method 1 — direct method

```
x̄ = Σfᵢxᵢ / Σfᵢ
```
**Simple, but tedious when the numbers are large.**

### Method 2 — assumed mean method

**Choose one class mark as the ASSUMED MEAN, a — preferably one near the CENTRE of the values, to keep the deviations small.**

```
dᵢ = xᵢ − a

x̄ = a + (Σfᵢdᵢ / Σfᵢ)
```

**Why it works:**
```
mean of the deviations  d̄ = Σfᵢ(xᵢ − a)/Σfᵢ
                           = Σfᵢxᵢ/Σfᵢ  −  a·Σfᵢ/Σfᵢ
                           = x̄ − a

so    x̄ = a + d̄
```
**Subtracting a from every value shifts the mean down by exactly a — so adding a back restores it.**

> [!IMPORTANT]
> **THE MEAN DOES NOT DEPEND ON THE CHOICE OF a.** Any class mark may be used, and the answer is identical.
>
> **So a is chosen purely for CONVENIENCE** — pick the one that makes the arithmetic easiest, usually a central value.

### Method 3 — step-deviation method

**If all the deviations are multiples of the class size h, divide them by h too:**
```
uᵢ = (xᵢ − a)/h

x̄ = a + h × (Σfᵢuᵢ / Σfᵢ)
```

**Worked, on the same data (a = 47.5, h = 15):**
```
direct:          x̄ = 1860/30 = 62
assumed mean:    x̄ = 47.5 + 435/30 = 47.5 + 14.5 = 62
step deviation:  x̄ = 47.5 + 15 × (29/30) = 47.5 + 14.5 = 62
```

> [!IMPORTANT]
> **All three methods give the SAME answer — they are the same calculation, arranged to make the arithmetic lighter.**
>
> **The assumed mean and step-deviation methods are just simplified forms of the direct method.**
>
> **Which to choose:**
> - **small, simple numbers** → the **direct** method
> - **numerically large xᵢ and fᵢ** → the **assumed mean** method
> - **large numbers AND equal class sizes** → the **step-deviation** method
>
> **Step deviation needs EQUAL class sizes; the other two do not.**

## 13.3 Mode of grouped data

> [!IMPORTANT]
> **The MODAL CLASS is the class with the MAXIMUM frequency.** The mode is a value inside it, given by
> ```
> Mode = l + [ (f₁ − f₀) / (2f₁ − f₀ − f₂) ] × h
>
> where   l  = lower limit of the modal class
>         h  = class size
>         f₁ = frequency of the MODAL class
>         f₀ = frequency of the class PRECEDING the modal class
>         f₂ = frequency of the class SUCCEEDING the modal class
> ```

> [!TIP]
> **What the formula is doing: it places the mode INSIDE the modal class, pulled towards whichever neighbour is busier.**
>
> If `f₀ = f₂` the two neighbours balance and the mode sits exactly in the middle of the class. **If the class before is much fuller, the mode shifts towards the lower limit; if the class after is fuller, it shifts higher.**
>
> **A sanity check: the answer must lie BETWEEN the modal class's limits.** If it does not, something has gone wrong.

**Worked:** modal class 40–55 with `l = 40, h = 15, f₁ = 7, f₀ = 3, f₂ = 6`:
```
Mode = 40 + [(7 − 3)/(14 − 3 − 6)] × 15
     = 40 + (4/5) × 15
     = 40 + 12 = 52
```

## 13.4 Median of grouped data

> [!IMPORTANT]
> **THE MEDIAN CLASS is the class whose CUMULATIVE FREQUENCY is greater than (and nearest to) n/2.**
> ```
> Median = l + [ (n/2 − cf) / f ] × h
>
> where   l  = lower limit of the MEDIAN class
>         n  = total number of observations
>         cf = cumulative frequency of the class PRECEDING the median class
>         f  = frequency of the median class
>         h  = class size
> ```

> [!TIP]
> **What the formula is doing: it walks you into the median class and stops at the right point.**
>
> `n/2` is how far along you must go; `cf` is how far you had already got before entering this class. **The difference `(n/2 − cf)` is how much further you must travel INSIDE the class**, out of the `f` observations it contains — and that fraction of the class width `h` is added to the lower limit.

**Worked:** `n = 53`, so `n/2 = 26.5`. The class 60–70 has cumulative frequency 29, the first exceeding 26.5 — so it is the median class, with `l = 60, cf = 22, f = 7, h = 10`:
```
Median = 60 + [(26.5 − 22)/7] × 10
       = 60 + 45/7
       = 66.4
```
**Meaning: about half the students scored below 66.4 and half above.**

> [!IMPORTANT]
> **For the median you must use the CUMULATIVE frequency, not the ordinary frequency.**
>
> **CUMULATIVE FREQUENCY of a class = the sum of all frequencies up to and including that class.**

## "Less than" and "more than" distributions

**A distribution given as "less than 140: 4, less than 145: 11, less than 150: 29, …" is already CUMULATIVE.**

> [!IMPORTANT]
> **To recover the ordinary frequencies, SUBTRACT consecutive entries:**
> ```
> below 140       4
> 140–145      11 − 4  = 7
> 145–150      29 − 11 = 18
> 150–155      40 − 29 = 11
> ...
> ```
> **The given numbers are the UPPER LIMITS of the classes**, so the classes are `below 140`, `140–145`, `145–150`, and so on.

## Choosing between the three measures

> [!IMPORTANT]
> - **MEAN** uses **every** observation, so it reflects all the data — but it is **dragged by extreme values**.
> - **MEDIAN** is the **middle** value; extreme values do not move it, so it is better for **skewed** data.
> - **MODE** is the **most frequent** value — the right choice when you want the *typical* or *most common* case, such as the shoe size a shop should stock most of.

## Summary

```
GROUPED DATA — the individual values are unknown, so every observation in a
class is taken to be the CLASS MARK (the midpoint). The mean is therefore
APPROXIMATE.

MEAN — three methods, all giving the SAME answer
   direct           x̄ = Σfᵢxᵢ / Σfᵢ
   assumed mean     x̄ = a + Σfᵢdᵢ/Σfᵢ            where dᵢ = xᵢ − a
   step deviation   x̄ = a + h(Σfᵢuᵢ/Σfᵢ)         where uᵢ = (xᵢ − a)/h
   the value of a makes no difference to the answer — choose it for convenience
   step deviation needs EQUAL class sizes

MODE   modal class = the class of MAXIMUM frequency
   Mode = l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h
   the answer must lie inside the modal class; it leans towards the busier neighbour

MEDIAN  median class = the first class whose CUMULATIVE frequency exceeds n/2
   Median = l + [(n/2 − cf)/f] × h
   (n/2 − cf) is how much further you must travel INSIDE the median class

CUMULATIVE FREQUENCY = the running total of frequencies
   a "less than" table is already cumulative — SUBTRACT consecutive entries to
   recover the ordinary frequencies, and read the given numbers as UPPER limits

WHICH MEASURE   mean uses all the data but is pulled by extremes;
                median ignores extremes and suits skewed data;
                mode gives the most COMMON value
```
