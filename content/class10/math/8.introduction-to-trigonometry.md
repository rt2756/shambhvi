## What this chapter is about

Students on a trip see the **Qutub Minar**. One of them wonders: *how tall is it?* You can't climb it with a tape. But if you stand a known distance away and measure the **angle** you look up at the top, a right triangle forms — and the angle and one side are enough to find the height.

**Trigonometry** ("tri" three + "gon" sides + "metron" measure) is the study of the link between the **angles** and the **sides** of a triangle. This chapter sets up the tools: six ratios, their values for special angles, and identities connecting them. Chapter 9 uses them on real heights and distances.

## 8.2 Trigonometric ratios

### Naming the sides

Take △ABC with the **right angle at B**, and focus on the acute angle **A**:

- **Hypotenuse** AC — opposite the right angle (always the longest side).
- **Side opposite ∠A** — BC (the side across from A).
- **Side adjacent to ∠A** — AB (the side next to A that isn't the hypotenuse).

> [!WARNING]
> **"Opposite" and "adjacent" depend on which angle you look from.** From ∠C, the opposite side is AB and the adjacent side is BC — they swap. The hypotenuse never changes.

### The six ratios

> [!IMPORTANT]
> ```
> sin A  = opposite / hypotenuse   = BC/AC
> cos A  = adjacent / hypotenuse   = AB/AC
> tan A  = opposite / adjacent     = BC/AB
>
> cosec A = 1/sin A = hypotenuse / opposite
> sec A   = 1/cos A = hypotenuse / adjacent
> cot A   = 1/tan A = adjacent / opposite
> ```
> and also **tan A = sin A / cos A**, **cot A = cos A / sin A**.
>
> **Why tan = sin/cos:** (BC/AC) ÷ (AB/AC) = BC/AB — the hypotenuses cancel.

> [!TIP]
> A memory line: **"Some People Have Curly Brown Hair Through Proper Brushing"** — Sin = P/H, Cos = B/H, Tan = P/B (P = perpendicular/opposite, B = base/adjacent, H = hypotenuse).

> [!NOTE]
> **sin A is one symbol**, not "sin × A". Without an angle, "sin" means nothing — just like "√" alone. Also, (sin A)² is written **sin² A**.

### Why the ratios depend only on the angle

Draw a bigger right triangle with the same angle A: take P on AC (extended) and drop a perpendicular PM to AB. Now △PAM ~ △CAB (**AA** — they share ∠A and both have a right angle). So their sides are in proportion:

```
MP/AP = BC/AC     →    sin A is the same in both triangles
```

> [!IMPORTANT]
> **The trigonometric ratios of an angle don't depend on the size of the triangle — only on the angle.** That's exactly why they're useful: measure a small triangle, and you know the ratio for the big one.

### Because sides are positive and the hypotenuse is longest

- **sin A and cos A are always ≤ 1** (opposite or adjacent ÷ the longest side).
- **sec A and cosec A are always ≥ 1**.
- **tan A** can be anything positive — tan 60° = √3 > 1.

### Finding all ratios from one

**Example 1 — tan A = 4/3. Find the rest.** tan A = opposite/adjacent, so take BC = 4k, AB = 3k (any k > 0 — remember, size doesn't matter).

```
AC² = (4k)² + (3k)² = 25k²   →   AC = 5k
sin A = 4/5,   cos A = 3/5,   cosec A = 5/4,   sec A = 5/3,   cot A = 3/4
```

**Example 2 — if sin B = sin Q (both acute), then ∠B = ∠Q.** In right triangles ABC (right at C) and PQR (right at R), sin B = AC/AB, sin Q = PR/PQ. Equal, so AC/PR = AB/PQ = k. By Pythagoras, BC = √(AB² − AC²) = k × √(PQ² − PR²) = k × QR. So all three sides are in ratio k → **SSS similarity** → ∠B = ∠Q.

**Example 3 — △ACB, right at C, AB = 29, BC = 21, ∠ABC = θ.** AC = √(29² − 21²) = √(841 − 441) = **20**.

```
sin θ = 20/29,  cos θ = 21/29
(i)  cos²θ + sin²θ = (441 + 400)/841 = 1
(ii) cos²θ − sin²θ = (441 − 400)/841 = 41/841
```

**Example 4 — right at B, tan A = 1. Verify 2 sin A cos A = 1.** tan A = 1 means BC = AB = k, so AC = √2 k. sin A = cos A = 1/√2, and 2 × (1/√2)(1/√2) = **1** ✔.

**Example 5 — △OPQ right at P, OP = 7 cm, OQ − PQ = 1 cm. Find sin Q, cos Q.**

```
OQ² − PQ² = OP² = 49
(OQ − PQ)(OQ + PQ) = 49   →   1 × (OQ + PQ) = 49
OQ + PQ = 49,  OQ − PQ = 1   →   OQ = 25,  PQ = 24
sin Q = OP/OQ = 7/25,   cos Q = PQ/OQ = 24/25
```

### Exercise 8.1, worked

**1. Right at B, AB = 24, BC = 7.** AC = √(576 + 49) = √625 = 25.
(i) sin A = BC/AC = **7/25**, cos A = AB/AC = **24/25**. (ii) From C the roles swap: sin C = AB/AC = **24/25**, cos C = BC/AC = **7/25**.

**2. Fig. 8.13: PQ = 12, PR = 13, right angle at Q.** QR = √(169 − 144) = 5. tan P = QR/PQ = 5/12, cot R = QR/PQ = 5/12 → tan P − cot R = **0**.

**3. sin A = 3/4.** Opposite 3k, hypotenuse 4k, adjacent √(16 − 9)k = √7 k → cos A = **√7/4**, tan A = **3/√7**.

**4. 15 cot A = 8** → cot A = 8/15: adjacent 8k, opposite 15k, hypotenuse 17k → sin A = **15/17**, sec A = **17/8**.

**5. sec θ = 13/12:** hypotenuse 13k, adjacent 12k, opposite 5k → sin θ = 5/13, cos θ = 12/13, tan θ = 5/12, cot θ = 12/5, cosec θ = 13/5.

**6. cos A = cos B (acute) ⇒ ∠A = ∠B.** Put them in one right triangle ABC (right at C): cos A = AC/AB and cos B = BC/AB. Equal → AC = BC → the triangle is isosceles → **∠A = ∠B**.

**7. cot θ = 7/8.** (1 + sin θ)(1 − sin θ) = 1 − sin²θ = cos²θ and (1 + cos θ)(1 − cos θ) = sin²θ. So (i) = cos²θ/sin²θ = cot²θ = **49/64**, and (ii) cot²θ = **49/64**.

**8. 3 cot A = 4** → tan A = 3/4, so sides 3, 4, 5: sin A = 3/5, cos A = 4/5.

```
(1 − tan²A)/(1 + tan²A) = (1 − 9/16)/(1 + 9/16) = (7/16)/(25/16) = 7/25
cos²A − sin²A = 16/25 − 9/25 = 7/25          → YES, equal
```

**9. Right at B, tan A = 1/√3** → A = 30°, C = 60°.
(i) sin A cos C + cos A sin C = ½ × ½ + (√3/2)(√3/2) = **1**. (ii) cos A cos C − sin A sin C = (√3/2)(½) − (½)(√3/2) = **0**.

**10. Right at Q, PR + QR = 25, PQ = 5.** PR² − QR² = 25 → (PR − QR)(25) = 25 → PR − QR = 1 → PR = 13, QR = 12.
sin P = QR/PR = **12/13**, cos P = PQ/PR = **5/13**, tan P = **12/5**.

**11. True or false?**
(i) tan A < 1 always — **False** (tan 60° = √3). (ii) sec A = 12/5 for some A — **True** (12/5 > 1; take hypotenuse 12, adjacent 5). (iii) "cos" is short for cosecant — **False**, it's cosine. (iv) cot A = cot × A — **False**, cot A is one symbol. (v) sin θ = 4/3 for some θ — **False**, sin θ ≤ 1.

## 8.3 Ratios of specific angles

### 45°

In △ABC right at B with ∠A = 45°, ∠C = 45° too, so **AB = BC = a**. Then AC = √(a² + a²) = a√2.

```
sin 45° = a/(a√2) = 1/√2      cos 45° = 1/√2      tan 45° = 1
```

### 30° and 60°

Take an **equilateral** triangle ABC with side 2a, and drop AD ⊥ BC. AD bisects BC (BD = a) and ∠A (∠BAD = 30°), and ∠B = 60°. AD = √(4a² − a²) = a√3.

```
In △ABD:   hypotenuse AB = 2a,  BD = a,  AD = a√3
sin 30° = BD/AB = 1/2         cos 30° = AD/AB = √3/2       tan 30° = 1/√3
sin 60° = AD/AB = √3/2        cos 60° = BD/AB = 1/2        tan 60° = √3
```

### 0° and 90°

Imagine ∠A shrinking toward 0: the opposite side BC shrinks to 0 and AC becomes almost AB. So **sin 0° = 0, cos 0° = 1**. As ∠A grows toward 90°, AB shrinks to 0 and BC becomes almost AC, so **sin 90° = 1, cos 90° = 0**.

> [!IMPORTANT]
> | ∠A | 0° | 30° | 45° | 60° | 90° |
> |---|---|---|---|---|---|
> | **sin A** | 0 | 1/2 | 1/√2 | √3/2 | 1 |
> | **cos A** | 1 | √3/2 | 1/√2 | 1/2 | 0 |
> | **tan A** | 0 | 1/√3 | 1 | √3 | not defined |
> | **cosec A** | not defined | 2 | √2 | 2/√3 | 1 |
> | **sec A** | 1 | 2/√3 | √2 | 2 | not defined |
> | **cot A** | not defined | √3 | 1 | 1/√3 | 0 |
>
> **Why "not defined":** tan 90° = sin 90°/cos 90° = 1/0, and you can't divide by 0.

> [!TIP]
> **Build the sin row from √0/2, √1/2, √2/2, √3/2, √4/2** = 0, ½, 1/√2, √3/2, 1. The **cos row is the same backwards**. tan = sin ÷ cos.
>
> As the angle goes from 0° to 90°: **sin increases** (0 → 1), **cos decreases** (1 → 0).

**Example 6 — right at B, AB = 5 cm, ∠ACB = 30°. Find BC and AC.** From C, AB is opposite and BC adjacent:

```
tan 30° = AB/BC → 1/√3 = 5/BC → BC = 5√3 cm
sin 30° = AB/AC → 1/2 = 5/AC  → AC = 10 cm
```

**Example 7 — right at Q, PQ = 3, PR = 6. Find ∠QPR and ∠PRQ.** sin R = PQ/PR = 3/6 = ½ → **∠PRQ = 30°**, so **∠QPR = 60°**.

**Example 8 — sin(A − B) = ½, cos(A + B) = ½. Find A and B.** A − B = 30° and A + B = 60° → **A = 45°, B = 15°**.

### Exercise 8.2, worked

(iii) cos45 / (sec30 + cosec30) = (1/√2) / (2/√3 + 2)

## 8.4 Trigonometric identities

An **identity** is an equation true for **every** value of the angle (where both sides are defined) — like (a + b)² = a² + 2ab + b² is true for all a, b.

### The first identity, from Pythagoras

In △ABC right at B: **AB² + BC² = AC²**. Divide every term by AC²:

```
(AB/AC)² + (BC/AC)² = 1      →      cos²A + sin²A = 1
```

> [!IMPORTANT]
> **The three identities** (0° ≤ A ≤ 90°, wherever defined):
> ```
> sin²A + cos²A = 1
> 1 + tan²A = sec²A          (0° ≤ A < 90°)
> cot²A + 1 = cosec²A        (0° < A ≤ 90°)
> ```
> **Why:** all three are Pythagoras. Divide AB² + BC² = AC² by **AC²** for the first, by **AB²** for the second (1 + (BC/AB)² = (AC/AB)²), and by **BC²** for the third.

> [!TIP]
> **Rearranged forms you'll use constantly:** cos²A = 1 − sin²A, sec²A − tan²A = 1, cosec²A − cot²A = 1, and (sec A − tan A)(sec A + tan A) = 1.

**Example 9 — cos A, tan A, sec A in terms of sin A.**

```
cos A = √(1 − sin²A)      tan A = sin A / √(1 − sin²A)      sec A = 1/√(1 − sin²A)
```

**Example 10 — prove sec A(1 − sin A)(sec A + tan A) = 1.**

```
LHS = (1/cos A)(1 − sin A)(1/cos A + sin A/cos A)
    = (1 − sin A)(1 + sin A)/cos²A = (1 − sin²A)/cos²A = cos²A/cos²A = 1 = RHS
```

**Example 11 — prove (cot A − cos A)/(cot A + cos A) = (cosec A − 1)/(cosec A + 1).**

```
LHS = (cos A/sin A − cos A)/(cos A/sin A + cos A)
    = cos A(1/sin A − 1) / cos A(1/sin A + 1) = (cosec A − 1)/(cosec A + 1) = RHS
```

**Example 12 — prove (sin θ − cos θ + 1)/(sin θ + cos θ − 1) = 1/(sec θ − tan θ), using sec²θ = 1 + tan²θ.** Divide top and bottom by cos θ:

```
LHS = (tan θ − 1 + sec θ)/(tan θ + 1 − sec θ)
multiply top and bottom by (tan θ − sec θ):
    = [(tan θ + sec θ) − 1](tan θ − sec θ) / [(tan θ − sec θ + 1)(tan θ − sec θ)]
top = (tan²θ − sec²θ) − (tan θ − sec θ) = −1 − tan θ + sec θ
    = −(tan θ − sec θ + 1)
so LHS = −1/(tan θ − sec θ) = 1/(sec θ − tan θ) = RHS
```

> [!TIP]
> **Strategy for proving identities:**
> 1. Start from the **more complicated side**.
> 2. If stuck, **convert everything to sin and cos**.
> 3. Look for **1 − sin², 1 − cos², sec² − tan²** to swap using the identities.
> 4. Combine fractions; factor; cancel.
> 5. Never move terms across the "=" — you're proving the equation, not assuming it.

### Exercise 8.3, worked

**1. sin A, sec A, tan A in terms of cot A.** From cosec²A = 1 + cot²A:

```
sin A = 1/√(1 + cot²A)      sec A = √(1 + cot²A)/cot A      tan A = 1/cot A
```

**2. Everything in terms of sec A.** From tan²A = sec²A − 1:

```
cos A = 1/sec A       tan A = √(sec²A − 1)       sin A = √(sec²A − 1)/sec A
cot A = 1/√(sec²A − 1)          cosec A = sec A/√(sec²A − 1)
```

**3. Choose the option.**

```
(i)   9sec²A − 9tan²A = 9(sec²A − tan²A) = 9                         → (B)
(ii)  (1 + tanθ + secθ)(1 + cotθ − cosecθ)
      = [(cosθ + sinθ + 1)/cosθ] × [(sinθ + cosθ − 1)/sinθ]
      = [(sinθ + cosθ)² − 1]/(sinθ cosθ) = 2sinθcosθ/(sinθcosθ) = 2   → (C)
(iii) (secA + tanA)(1 − sinA) = [(1 + sinA)/cosA](1 − sinA) = cos²A/cosA = cosA   → (D)
(iv)  (1 + tan²A)/(1 + cot²A) = sec²A/cosec²A = sin²A/cos²A = tan²A   → (D)
```

**4. Prove.**

```
(i)  (cosecθ − cotθ)² = [(1 − cosθ)/sinθ]² = (1 − cosθ)²/(1 − cos²θ)
     = (1 − cosθ)²/[(1 − cosθ)(1 + cosθ)] = (1 − cosθ)/(1 + cosθ)  ✔

(ii) cosA/(1 + sinA) + (1 + sinA)/cosA = [cos²A + (1 + sinA)²]/[(1 + sinA)cosA]
     = (cos²A + sin²A + 1 + 2sinA)/[(1 + sinA)cosA] = 2(1 + sinA)/[(1 + sinA)cosA] = 2secA  ✔

(iii) with s = sinθ, c = cosθ:
     tanθ/(1 − cotθ) = s²/[c(s − c)],     cotθ/(1 − tanθ) = −c²/[s(s − c)]
     sum = (s³ − c³)/[sc(s − c)] = (s² + sc + c²)/(sc) = (1 + sc)/(sc) = 1 + secθ cosecθ  ✔

(iv) LHS = (1 + secA)/secA = cosA + 1
     RHS = sin²A/(1 − cosA) = (1 − cosA)(1 + cosA)/(1 − cosA) = 1 + cosA  ✔

(v)  divide top and bottom by sinA: (cotA − 1 + cosecA)/(cotA + 1 − cosecA)
     replace the 1 on top by cosec²A − cot²A:
     top = (cotA + cosecA) − (cosecA − cotA)(cosecA + cotA) = (cotA + cosecA)(1 − cosecA + cotA)
     the bracket cancels with the bottom → cosecA + cotA  ✔

(vi) √[(1 + sinA)/(1 − sinA)] = √[(1 + sinA)²/(1 − sin²A)] = (1 + sinA)/cosA = secA + tanA  ✔

(vii) (sinθ − 2sin³θ)/(2cos³θ − cosθ) = sinθ(1 − 2sin²θ)/[cosθ(2cos²θ − 1)]
     and 1 − 2sin²θ = 1 − 2(1 − cos²θ) = 2cos²θ − 1, which cancels → tanθ  ✔

(viii) (sinA + cosecA)² + (cosA + secA)² = sin²A + cosec²A + 2 + cos²A + sec²A + 2
     = 5 + cosec²A + sec²A = 5 + (1 + cot²A) + (1 + tan²A) = 7 + tan²A + cot²A  ✔

(ix) LHS = (1/s − s)(1/c − c) = (c²/s)(s²/c) = sc
     RHS = 1/(s/c + c/s) = sc/(s² + c²) = sc  ✔

(x)  (1 + tan²A)/(1 + cot²A) = sec²A/cosec²A = tan²A
     and (1 − tanA)/(1 − cotA) = (1 − tanA)/[(tanA − 1)/tanA] = −tanA, squared = tan²A  ✔
```

## In a nutshell

- In a right triangle: **sin = opp/hyp, cos = adj/hyp, tan = opp/adj**; cosec, sec, cot are their reciprocals; **tan = sin/cos**.
- The ratios depend **only on the angle** (similar triangles).
- **sin, cos ≤ 1; sec, cosec ≥ 1.**
- **Special values:** sin 0, 30, 45, 60, 90 = 0, ½, 1/√2, √3/2, 1; cos is the reverse; tan 90° and cot 0° are not defined.
- **Identities:** sin² + cos² = 1, 1 + tan² = sec², 1 + cot² = cosec² — each is Pythagoras divided by a side².

> [!WARNING]
> **Top traps:** opposite/adjacent swap when you change the angle · sin²A means (sin A)², not sin(A²) · sin(A + B) ≠ sin A + sin B · tan 90° is NOT infinity on a test — write "not defined" · cos decreases from 0° to 90° · when finding ratios from one ratio, use k for sides and Pythagoras for the third side · in identities, work on one side — don't cross-multiply both.
