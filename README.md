# Shambhvi

Personal learning materials for Shambhvi (class 7, CBSE, India).

## Layout

| Path | What it is |
|---|---|
| `mathematics.md` | Original hand-written math notes (started from NCERT Class 6 Chapter 15). Foundation topics on the website are derived from this file. |
| `learning_website/` | Next.js site Shambhvi runs locally to read notes, take quizzes, and chat with an AI tutor. See [`learning_website/README.md`](learning_website/README.md) to run it. |

## Quick start

```bash
cd learning_website
npm install
npm run dev
```

Then open `http://localhost:3000`.
