# Rational Numbers

**Rational** = $\dfrac{p}{q}$, $p,q$ integers, $q\ne0$ · e.g. $\frac34,\ \frac{-5}{2},\ 7=\frac71,\ 0=\frac01$
Every integer is rational · same sign → positive, different sign → negative

## Standard form

- Denominator **positive**, fully simplified
- $\dfrac{-8}{12}\to\dfrac{-2}{3}$ · $\dfrac{4}{-6}\to\dfrac{-4}{6}\to\dfrac{-2}{3}$

## Compare

- Same denominator → compare numerators · $\frac27<\frac57$
- Different → make denominators equal (LCM) · $\frac23$ vs $\frac34$ → $\frac{8}{12}$ vs $\frac{9}{12}$
- Any negative < any positive

## Operations

- ± same denom → ± numerators · diff denom → LCM first · $\frac14+\frac16=\frac{3}{12}+\frac{2}{12}=\frac{5}{12}$
- × → tops×tops, bottoms×bottoms · $\frac23\times\frac{-4}{5}=\frac{-8}{15}$
- ÷ → × reciprocal · $\frac23\div\frac45=\frac23\times\frac54=\frac56$
- Sign rules same as integers

**⚠️** denominator never 0 · $\frac{-3}{4}=\frac{3}{-4}$ (both $=-\frac34$) · add only after equal denominators · compare by value, not digit size
