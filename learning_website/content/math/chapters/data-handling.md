# Data Handling

**Data** = collected numbers/facts · **Frequency** = how many times a value occurs

## Representative values

- **Mean** $=\dfrac{\text{sum}}{\text{count}}$ · e.g. 8,7,9,6,10 → $\frac{40}{5}=8$
- **Median** = middle of **sorted** data · 6,7,8,9,10 → 8 · even count → average of 2 middle values
- **Mode** = most frequent · 5,7,5,8,5 → 5 · a list can have none or many

## Bar graphs

- Equal-width bars, height = frequency · **double bar** compares two groups
- Always label both axes + write the scale

## Probability

- $P(\text{event}) = \dfrac{\text{favourable outcomes}}{\text{total outcomes}}$ · always between 0 and 1
- 0 = impossible · 1 = certain
- Coin: $P(\text{heads})=\frac12$ · Die: $P(4)=\frac16$, $P(\text{even})=\frac36=\frac12$

**⚠️** mean ≠ median (median needs sorting) · mode = **most** frequent (not 2nd) · $P$ never > 1 · no scale on a bar graph = meaningless
