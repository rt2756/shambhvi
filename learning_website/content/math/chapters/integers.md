# Integers

**Integer** = …, −3, −2, −1, 0, 1, 2, 3, … — no fractions/decimals. **0 is neither + nor −.**

**Order:** further right on the number line = bigger → $-2 > -5$ · every negative < every positive.

## Addition

- Same sign → add values, keep sign · e.g. $(-4)+(-3) = -7$
- Different signs → subtract smaller from larger, keep larger's sign · e.g. $7+(-2) = 5$
- $a + 0 = a$

## Subtraction

- $a - b = a + (-b)$ · two minuses → plus · e.g. $4-(-3) = 4+3 = 7$

## Multiplication & division — signs

- Same signs → **+** · different signs → **−**
- $(-6)\times4 = -24$ · $(-7)\times(-3) = 21$ · $(-24)\div6 = -4$
- Negatives in a product: odd count → −, even → + · e.g. $(-2)^3 = -8$

## Properties (hold for + and ×, not − or ÷)

- Closure · Commutative $a+b=b+a$ · Associative $(a+b)+c=a+(b+c)$
- Identity $a+0=a,\ a\times1=a$ · Zero $a\times0=0$ · Distributive $a(b+c)=ab+ac$
- Shortcut · e.g. $7\times99 = 7(100-1) = 693$

**⚠️** $-8>-3$ ✗ (it's $-3>-8$) · $4-(-3)=1$ ✗ (=7) · $(-2)^3=+8$ ✗ (=−8) · $0\div7=0$ ✓ but $7\div0$ = undefined
