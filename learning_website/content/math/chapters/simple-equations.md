# Simple Equations

**Variable** = letter for unknown ($x$) · **Constant** = fixed number · **Equation** = two expressions joined by $=$ (a balance scale)

## Set up from words

- Pick a variable, translate "is / equals" → $=$ · e.g. "3 more than twice the age is 19" → $2x+3=19$

## Solve — balance method (same operation on both sides)

- $x-5=12$ → add 5 both sides → $x=17$
- $4x=20$ → ÷4 both sides → $x=5$
- $3x+7=22$ → −7 → $3x=15$ → ÷3 → $x=5$

## Solve — transposition (move a term, flip its operation)

- $+5$ → $-5$ on the other side · $\times3$ → $\div3$
- $3x+7=22$ → $3x=22-7=15$ → $x=\frac{15}{3}=5$
- Check: put the answer back; both sides must match

**⚠️** must do the **same** thing to both sides · transposing $4x=20$ → $x=20\div4$, not $20-4$ · never ÷ by 0 · always verify by substituting back
