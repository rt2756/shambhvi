# Angles: The Basics
- **Acute angle**: < 90°
- **Obtuse angle**: 90 < angle < 180°
- **Reflex angle**: 180 < angle < 360°
- In a clock, **30° in an hour**, **6° in a minute**, **6° in a second**
  - In 12 hours, the hour hand covers 360°, so 1 hours = 360 / 12 = 30°
  - In 60 minutes, the minute hand covers 360°, so 1 minute = 360 / 60 = 6°
  - In 60 seconds, the seconds hand covers 360°, so 1 second = 360 / 60 = 6°
- **Straight angle = 180°**
- **Right angle = 90°**
  - **Perpendicular lines**: Two lines at 90° to each other are called to be perpendicular to each other
