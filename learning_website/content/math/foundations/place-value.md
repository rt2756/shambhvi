# Place Value and Large Numbers
- **Hundred**: $10^{2}$, 100
- **Thousand**: $10^{3}$, 1000
- **Million**: $10^{6}$, 1000000
- **Billion**: $10^{9}$, 1000000000
- **Trillion**: $10^{12}$, 1000000000000
